範例一  線性測驗 + 錯誤解說插入 + 計分板

HTTP 是哪一種類型的協定？

有狀態（Stateful）協定 無狀態（Stateless）協定 串流（Streaming）協定 全雙工（Full-duplex）協定

重點提示

HTTP 每次 Request/Response 都是獨立的，伺服器不記憶前次請求，因此稱為「無狀態」協定。Cookie、Session 是為了補充狀態管理而出現的機制。

DNS 的主要功能是什麼？

傳送電子郵件 加密網路流量 將網域名稱解析為 IP 位址 分配動態 IP 給裝置

重點提示

DNS（Domain Name System）就像電話簿，把人類好記的網址翻譯成機器使用的 IP 位址。DHCP 才是動態分配 IP 的協定。

TCP 建立連線的「三次握手」順序為何？

ACK → SYN → SYN-ACK SYN-ACK → SYN → ACK SYN → ACK → SYN-ACK SYN → SYN-ACK → ACK

重點提示

客戶端先發 SYN，伺服器回覆 SYN-ACK（表示「我收到了，你能收到我嗎？」），最後客戶端回 ACK 確認。三步完成即可傳送資料。

測驗完成 🎉
