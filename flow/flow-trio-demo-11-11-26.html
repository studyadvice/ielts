內容流動三件組（粗製版）

ui-stream 內容流、ui-metro 捷運路線圖、ui-orbit 軌道。三支獨立 .js，單檔含 CSS，不用 Shadow DOM。先看畫面與互動感，細節之後再磨。

1. ui-stream 內容流

<ui-stream>

批改過程重播：學生句子滑入，老師回饋逐字打出，遇到暫停點停下來讓學生先猜。

I think the river is very beautiful and there are many trees. beautiful 和 many 都太籠統了。先把 beautiful 換成能「看見」的描述。 試試看：The river winds through the valley, lined with willow trees. 字彙資源 6.0 → 6.5 The river winds through the valley, lined with willow trees, and the water is very clear. 很好。最後一句的 very clear 也可以升級：crystal clear 或 so clear you can see the riverbed。 本題完成，進入下一題。
事件會顯示在這裡。
<ui-stream controls autoplay speed="28" delay="700" height="460"
           accent="key" student-color="violet" teacher-color="key">
  <stream-item from="student" name="Amy" time="14:41">I think the river is…</stream-item>
  <stream-item from="teacher" name="老師" typed
               pause="先想想：老師會先改哪個字？">beautiful 和 many 都太籠統了…</stream-item>
  <stream-item from="system">字彙資源 6.0 → 6.5</stream-item>
</ui-stream>

屬性：autoplay、controls、speed（逐字毫秒）、delay（則與則之間）、height、
      accent、teacher-color、student-color、system-color
stream-item：from=teacher|student|system、name、time、typed、pause="提示文字"、icon
方法：play() pause() next() replay()
事件：ui-stream:item、ui-stream:pause、ui-stream:done

2. ui-metro 捷運路線圖

<ui-metro>

三條路線是三種 Task 2 結構，白圈是轉乘站（共用段落）。點站點，下方顯示該段寫法，其他路線變暗。

<ui-metro title="…" gap-x="170" gap-y="78" stop-size="20" panel-title="{line} · {label}">
  <metro-line name="完全同意型" color="key">
    <metro-stop key="intro" label="開頭" detail="m-intro"></metro-stop>   ← 同 key = 轉乘站
    <metro-stop key="a1" label="論點一" detail="m-a1"></metro-stop>
    <metro-stop key="concl" label="結論" detail="m-concl"></metro-stop>
  </metro-line>
  …
</ui-metro>
事件：ui-metro:select { line, key, label }

3. ui-orbit 軌道

<ui-orbit>

Part 2 題卡在中心，想法繞著轉。點一個想法，它飛進右側插槽並展開細節；再點圖示送回軌道。

<ui-orbit size="460" radius="150" item-size="68" period="36" accent="pink" pause-on-hover>
  <orbit-core icon="chat-quote-fill" label="Describe a river…" color="yellow"></orbit-core>
  <orbit-item icon="geo-alt-fill" label="在哪裡" detail="o-where" color="key"></orbit-item>
  <orbit-item icon="translate" label="可用字彙" detail="o-vocab" ring="2"></orbit-item>   ← ring="2" 外圈
</ui-orbit>
事件：ui-orbit:dock、ui-orbit:release { label }
