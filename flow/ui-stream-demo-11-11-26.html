<ui-stream> 內容流 v0.3

聊天室回放式的內容流動介面。單一 ui-stream.js，CSS 內建，不用 Shadow DOM。本頁上半是範例與程式碼對照，下半是依分類整理的屬性總覽，最後是版本對照。

範例 1：批改過程重播

控制列、進度條、逐字打出（含 mark 底色同步出現）、暫停點、暫停後揭露參考答案。

I think the river is very beautiful and there are many trees. beautiful 和 many 都太籠統了。先把 beautiful 換成能「看見」的描述。 試試看：The river winds through the valley, lined with willow trees. 字彙資源 6.0 → 6.5 The river winds through the valley, lined with willow trees, and the water is very clear. 很好。最後一句的 very clear 也可以升級：crystal clear 或 so clear you can see the riverbed。 本題完成。
事件會顯示在這裡。
<ui-stream title="Speaking Part 2：Describe a river"
           controls progress autoplay speed="26" delay="700" height="520" accent="key">
  <stream-item from="student" name="Amy" time="14:41">I think the river is…</stream-item>
  <stream-item from="teacher" name="老師" time="14:42" typed
               pause="先想想：老師會先改哪個字？" reveal="ans-1">beautiful 和 many 都太籠統了…</stream-item>
  <stream-item from="teacher" typed>試試看：The river <mark>winds through</mark>…</stream-item>
  <stream-item from="system">字彙資源 6.0 → 6.5</stream-item>
  <stream-item from="teacher" typed badge="升級" badge-color="energetic">很好…</stream-item>
  <stream-item from="system" delay="1200">本題完成。</stream-item>
</ui-stream>

範例 4：v0.3 新增屬性一次看

step 逐則、速度選單、三種間隔、頭像靠下、底色與 mark 色、整頁遮罩暫停、輸入中動畫、highlight、reveal-target、add()、export()。

step 模式：每一則都要按「下一則」。gap-system 讓這一則前後留白更多。 The city is very big and very crowded. And there are a lot of cars. 兩個 very 都可以升級：very big → sprawling，very crowded → densely populated。 a lot of cars → heavy traffic。參考答案會揭露到右側的區塊，不是插在內容流裡。 （這一則用 gap="48" 單獨留白）The city is sprawling and densely populated, with heavy traffic.

屬性總覽（依分類）

數字單位：px；字級：rem 或 CSS 長度；顏色：品牌色名稱或色碼。布林屬性寫 false 可以關掉預設開啟的功能。

一、播放控制（ui-stream）

屬性值預設說明
autoplay布林關載入後自動開始播放。
speed毫秒30逐字打出時每個字的間隔。
delay毫秒600一則結束到下一則出現的間隔。
start整數0載入時直接顯示到第幾則（不播動畫），從那裡開始。
loop布林關播完清空重來。
type-all布林關每一則都逐字打出，不必個別寫 typed。
auto-scroll布林開新內容出現時自動捲到底。設 false 則由使用者自己捲。
step布林關逐則模式：每一則播完就停，要按「下一則」或 play() 才出下一則。上課逐則講解用。

二、控制列與進度（ui-stream）

屬性值預設說明
controls布林關顯示控制列：播放 / 暫停切換、下一則、重播。
controls-positiontop、bottomtop控制列放在內容流上方或下方。
counter布林開控制列右側的「目前 / 總數」。
progress布林關控制列下方 3px 進度條，用 accent 色。
labels逗號分隔四個文字播放,暫停,下一則,重播按鈕文字。留空字串只顯示圖示，例如 labels=",,,"。
speed-control布林關控制列多一個速度選單（0.5x、1x、1.5x、2x），同時影響逐字速度與則間延遲。

三、版面（ui-stream）

屬性值預設說明
title文字無元件上方標題，讀取後移除屬性，避免瀏覽器提示。
heightpx自動整體固定高度，內容超出時在內部捲動。
gappx14訊息之間的上下間隔。
gap-samepx同 gap同一角色連續發言時的間隔，通常比 gap 小。
gap-systempx同 gapsystem 訊息前後的間隔，讓它像分隔線。
paddingpx16內容流四周內距。
bubble-width百分比數字78氣泡最大寬度，佔內容流寬度的百分比。system 固定 90。
bubble-radiuspx12氣泡圓角。
bubble-paddingCSS padding 值10px 14px氣泡內距。
line-height數字1.6氣泡行高。
font-sizerem 或長度1rem整體字級。
meta-sizerem 或長度0.75rem名稱、時間那一行的字級。
avatar布林開顯示頭像圓圈。
avatar-sizepx36頭像直徑，圖示大小自動跟隨。
avatar-positiontop、bottomtop頭像和名稱列對齊（top）或和氣泡底對齊（bottom）。
bordered布林開外框與圓角。設 false 時控制列的分隔線仍保留。

四、色彩（ui-stream）

屬性值預設說明
accent顏色key控制列按鈕、進度條、揭露區塊的框線。
border-color顏色bg-alternative外框與控制列分隔線。
text-color顏色vanilla外框式氣泡的文字色。實心氣泡文字預設深色，可用角色的 text-color 覆寫。
background顏色base內容流與外框式氣泡的底色。
mark-color顏色無氣泡裡 <mark> 的底色，文字自動深色。不設則用頁面 CSS。
teacher-color顏色key內建 teacher 角色的顏色。
student-color顏色violet內建 student 角色的顏色。
system-color顏色gray內建 system 角色的顏色。
pause-color顏色yellow暫停按鈕的顏色。

五、動畫與暫停（ui-stream）

屬性值預設說明
animationslide、pop、fadeslide訊息出現的方式。slide 從所屬側邊滑入，pop 由小放大，fade 只淡入。
cursor布林開逐字打出時的閃爍游標。
pause-iconBootstrap Icons 名稱hand-index-thumb暫停按鈕圖示。
pause-text文字點一下繼續stream-item 的 pause 沒給文字時的預設提示。
pause-stylebutton、overlaybuttonbutton 在內容流裡放一顆按鈕；overlay 用實色遮罩蓋住整個內容流，按任何地方繼續。
typing-indicator布林關逐字開始前先出現跳動的三個點約 0.7 秒，模擬對方正在輸入。

六、角色（stream-role）

內建 teacher（右側、實心）、student（左側、外框）、system（置中、虛線）。寫 <stream-role name="teacher"> 可以覆寫內建角色，寫新的 name 就是新角色。

屬性值預設說明
name文字必填角色代號，stream-item 的 from 用這個。
label文字無stream-item 沒給 name 時顯示的名稱。
color顏色shell這個角色的頭像、名稱、氣泡色。
iconBootstrap Icons 名稱person-fill頭像圖示。
sideleft、right、centerleft氣泡靠哪一邊。center 不顯示頭像。
stylefilled、outline、dashedoutline氣泡樣式。
image圖片網址無這個角色的預設頭像圖片，不必每則寫。
text-color顏色自動這個角色氣泡的文字色，覆寫自動判斷（實心深色、外框 text-color）。

七、訊息（stream-item）

屬性值預設說明
from角色 namestudent內建 teacher、student、system，或 stream-role 定義的角色。
name文字角色 label顯示名稱。
time文字無名稱旁的時間，純文字不做格式化。
badge文字無名稱列右側的小角標，例如「追問」、「修正」。
badge-color顏色角色色角標底色。
iconBootstrap Icons 名稱角色 icon只覆寫這一則的頭像圖示。
image圖片網址無以圖片當頭像，優先於 icon。
color顏色角色色只覆寫這一則的顏色。
source元素 id無內容改從 template 或任何帶 id 的元素複製，適合長內容或多則共用。
typed布林關逐字打出。HTML 標籤（mark、c-key 等）會隨文字一起出現。
speed毫秒沿用容器只覆寫這一則的逐字速度。
delay毫秒沿用容器這一則結束後到下一則的間隔。
pause文字或空值無這一則之後停下來，顯示按鈕，按了才繼續。空值用 pause-text。
reveal元素 id無這一則之後（有 pause 則在按下繼續後）插入該 id 的內容，例如參考答案。
reveal-target元素 id無搭配 reveal：內容不插在內容流裡，改放進這個元素並顯示它（移除 hidden）。
gappx無這一則前面的間隔，覆寫 gap、gap-same、gap-system。
highlight布林關這一則出現（打完）時氣泡用 accent 色閃三下。

八、資料與程式

項目值預設說明
srcURL無從網址讀取 JSON。
data-id全域變數名稱無從 window[data-id] 讀取 JSON。JSON 格式：陣列，或 { roles, items }；item 的 text 為純文字、html 為 HTML，其他欄位同 stream-item 屬性的駝峰寫法。
方法play()、pause()、toggle()、next()、replay()、goto(i)、finish()；add(item) 動態加一則（物件欄位同 JSON item，播放到底時會自動播出）；export() 回傳純文字、export('html') 回傳訊息 HTML；唯讀屬性 index、total。
事件ui-stream:item、ui-stream:typed、ui-stream:pause、ui-stream:resume、ui-stream:done，都會冒泡。
UiStreamConfig載入前設定 window.UiStreamConfig，欄位同 ui-stream 屬性的駝峰寫法（如 controlsPosition），所有實例的預設值。載入後可讀 window.UiStream.config。

v0.1 → v0.2 → v0.3 改了什麼

v0.1（粗製版）

只有 teacher / student / system 三種角色，寫死。
typed 先轉純文字打出，打完才換回 HTML，
途中看不到 mark 底色。
暫停只能停，不能在繼續後給東西。
控制列固定在上方，按鈕文字固定。
沒有 JSON、沒有全域設定、沒有 goto / finish。

v0.2

<stream-role> 自訂角色：顏色、圖示、側邊、氣泡樣式。
逐字打出改為逐節點，mark、c-key 隨文字出現。
pause 之後可以 reveal 一段隱藏內容（參考答案）。
controls-position、labels、counter、progress。
badge、image、color、source、speed、delay 可逐則設定。
src / data-id JSON 模式，window.UiStreamConfig 全域預設。
goto(i)、finish()、toggle()，新增 typed / resume 事件。
start、loop、type-all、auto-scroll、cursor、animation。

v0.3（依討論清單實作，排除 sound、hotkeys、columns、detail）

播放：step 逐則模式。
控制列：speed-control 速度選單。
版面：gap-same、gap-system、bubble-padding、line-height、avatar-position。
色彩：background、mark-color。
暫停與動畫：pause-style="overlay"、typing-indicator。
角色：image、text-color。
訊息：gap、reveal-target、highlight。
程式：add(item)、export(format)。
