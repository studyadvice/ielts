pause()特效停住正在落下的章、正在浮現的評語停在當下。

屬性值預設說明

avatar-repeatall、first、lastalllayout 為 flat、tail 時沒寫則等同 first。

畫面區 stage

屬性值預設說明

stage-width百分比數字60畫面區佔整個外框寬度的百分比，10 到 90。
stage-start#id、圖片網址無畫面區的開場內容；重播、goto、loop 時回到它。
stage（訊息）#id、圖片網址、clear無寫在 stream-item 或 p-msg：這一則一出現就切換畫面區。# 開頭是 template 或元素的內容，clear 是清空，其他當成圖片網址。

屬性總覽（依分類，v0.5）

數字單位：px；字級：rem 或 CSS 長度；顏色：品牌色名稱或色碼。布林屬性寫 false 可以關掉預設開啟的功能。

一、播放控制（ui-stream）

屬性值預設說明
autoplay布林關載入後自動開始播放。
speed毫秒30逐字打出時每個字的間隔。
delay毫秒600一則結束到下一則出現的間隔。
start整數0載入時直接顯示到第幾則（不播動畫），從那裡開始。
loop布林關播完清空重來。
type-all布林關每一則都逐字打出，不必個別寫 typed。
modelive無接收模式：不顯示控制列，loop、autoplay、start 失效；預先寫好的 stream-item 一載入就直接顯示，之後用 add() 或 ui-contacts 拖放送進來的訊息逐則播出。
