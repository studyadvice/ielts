<ui-contacts> 通訊錄 v0.1

預先寫好人物與訊息，把人物卡片拖到 <ui-stream mode="live"> 就會送出他的下一則訊息；也可以點卡片右下角的電話圖示送出。單一 ui-contacts.js，CSS 內建，不用 Shadow DOM。需要先載入 ui-stream.js（v0.5 以上）。ui-stream 的完整範例見 ui-stream-demo-11-15-26.html。

範例 1：通訊錄拖放到內容流

照截圖的雙欄版面。卡片右下角數字是剩餘訊息數，用完後變灰、不能再拖。點 ⋯ 可以預覽這個人的訊息。

把左邊的人物拖到右邊的對話框，或點電話圖示。

Good evening, welcome to the Riverside Hotel. How may I help you? Certainly. Could I have your surname, please? Your room is on the third floor. Breakfast is served from 7 to 10. Hi, I have a reservation under the name Bowman. Is there a lift? I have quite a lot of luggage. Excuse me, is there anywhere nearby to grab a bite? I'd like to extend my stay by two nights, if possible. Thanks, that's really kind of you. The air conditioning in my room isn't working properly. Sorry, I'm in a meeting. Could you send it to my email? （一匹馬走進了大廳。） Hello? Is anyone at the front desk? I'm afraid I've locked myself out of my room. Could you recommend a good museum within walking distance? What time is check-out? Could I get a late check-out, around two?

範例 2：card-theme 預設樣式組合

一個屬性套好底色、框線、文字、頭像與 hover 色。tint、bar 兩組會用每張卡片自己的 color。

night（預設）
night：深底、細框。Second message.
cocoa
cocoa：bg-alternative 底、無框。Second message.
paper
paper：淺色卡片。Second message.
key
key：key 色框線與名字。Second message.
neon
neon：energetic 螢光綠。Second message.
indigo
indigo：2px 靛藍框。Second message.
dreamy
dreamy：粉色虛線框。Second message.
double
double：雙線框。Second message.
tint（用卡片 color）
tint：框線、名字、頭像都用卡片 color。Second message.
bar（用卡片 color）
bar：左側色條。Second message.
<ui-contacts card-theme="neon">…</ui-contacts>            ← 整組套用
<p-card card-theme="paper" …>…</p-card>                  ← 單張覆寫
<p-card card-theme="bar" color="green" …>…</p-card>      ← tint、bar 會用卡片的 color

可用值：night、cocoa、paper、key、neon、indigo、dreamy、double、tint、bar
優先順序：p-card 個別屬性 → p-card 的 card-theme → ui-contacts 個別屬性 → ui-contacts 的 card-theme

範例 4：方法與事件

用程式送出、查剩餘數、重置；監聽 ui-contacts:send 與 ui-contacts:empty。

I think the river is very beautiful. The river winds through the valley. beautiful 太籠統了，試著描述你看見什麼。 很好。還能再升級嗎？
事件會顯示在這裡。
const c = document.getElementById('c4');
c.send('Amy');      // 依名字、role 或索引送出下一則，回傳 true / false
c.send(1, 's4');    // 第二個參數可指定 ui-stream 的 id
c.remaining('Amy'); // 剩餘訊息數
c.cards;            // [{ name, role, total, sent }, …]
c.reset();          // 全部卡片恢復；c.reset('Amy') 只恢復一張

c.addEventListener('ui-contacts:send',  e => e.detail);  // { name, role, index, remaining, card, target }
c.addEventListener('ui-contacts:empty', e => e.detail);  // { name, role, card }

屬性總覽

數字單位：px；字級：rem 或 CSS 長度；顏色：品牌色名稱或色碼。布林屬性寫 false 可關掉預設開啟的功能。標「可覆寫」的屬性也能寫在 p-card 上。

一、連結與訊息（ui-contacts）

屬性值預設說明
forui-stream 的 id，可空白分隔多個無拖放目標。不寫時，頁面上只有一個 ui-stream 就自動用它。點電話圖示送到第一個。
type-all布林關所有訊息都逐字打出（可覆寫）。p-msg 寫 typed="false" 可單則關掉。
sideleft、right、centerleft人物在對話中靠哪一邊（可覆寫）。
data-stylefilled、outline、dashed、double、notch、calloutoutline人物在對話中的氣泡樣式（可覆寫）。

二、標題與版面（ui-contacts）

屬性值預設說明
title、title-size、title-weight、title-color文字、rem、數字、顏色無、1.2rem、700、violet標題，與 ui-stream 一致。
columns整數2欄數。
gappx12卡片間距。
card-paddingCSS padding 值12px 14px卡片內距。
card-radiuspx10卡片圓角。
card-min-heightpx自動卡片最小高度。
avatar-sizepx44頭像大小。
avatar-shapecircle、rounded、squarecircle頭像形狀。
name-size、name-weightrem、數字1rem、600名字字級與粗細。
meta-sizerem0.85rem狀態文字字級。

三、樣式與色彩（ui-contacts，皆可覆寫）

屬性值預設說明
card-themenight、cocoa、paper、key、neon、indigo、dreamy、double、tint、barnight預設樣式組合，一次設定下面各項。
card-bg顏色依 theme卡片底色。
card-border-color顏色依 theme卡片框線色。
card-border-widthpx依 theme卡片框線粗細，0 為無框。
card-border-stylesolid、dashed、double依 theme卡片框線樣式。
card-barpx依 theme左側色條寬度，顏色用卡片 color。
name-color、meta-color、icon-color顏色依 theme名字、狀態文字與分機、⋯ 與電話圖示的顏色。
avatar-bg、avatar-text-color顏色依 theme縮寫或圖示頭像的底色與文字色。
hover-color顏色依 theme滑鼠移上卡片的外框色。
drop-color顏色key拖曳時目標 ui-stream 的提示框線色（只寫在 ui-contacts）。

四、顯示開關（ui-contacts，皆可覆寫）

屬性值預設說明
show-status布林關顯示狀態點與狀態文字。
status-dotavatar、textavatar狀態點放在頭像右下角，或狀態文字前面。
show-ext布林開名字後面顯示分機號碼。
show-menu布林開⋯ 選單，點開預覽這個人的訊息。
show-call布林開電話圖示，點了送出下一則。
show-count布林開剩餘訊息數。

五、人物（p-card）與訊息（p-msg）

屬性值預設說明
p-card name文字必填人物名字，也是對話中顯示的名稱。
p-card role文字由 name 產生在 ui-stream 註冊的角色代號。兩組通訊錄有同名人物又要分開設定時才需要寫。
p-card ext文字無分機號碼。
p-card status文字無狀態文字，純裝飾。
p-card status-color顏色自動狀態點顏色。不寫時依文字判斷：Available 綠、Meeting／Busy 紫、Away 黃、DND 紅、其他灰。
p-card image、initials、icon網址、文字、Bootstrap Icons 名稱名字縮寫頭像。都不寫時取名字前兩個字的字首，例如 Dolly The Horse 為 DT。對話中的頭像同步。
p-card color顏色自動輪替人物主色：對話中的氣泡、頭像色，也用於剩餘數、色條、tint 樣式。
p-card text-color、text-align顏色、對齊無對話中氣泡的文字色與對齊。
p-msg 內容HTML訊息內容，可用 mark、c-key 等色名標籤。
p-msg 屬性typed、time、badge、badge-color、speed、delay、gap、highlight、color、side、data-style、text-align、pause、reveal、reveal-target，意思同 stream-item。

六、方法、事件與全域設定

項目說明
方法send(who, targetId?)、remaining(who)、reset(who?)；who 可以是名字、role、索引或 p-card 元素。唯讀屬性 cards。
事件ui-contacts:send { name, role, index, remaining, card, target }、ui-contacts:empty { name, role, card }，都會冒泡。
UiContactsConfig載入前設定 window.UiContactsConfig，欄位同屬性的駝峰寫法。載入後可讀 window.UiContacts.themes 查看所有樣式組合。
操作拖放用 pointer events，滑鼠與觸控都能用。卡片上不能捲動頁面（觸控時請在卡片外滑動）。訊息用完的卡片改為灰階虛線框，不能再拖。
