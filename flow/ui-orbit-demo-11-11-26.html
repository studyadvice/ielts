<ui-orbit> 軌道 v2.0.0

小圓圈只放圖示，文字改成軌道外側的水平標籤：右半邊靠左對齊，左半邊靠右對齊，上下方置中。點圓圈或標籤都能讓想法停進右側插槽；再點插槽裡的圖示送回軌道。

1. 長標籤：一個想法就是一句提示

label-width="180"、label-lines="2"。超過兩行的標籤會以 ... 截斷，滑鼠停留可看全文。

2. 兩圈軌道，逆時針旋轉

ring="2" 放在外圈。direction="ccw"、label-lines="1"。

修改前後對照

修改前（v1）：文字擠在 64px 圓圈裡，0.7rem，只放得下二到四個字
<ui-orbit size="460" radius="150" item-size="68" period="36">
  <orbit-item icon="geo-alt-fill" label="在哪裡" detail="o-where" color="key"></orbit-item>
</ui-orbit>

修改後（v2.0.0）：圓圈只放圖示，標籤在軌道外側水平顯示，可放一整句提示
<ui-orbit radius="160" item-size="56" period="48" label-width="180" label-lines="2">
  <orbit-item icon="geo-alt-fill" label="在哪裡：先給一個具體地名" detail="o-where" color="key"></orbit-item>
</ui-orbit>

新屬性：label-width（標籤最大寬度，預設 170）、label-lines（最多行數，預設 2）、
        label-size（字級，預設 0.95rem）、label-gap（圓圈到標籤距離，預設 8）、core-size（中心圓直徑）
size 改為軌道區的最小寬度，實際寬高會依半徑與標籤寬度自動計算。舊的寫法不需修改即可使用。
事件不變：ui-orbit:dock、ui-orbit:release { label }
