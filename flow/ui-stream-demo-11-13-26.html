<ui-stream> 內容流 v0.4：新增氣泡樣式與外框粗細

新增 double（雙線框）、notch（切角框）、callout（引線框）三種氣泡樣式，以及 border-width（整個元件外框粗細）、bubble-border-width（氣泡邊框粗細）、title-size、title-weight、title-color（標題樣式）。完整用法請參考 ui-stream-demo-11-11-26.html。

範例 1：三種新樣式，左右各一

stream-role 的 style 屬性指定樣式；靠右的氣泡會自動鏡像。

Describe a time you helped someone. 雙線框適合用來標示題目或重點句。 I helped my neighbour carry boxes when she moved house last summer. 切角框像一張便條，適合放範例答案。 It was exhausting, but I felt genuinely useful. 引線框適合放旁白或補充說明。 
<ui-stream autoplay delay="350" height="760" border-width="3">
  <stream-role name="d1" color="blue"    side="left"  style="double"  label="double 靠左"></stream-role>
  <stream-role name="d2" color="key"     side="right" style="double"  label="double 靠右"></stream-role>
  <stream-role name="n1" color="quiet"   side="left"  style="notch"   label="notch 靠左"></stream-role>
  <stream-role name="n2" color="playful" side="right" style="notch"   label="notch 靠右"></stream-role>
  <stream-role name="c1" color="quiet"   side="left"  style="callout" label="callout 靠左"></stream-role>
  <stream-role name="c2" color="yellow"  side="right" style="callout" label="callout 靠右"></stream-role>
  <stream-item from="d1">Describe a time you helped someone.</stream-item>
  <stream-item from="d2">雙線框適合用來標示題目或重點句。</stream-item>
  <stream-item from="n1">I helped my neighbour carry boxes…</stream-item>
  <stream-item from="n2">切角框像一張便條，適合放範例答案。</stream-item>
  <stream-item from="c1">It was exhausting, but I felt genuinely useful.</stream-item>
  <stream-item from="c2">引線框適合放旁白或補充說明。</stream-item>
</ui-stream>

範例 2：調整粗細與切角大小

bubble-border-width 統一氣泡邊框粗細；notch 的切角大小沿用 bubble-radius；頭像在下時，callout 引線改為往下指。

A cut corner makes the bubble look like a sticky note. The leader line points back to the speaker. Thin double border. 
<ui-stream autoplay delay="350" height="460"
           border-width="1" bubble-border-width="2" bubble-radius="24" avatar-position="bottom">
  <stream-role name="n" color="green"  side="left"  style="notch"></stream-role>
  <stream-role name="c" color="pink"   side="right" style="callout"></stream-role>
  <stream-role name="d" color="violet" side="left"  style="double"></stream-role>
  …
</ui-stream>

範例 3：標題樣式

title-size、title-weight、title-color 調整 title 的字級、粗細與顏色。

預設為 1.2rem、700、violet。
標題改為 1.6rem、400、key。 
<ui-stream title="預設標題樣式">…</ui-stream>

<ui-stream title="Speaking Part 3"
           title-size="1.6rem" title-weight="400" title-color="key">
  …
</ui-stream>

新增的屬性與樣式

屬性／值預設值說明
border-width1整個元件外框粗細（px）。bordered="false" 時仍為無外框。
bubble-border-width0所有氣泡的邊框粗細（px）。0 表示依各樣式的預設值：filled、outline、dashed 為 1，double 為 4，notch 為 1.5，callout 為 3。
title-size1.2rem標題字級。只寫數字視為 rem。
title-weight700標題粗細，例如 400、700、800。
title-colorviolet標題顏色，可用色票名稱或 hex。
style="double"雙線框。雙線需要 3px 以上才看得出兩條線。
style="notch"切角框：邊框為角色色，底色是角色色和背景色調和出的實色。靠左切右上角，靠右切左上角，切角大小沿用 bubble-radius（最小 6px）。
style="callout"引線框：粗框外側有一條分離的直線，直線上拉出折線引線指向頭像。頭像在上（預設）時引線往上，avatar-position="bottom" 時往下。氣泡會往內縮 78px 讓出引線空間。

全域設定同樣適用：window.UiStreamConfig = { borderWidth: 2, bubbleBorderWidth: 0, titleSize: '1.4rem', titleColor: 'key' }。JSON 的 roles 也可以寫 "style": "notch"。

版本對照：v0.3 → v0.4

v0.3

/* 預設值 */
bordered: true, avatar: true, …

/* 標題 */
.us-title{font-size:1.2rem;font-weight:700;color:${PALETTE.violet};…}

/* 外框與氣泡 */
.us-wrap{border:1px solid var(--us-border);…}
.us-bubble{border:1px solid var(--us-c);…}

/* 樣式：filled | outline | dashed */

v0.4

/* 預設值 */
bordered: true, borderWidth: 1, bubbleBorderWidth: 0, avatar: true, …
titleSize: '1.2rem', titleWeight: 700, titleColor: 'violet',

/* 標題 */
.us-title{font-size:var(--us-tfs);font-weight:var(--us-tfw);color:var(--us-tc);…}

/* 外框與氣泡 */
.us-wrap{border:var(--us-wbw,1px) solid var(--us-border);…}
.us-bubble{border:var(--us-bbw,1px) solid var(--us-c);…}

/* 樣式：filled | outline | dashed | double | notch | callout */
.us-double .us-bubble{border-style:double;border-width:var(--us-bbw,4px);}
.us-notch .us-bubble{clip-path:polygon(…);background:var(--us-c);}
.us-notch .us-bubble::before{inset:var(--nb);background:color-mix(…);}
.us-callout .us-bubble{border-width:var(--cb);margin-left:78px;}
.us-callout .us-bubble::before{/* 分離的直線 */}
.us-callout .us-bubble::after{/* 折線引線，skewX */}
