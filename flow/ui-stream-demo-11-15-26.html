v0.4 新增的屬性與樣式

屬性／值預設值說明
border-width1整個元件外框粗細（px）。bordered="false" 時仍為無外框。
bubble-border-width0所有氣泡的邊框粗細（px）。0 表示依各樣式的預設值：filled、outline、dashed 為 1，double 為 4，notch 為 1.5，callout 為 3。
title-size1.2rem標題字級。只寫數字視為 rem。
title-weight700標題粗細，例如 400、700、800。
title-colorviolet標題顏色，可用色票名稱或 hex。
text-align訊息內容對齊：left、center、right、justify。可設在 ui-stream（全部）、stream-role（該角色）或 stream-item（單則），越細的優先。未設定時維持原樣，system 置中、其他靠左。
avatar-repeatall同一人連續發言時的頭像：all 每則都顯示；first 只在第一則顯示；last 只在最後一則顯示（適合搭配 avatar-position="bottom"）。隱藏的頭像保留空位，訊息不會錯位。設為 first 或 last 時，名字只在連續發言的第一則顯示；時間與徽章照常顯示。
<c-色名>訊息內可用 <c-key>、<c-calm>、<c-urgent> 等色名標籤，逐字打出時顏色同步出現。ui-stream.js 已內建，頁面上不需要其他元件。
data-style="double"雙線框。雙線需要 3px 以上才看得出兩條線。
data-style="notch"切角框：邊框為角色色，底色是角色色和背景色調和出的實色。靠左切右上角，靠右切左上角，切角大小沿用 bubble-radius（最小 6px）。
data-style="callout"引線框：粗框外側有一條分離的直線，直線上拉出折線引線指向頭像。頭像在上（預設）時引線往上，avatar-position="bottom" 時往下。氣泡會往內縮 78px 讓出引線空間。

全域設定同樣適用：window.UiStreamConfig = { borderWidth: 2, bubbleBorderWidth: 0, titleSize: '1.4rem', titleColor: 'key' }。JSON 的 roles 寫 "dataStyle": "notch"。

屬性總覽

屬性總覽（依分類，v0.5）

數字單位：px；字級：rem 或 CSS 長度；顏色：品牌色名稱或色碼。布林屬性寫 false 可以關掉預設開啟的功能。

一、播放控制（ui-stream）

屬性值預設說明
autoplay布林關載入後自動開始播放。
speed毫秒30逐字打出時每個字的間隔。
delay毫秒600一則結束到下一則出現的間隔。
start整數0載入時直接顯示到第幾則（不播動畫），從那裡開始。
loop布林關播完清空重來。
type-all布林關每一則都逐字打出，不必個別寫 typed。
modelive無接收模式：不顯示控制列，loop、autoplay、start 失效；預先寫好的 stream-item 一載入就直接顯示，之後用 add() 或 ui-contacts 拖放送進來的訊息逐則播出。
auto-scroll布林開新內容出現時自動捲到底。有 height 時捲動內容流；沒有 height 時改捲動整個頁面，讓最後一行留在視窗內（元件不在畫面上時不捲）。設 false 則由使用者自己捲。
scroll-spacepx48捲到底時最後一行下方保留的空白，方便螢幕錄影時不出界。有 height 時是內容流底部的留白；沒有 height 時是元件底部到視窗底部的距離。
step布林關逐則模式：每一則播完就停，要按「下一則」或 play() 才出下一則。上課逐則講解用。

八、資料與程式

項目值預設說明
srcURL無從網址讀取 JSON。
data-id全域變數名稱無從 window[data-id] 讀取 JSON。JSON 格式：陣列，或 { roles, items }；item 的 text 為純文字、html 為 HTML，其他欄位同 stream-item 屬性的駝峰寫法。
方法play()、pause()、toggle()、next()、replay()、goto(i)、finish()；add(item) 動態加一則（物件欄位同 JSON item，可含 side、dataStyle、initials，播放到底時會自動播出）；addRole(name, opts) 註冊或更新角色（opts 欄位同 stream-role 屬性的駝峰寫法，如 dataStyle、textColor）；hasRole(name)；唯讀屬性 live；export() 回傳純文字、export('html') 回傳訊息 HTML；唯讀屬性 index、total。
事件ui-stream:item、ui-stream:typed、ui-stream:pause、ui-stream:resume、ui-stream:done，都會冒泡。
UiStreamConfig載入前設定 window.UiStreamConfig，欄位同 ui-stream 屬性的駝峰寫法（如 controlsPosition），所有實例的預設值。載入後可讀 window.UiStream.config。
