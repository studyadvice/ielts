mini-table 儲存格揭曉

mini-table.js 新增儲存格 API，搭配 ui-plus.js 的 <ui-btn>，用 Excel 的座標指定某一格，點擊後顯示內容。表頭算第 1 列。建立日期 11-10-26。

範例一：座標怎麼數

三欄三列的表：第 1 列是表頭，所以 B2 是第一筆資料的第二欄。按下按鈕，九格同時換成自己的座標；內容用 | 分隔，一格一段，依 A1、B1、C1、A2…的順序對應。

範例二：單格揭曉答案

最常用的寫法。target-cell-content 可以寫 HTML；長一點的內容放進 template，用 target-cell-source 讀取。再按一次恢復成問號。

範例三：JavaScript API

不透過 ui-btn 也可以直接操作。寫入的內容會被記住，呼叫 render() 重畫後仍然保留；resetCell() 恢復原始內容。

Fluency | 6 Lexical resource | 6

JavaScript

const t = document.getElementById('api-tbl');
t.cellAt('B2');               // 取得儲存格元素（th 或 td）
t.resolveCells('A2:B3');      // ['A2', 'B2', 'A3', 'B3']
t.setCell('B3', '7.5');       // 寫入並記住，render() 後仍保留
t.resetCell('B3');            // 恢復原始內容
t.size();                     // { cols: 2, rows: 3 }，表頭算一列
MiniTable.parseRef('$AA$12'); // { col: 27, row: 12 }
MiniTable.refName(27, 12);    // 'AA12'

座標規則與相關屬性

項目範例說明
座標B2、AA12欄用字母、列用數字，都從 1 起算，大小寫皆可。有表頭時表頭是第 1 列；沒有表頭時第一筆資料就是第 1 列。
多格與範圍B2 C3、C2:C4逗號或空白分隔，範圍依列的順序展開（A1、B1…A2、B2…）。
絕對參照$B$2從 Excel 複製過來的 $ 會略過。
超出範圍D9主控台警告並說明表格的欄數與列數，那一格略過。
mini-table-idmini-table-id="mytbl"寫在 ui-btn 上，指定表格。也接受 min-table-id。
target-celltarget-cell="B2"寫在 ui-btn 上，指定儲存格。
target-cell-contenttarget-cell-content="<b>Cafe</b>"寫在 ui-btn 上，要顯示的內容。多格用 | 分隔。
target-cell-sourcetarget-cell-source="ans"寫在 ui-btn 上，從 template 讀內容，優先於 target-cell-content。

ui-btn 的 label-open、stagger、anim-duration、animation="none"、open、group 都能和儲存格一起用。兩支檔案的載入順序不拘。
