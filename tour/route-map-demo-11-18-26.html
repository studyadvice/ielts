<route-map> 路線圖 v1.1

用捷運路線圖呈現任何「類別與項目」的關係：路線是類別，車站是項目，轉乘站是兩個類別共有的項目，分區是階段，亮色與暗色是進度。路線只走水平、垂直、45 度，轉角自動變圓，端點自動加上路線牌，整張圖依內容自動裁切。單一 route-map.js，CSS 內建，不用 Shadow DOM。車站的 id 可以直接給 page-tour 當鏡頭目標。

新範例 A：show-grid 座標格線

設計路線時打開，確認每一站的座標；做好再拿掉。

形容詞 名詞 副詞 
<route-map grid="30" show-grid label-zoom="1.8">
  …
</route-map>

show-grid 的畫法
  格線區的底色是 rgb(36,36,36)，格線是底色 #0C0D0C 的細縫
  上方與左側的數字是格座標，與 at、path、from、to 用的座標相同
  範圍是 0 到 cols、0 到 rows；沒寫 cols、rows 時依路線自動決定
  不用透明度；寫 show-grid="false" 或拿掉屬性就不畫

新範例 B：route-train 火車沿線跑，可以跨線

圖示是 Bootstrap Icons；起站與終點寫車站 id 或站名；播放時整張圖不能操作。

聽力入門 數字拼寫 地圖題 選擇題 聽力模考 閱讀入門 略讀 是非題 段落配對 閱讀模考 口說入門 自我介紹 延伸回答 口說模考 同義替換 觀點表達 邏輯連接
按上面的按鈕播放。播放時把滑鼠移到站名上，不會放大。
<route-map id="rm-train" grid="32" label-zoom="1.6">
  <route-line name="聽力線" …>
    <route-stop id="st-l0" at="1,6">聽力入門</route-stop>   ← 想當起站或終點的車站，寫 id 或直接用站名
  </route-line>
  <route-transfer id="st-syn" at="13,6">同義替換</route-transfer>   ← 有轉乘站，火車才能換線
  <route-train id="t1" from="st-l0" to="st-l1" icon="bi-train-front-fill" color="yellow"></route-train>
  <route-train id="t3" from="閱讀入門" to="口說入門" duration="5000"></route-train>   ← 自動找最短路徑，換線也可以
</route-map>

const map = document.getElementById('rm-train');
map.play('t2');                 // 用 route-train 的 id；也可以寫第幾個，例如 map.play(0)
map.play('t2').then(ok => …);   // 跑完是 true，被 stop() 中斷是 false
map.stop();                     // 中斷並收掉火車
map.addEventListener('route-map:train-end', e => e.detail);   // { id, from, to, lines, completed }

播放時的細節
  路線一律中途不停，沿著畫出來的圓角路徑跑，圖示不旋轉
  跑的時候先把放大的站名還原，再鎖住整張圖；hover() 會被忽略並回傳 false，page-tour 的 fx-hover 也一樣
  跑完火車留在終點，下一次播放或 stop() 時收掉
  找不到車站、兩站沒有相連，會在圖下方用紅框說明，並發出 route-map:train-error
  autoplay 寫在 route-train 上，圖畫好就自動播放（只有第一個有 autoplay 的會播）

範例 2：站名放大，個別倍數與程式控制

label-zoom 是整張圖的倍數；route-stop、route-transfer 的 zoom 可以個別覆寫，寫 1 就不放大。

形容詞 名詞 副詞
滑鼠移到站名上試試：「名詞」放大 2.6 倍，「副詞」不放大。
<route-map label-zoom="1.6" label-zoom-speed="220">
  …
  <route-transfer id="st-adj"  at="3,4"  sub="後位修飾名詞">形容詞</route-transfer>           ← 用整張圖的 1.6
  <route-transfer id="st-noun" at="10,4" sub="主詞、受詞、補語" zoom="2.6">名詞</route-transfer>
  <route-transfer id="st-adv"  at="17,4" sub="修飾整句" zoom="1">副詞</route-transfer>      ← 不放大
</route-map>

const map = document.getElementById('rm2');
map.hover('st-noun');          // 放大
map.hover('st-noun', false);   // 還原
map.stations;                  // 有 id 的車站清單

map.addEventListener('route-map:hover', e => e.detail);   // { id, on }

放大時的細節
  以車站為中心往外放大，站名不會蓋住車站
  放大的那一站移到最上層，不會被線條或其他站名壓住
  副標題（sub）跟著一起放大
  page-tour 的 <fx-hover target="#st-noun"> 會呼叫 hover()，錄影時也看得到放大

屬性總覽

<route-map>

屬性值預設說明
gridpx36一格的大小。所有座標都以格為單位。
cols、rows格數自動畫布大小。省略時依路線座標決定；整張圖最後會依內容自動裁切。
pad格數1.7座標原點往內縮的距離。
donex 座標無進度：x 小於等於這個值的路段與車站用亮色，其餘用暗色（實色混合，不用透明度）。
line-widthpxgrid × 0.26路線粗細，最小 7。
label-zoom倍數1滑鼠移到站名上時放大的倍數；1 表示不放大。
label-zoom-speed毫秒180放大與還原的時間。
show-grid布林關畫出座標格線與座標數字，設計路線時使用；底色是 rgb(36,36,36)，格線是 #0C0D0C 細縫。寫 show-grid="false" 等於關。
legend「x,y」無在這個格座標畫圖例；不寫就不畫。
legend-title、legend-transfer、legend-future、legend-here文字圖例、轉乘站：兩條路線共用、暗色：還沒到、目前位置圖例的文字。

子標籤

標籤與屬性值預設說明
<route-zone from to>x 座標必填分區背景，標籤內文是分區名稱。第一區與最後一區會延伸到圖的邊緣。
<route-line name color path>文字、顏色、座標串必填路線。path 是轉彎點，空白分隔，例如 "2,17 14,5 31,5"。
route-line 的 badgefalse開寫 false 不畫端點路線牌。
<route-stop at label sub zoom id>座標、方位、文字、倍數、idlabel：s寫在 route-line 裡的一般車站，內文是站名。label 是站名方位：n、ne、e、se、s、sw、w、nw。sub 是第二行小字。
<route-transfer …>同 route-stoplabel：s轉乘站，直接寫在 route-map 裡。
<route-here at>座標無目前位置：脈衝光圈與標籤，內文預設「你在這裡」。
<route-train from to>車站 id 或站名必填火車。從起站沿路線跑到終點，必要時在轉乘站換線，自動找最短路徑，中途不停。
route-train 的 iconBootstrap Icons 名稱bi-train-front-fill寫 bi-train-front-fill、train-front-fill 都可以；頁面要引用 bootstrap-icons.css。
route-train 的 color色票名稱或色碼yellow圖示底圓的顏色。
route-train 的 sizepx30底圓直徑，圖示大小跟著縮放。
route-train 的 speed、durationpx 每秒、毫秒240、無速度；寫了 duration 就用它當總時間，speed 無效。
route-train 的 autoplay、id布林、文字無autoplay：圖畫好就播放。id：給 play('id') 使用。
id文字無寫在 route-stop、route-transfer 上的 id 會移到畫出來的車站，page-tour 可以直接用 #id 指定。

方法與事件

項目說明
hover(id, on)放大（on 預設 true）或還原某一站的站名；id 可以是字串或車站元素。
play(target)播放火車。target 是 route-train 的 id 或第幾個（預設 0）。回傳 Promise：跑完是 true，被中斷或無法播放是 false。播放中不能操作站名。
stop()中斷動畫並收掉火車，解除鎖定。
render()修改子標籤後重新繪製。
stations唯讀，有 id 的車站清單。
事件route-map:render（畫完）、route-map:hover（detail：id、on）、route-map:train-start、route-map:train-end（detail：id、from、to、lines、completed）、route-map:train-error（detail：message），都會冒泡。
