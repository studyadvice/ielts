<page-tour> 鏡頭漫遊 v1.0

把既有的教材頁面當成畫布：原本的 HTML 包進 <tour-world>，版面完全不用改，鏡頭要去哪裡就寫那個元素的 id。導演預先寫好運鏡與特效，按下開始自動播放，直接螢幕錄影。單一 page-tour.js，CSS 內建，不用 Shadow DOM。

範例特效清單屬性總覽route-map 路線圖

範例：既有頁面當畫布

下面的教材是一般的 Bootstrap 版面（左欄三張卡片、右欄路線圖與兩張卡片），右側另外用 tour-panel 自由擺了一張「下課前」。按 F 全螢幕、H 隱藏控制列，錄影效果最好。

這個範例的寫法

<page-tour world-w="1600" countdown="3" dots>
  <tour-world>
    …原本的教材 HTML，不用改…
    <tour-panel id="p-free" x="1230" y="40" w="330">…</tour-panel>   ← 需要自由擺放的才用 x、y
  </tour-world>

  <tour-step to="overview" hold="2.5" caption="今天的路線"></tour-step>
  <tour-step to="#p-sent" move="1.4" hold="3.6" dim drift>
    <fx-mark target="#chunk" color="key" at="0.4"></fx-mark>
    <fx-arrow target="#chunk" from="right" color="pink" at="1.3">真主詞</fx-arrow>
  </tour-step>
  <tour-step to="#st-noun" zoom="3.2" rotate="-3" hold="4.2">     ← route-map 的車站 id
    <fx-hover target="#st-noun" at="1.8"></fx-hover>              ← 站名放大
  </tour-step>
</page-tour>

特效清單

寫法屬性預設說明
<fx-ring>target、coloryellow目標外圍的脈衝光圈，步驟結束時消失。
<fx-arrow>文字</fx-arrow>target、from、color、lengthtop-left、yellow、170大箭頭從八個方向之一（top、bottom、left、right、top-left、top-right、bottom-left、bottom-right）指向目標並來回跳動；內文是尾端標籤。
<fx-mark>target、coloryellow螢光筆由左到右刷上底色，保留到結尾。
<fx-line>from、to、from-side、to-side、color、width、duration自動、key、4、1.2兩個元素之間畫出帶箭頭的曲線，保留到結尾；線條粗細與箭頭大小不隨縮放改變。
<fx-count>target、from、to、decimals、duration0、0、0、1.2數字滾動到指定值。
<fx-hover>target無模擬滑鼠懸停：route-map 的車站會放大站名；其他元素會收到 mouseenter 並加上 tour-hover class。步驟結束時還原。
<fx-cursor>target、click、hover、duration0.9模擬游標移到目標；寫 click 會真的點下去，寫 hover 會觸發懸停。
<fx-note>文字</fx-note>target、coloryellow目標下方彈出一張歪斜的便利貼。
<fx-shake>target無目標左右搖一下。
<fx-punch>strength0.07鏡頭瞬間推近再彈回。
<fx-confetti>target、count全畫面、260寫 target 從目標位置噴出彩帶；不寫就從上方與兩側灑滿畫面。
所有特效的 at秒0鏡頭到達後第幾秒觸發，受暫停與速度影響。

屬性總覽

<page-tour>

屬性值預設說明
world-wpx1600畫布寬度，建議和教材頁面實際寬度一致；高度依內容決定。
aspect比例16/9播放器比例。全螢幕時填滿螢幕。
countdown秒3按下開始後倒數，方便按下錄影。
autoplay布林關不顯示開始畫面，直接播放；同時寫 countdown 才會倒數。
start步驟索引0從第幾步開始（從 0 算），前面步驟留下的效果會先補上。
loop布林關播完自動重播。
clean布林關一開始就隱藏控制列與進度條。
dots布林關畫布加上點狀網格背景。
background、caption-color、hud-color顏色base、key、key背景、字幕框、控制列的顏色。
keyboardfalse開寫 false 關閉鍵盤控制。
start-title、start-button、start-text文字鏡頭漫遊、開始播放、自動說明開始畫面的文字。

<tour-world>、<tour-panel>

標籤值預設說明
<tour-world>無無包住原本的教材 HTML。推薦一定要寫：內容完全不會被移動，頁面上的其他元件不受影響。沒寫的話，page-tour 會自己建立並把內容搬進去。
<tour-panel x y w h>px無寫了 x 的 tour-panel 會以畫布左上角為原點自由擺放；h 可以省略。沒寫 x 的 tour-panel 就是一般區塊。

<tour-step>

屬性值預設說明
to#id、多個用逗號、overviewoverview鏡頭目標；多個目標時一起入鏡；overview 是全景。
zoom倍數自動以全景為 1 倍。沒寫時自動縮放到目標剛好入鏡。
at「x,y」無不指定元素，直接把鏡頭對準畫布座標（搭配 zoom，預設 2）。
move、hold秒1.4、2.5移動時間、到達後停留時間。
via#id，逗號分隔無依序經過這些點再到目標。
rotate度0鏡頭傾斜；下一步沒寫就回正。
dim布林關聚光：目標以外的區塊與之前的連線一起壓暗（用亮度濾鏡，不用透明度）。
drift布林關停留期間鏡頭緩慢推近。
caption文字無畫面下方的字幕條。

方法與事件

項目說明
方法play()、pause()、toggle()、next()、prev()、restart()、jump(i)；唯讀 index、total。
事件page-tour:ready、page-tour:start、page-tour:step（detail：index、total）、page-tour:done，都會冒泡。
跳步清掉特效，螢光筆與數字還原，再把前面各步會留下來的效果瞬間補上。頁面上被模擬點擊改變的內容不會還原，同一個點擊也不會重複觸發；要完全重來請重新整理頁面。
