後端架構
採用 Node.js + Fastify，搭配 Redis 快取層，API 平均回應時間低於 50ms。水平擴展透過 Kubernetes 自動完成，峰值流量下無需人工介入。
前端設計
React 18 + Vite 建構，採用 CSS Modules 避免樣式污染。Lighthouse 效能分數達 98，Core Web Vitals 全綠。
資料庫策略
PostgreSQL 主從架構，搭配 TimescaleDB 處理時序資料。每秒可寫入 200,000 筆記錄，讀取查詢 P99 延遲 8ms 以內。

API 速查
屬性 / 設定 位置 說明
mode="icon" <ui-list> 啟用 icon 模式，以 Bootstrap Icons 取代左側數字欄位。
icon="..." <list-item> Bootstrap Icons 圖示名稱，例如 star-fill、cpu-fill。未設定此屬性時，即使在 icon mode 下也退回顯示數字。
iconFontSize NumericList.setup() 全域調整圖示大小，預設 2.25rem。例如 NumericList.setup({ iconFontSize: '2rem' })。
accent="..." <list-item> 圖示顏色，與數字模式相同，支援品牌色名稱或任意 CSS 色值。
theme-color="..." <ui-list> 整個清單的統一圖示顏色，優先序低於 accent。
其餘屬性 hover、active、gap、width、source、target 行為與數字模式完全相同。
