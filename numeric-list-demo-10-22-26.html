C-2  屬性說明
屬性 位置 說明
mode="fab" <ui-list> 啟用固定定位垂直工具列；<ui-list> 本身成為 fixed 容器，不佔文件流。
position="right|left" <ui-list> 貼靠螢幕右側（預設）或左側。左右兩組可同時存在。
bottom="..." <ui-list> 距螢幕底部距離，預設 120px。可任意 CSS 長度值。
offset="..." <ui-list> 距螢幕邊緣距離，預設 16px。
icon="..." <list-item> Bootstrap Icons 名稱，顯示為按鈕圖示。
label="..." <list-item> 圖示下方的短文字（如 TOP）。可選，不設定則純圖示。
href="..." <list-item> 以 # 開頭 → JS smooth scroll 捲動至錨點（#top 或 # 捲到頂部）。
外部 URL → <a> 連結，搭配 link-target。
link-target="..." <list-item> 外連結的 target 屬性（如 _blank）。與 source/target 機制不衝突。
accent="..." <list-item> 該按鈕的圖示顏色與 hover 顏色，支援品牌色名稱或任意 CSS 色值。
setup() 設定項 fabSize（按鈕大小，預設 52px）、fabIconSize（1.4rem）、fabLabelSize（0.6rem）、fabBg（#0d1b24）、fabBorderRadius（8px）、fabOffset（16px）、fabBottom（120px）
