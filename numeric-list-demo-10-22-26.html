E  ·  API 速查

本次新增屬性與設定項。

屬性 / 設定 位置 說明
mode="icon" <ui-list> 啟用 icon 模式，以 Bootstrap Icons 取代左側數字欄位。
icon="..." <list-item> Bootstrap Icons 名稱，例如 star-fill。未設定時即使在 icon mode 下也退回顯示數字。
cols="N" <ui-list> N ≥ 2 時切換為 CSS Grid N 欄佈局；cols="1" 或不設定則維持預設直欄 flex 模式。
last-span <ui-list> 布林屬性。Grid 模式下，最後一個 <list-item> 橫跨整列（grid-column: 1 / -1）。偶數項目無視覺效果但無副作用。
iconFontSize NumericList.setup() 全域調整圖示大小，預設 2.25rem。
gridNumberMinWidth NumericList.setup() Grid 模式下數字欄最小寬度，預設 60px（last-span 項目自動恢復至 numberMinWidth）。
其餘屬性 accent、theme-color、hover、active、gap、width、source、target 行為與直欄模式完全相同，可與 icon / cols 自由組合。
