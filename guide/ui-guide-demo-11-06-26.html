ui-guide：指引框

建立日期 11-06-26。框住頁面上任何有 id 的元素，左側放號碼方塊，用水平、垂直的自動折線連到另一個元素。說明卡支援 HTML、角標與可設定分隔線的頁尾。顯示由你自己放的按鈕控制：加上 guide-for 就是控制鈕。
第二次修改：多條線進入同一目標時終點自動分開；同方向的線自動錯開；文字重排時自動重算；新增適合密集文字的 num-pos="badge" 小圓號碼。範例 4 到 7 用不同文字密度測試折線位置。
第三次修改：新增 card-reveal，說明卡要按下才顯示，有 click、button、step 三種；說明卡隱藏時框的右上角有閃動的「?」提示；新增 cards-show、cards-hide、cards-toggle 三個控制動作。見範例 8。

屬性一覽

屬性寫在哪裡值說明
mode<ui-guide>all、stepall：一次全部顯示或隱藏。step：一次多一個。
open<ui-guide>布林載入時就全部顯示。
stagger<ui-guide>毫秒全部顯示時，每個框之間的間隔，做出依序出現的效果。
draw-speed<ui-guide>毫秒線畫出來的時間，預設 600。no-animation 關閉動畫。
loop<ui-guide>布林逐步模式到最後一個後，再按「下一個」全部收起。
num<guide-mark>文字或 HTML號碼方塊的內容，預設依序 1、2、3。
target<guide-mark>元素 id要框起來的元素，任何有 id 的元素都可以。
to<guide-mark>元素 id線要連到的元素；不寫就只有框，沒有線。
exit、enter<guide-mark>left、right、top、bottom線從框的哪一邊出去、從目標的哪一邊進來。不寫時依位置自動判斷。
lane<guide-mark>整數錯開距離，每加 1 多離開 14px。不寫時，同一個出口方向的線依序自動錯開。
內容、source<guide-mark>HTML、元素 id說明卡的內容，可以直接寫在標籤裡，或從 template 讀取。
badge、badge-color<guide-mark>文字、色名說明卡右上角的角標。
footer<guide-mark>HTML說明卡頁尾。
divider、divider-color兩者皆可solid、dashed、dotted、none；色名頁尾上方分隔線的樣式與顏色。
label-pos兩者皆可bottom、top、left、right說明卡放在框的哪一邊，預設 bottom。
num-pos兩者皆可left、right、badge、none號碼方塊在框的左側、右側；badge 是框左上角的小圓號碼，適合框住段落裡的字；none 不顯示。
color兩者皆可色名或色碼框、號碼方塊、線與圓點的顏色，預設 shell。bg-alternative 的號碼自動用白字。
line-width、line-style兩者皆可px；solid、dashed框與線的粗細、線的樣式。
pad、gap、tab-width、radius、dot-size、card-width兩者皆可px框與目標的間距、線離開框的距離、號碼方塊寬度、圓角、圓點半徑、說明卡寬度。
card-reveal兩者皆可click、button、step說明卡按下才顯示。click：點號碼方塊或「?」提示。button：說明卡的位置先放一顆小按鈕。step：逐步模式中，按「下一個」先出現框，再按一次才出現說明卡。不寫就跟著框一起出現。
card-button-label兩者皆可HTMLbutton 模式小按鈕的文字，預設「看解說」。
guide-for任何按鈕ui-guide 的 id讓這個元素成為控制鈕。
guide-action任何按鈕toggle、show、hide、next、prev、reset、cards-show、cards-hide、cards-toggle按下時的動作。cards-* 只控制已顯示的框的說明卡。預設：all 模式為 toggle，step 模式為 next。
guide-label-open、guide-label-closed任何按鈕HTML有框顯示中與全部隱藏時，按鈕各自顯示的文字。
