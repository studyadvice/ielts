ui-network 元件展示

透過 <ui-network> 與 <ui-node> 語意標籤宣告 Bootstrap Icons 名稱與圓圈尺寸，元件自動隨機排列並以三角網格繪製連線。目前版本 v1.2.0，建立日期 11-07-26。

範例一：仿原圖網路圖（含書籤與外部連結）

地圖、手把、調色盤三顆圓圈跳到本頁下方書籤；書本圓圈另開 Bootstrap Icons 官網。滑鼠移入圓圈時，相連的線條會亮起。

兩者使用相同種子與節點。左側 padding 為 16 且密度 dense，右側 padding 為 64 且密度 sparse，比例皆為 4:3。

範例三：漂浮動畫與自訂配色

開啟 float 後圓圈緩慢漂移，線條同步跟隨。背景、線條、圓圈底色都改用色票名稱指定，節點未設定 color 時自動輪替。

範例四：錯誤提示（Bootstrap alert）

不存在的圖示名稱、色票外的顏色、無法辨識的尺寸，會在元件上方以提示訊息顯示。點擊旗子圓圈會因找不到書籤而再出現一則提示。

HTML

範例五：node-click 事件與攔截

每次點擊都會觸發 node-click 事件。鎖頭圓圈設有 data-lock，監聽器呼叫 preventDefault() 後，原本的書籤跳轉就不會執行。

HTML

JavaScript

const net = document.getElementById('net-event');
net.addEventListener('node-click', e => {
  const { index, icon, href, node } = e.detail;
  if (node.dataset.lock !== undefined) {
    e.preventDefault();          // 取消跳轉
    log(`已攔截 #${index} ${icon}`, 'stop');
    return;
  }
  log(`點擊 #${index} ${icon} ${href ?? ''}`, 'hit');
});

所有顏色屬性除了色票名稱，也接受 #RGB、#RRGGBB、#RRGGBBAA、rgb() 與 rgba()。這裡用白色圓圈與約 85% 透明度的白線重現原圖風格；圖示顏色混用色票名稱、色碼與 rgb() 寫法。

範例七：色碼錯誤與透明度下限v1.1.0 新增

格式錯誤的色碼與 CSS 具名顏色（例如 white）會提示並改用預設色。透明度低於 0.78 時提示並自動調整為 0.78。

HTML

範例八：random-black 隨機彩色圖示v1.2.0 新增

加上 random-black 後，所有圖示改用依種子產生的隨機顏色，圓圈一律為黑色底。節點上的 color、fill 與容器的 node-fill 都不會生效，例如第一顆圓圈雖然寫了 fill="#FFFFFF"，仍維持黑色底。按下按鈕可重新隨機版面與配色。

HTML

更新紀錄

v1.2.0：新增 random-black 屬性

容器加上 random-black 後，圖示顏色依種子隨機產生，圓圈固定為黑色底（色票 background #0C0D0C），不受任何 fill、node-fill、color 設定影響。

v1.1.0：每顆圓圈需逐一指定顏色

<ui-network node-fill="#0C0D0C">
  <ui-node icon="map-fill" color="green"></ui-node>
  <ui-node icon="controller" color="pink"></ui-node>
  <ui-node icon="tv-fill" color="#5DBAE8"></ui-node>
</ui-network>

v1.2.0：一個屬性完成隨機彩色加黑底

<ui-network random-black>
  <ui-node icon="map-fill"></ui-node>
  <ui-node icon="controller"></ui-node>
  <ui-node icon="tv-fill"></ui-node>
</ui-network>

v1.1.0：開放自訂色碼

所有顏色屬性（color、fill、node-fill、bg-from、bg-to、line-color、line-active）都可直接填色碼。未設定時的預設色與自動輪替色維持不變。

v1.0.0：只接受色票名稱，色碼會被視為錯誤

<ui-network node-fill="vanilla" line-color="shell">
  <ui-node icon="map-fill" color="green"></ui-node>
  <!-- 下列寫法會提示「色票中沒有」並改用預設色 -->
  <ui-node icon="tv-fill" color="#B484E8"></ui-node>
</ui-network>

v1.1.0：色票名稱與色碼皆可

<ui-network node-fill="#FFFFFF" line-color="#FFFFFFD9">
  <ui-node icon="map-fill" color="green"></ui-node>
  <ui-node icon="tv-fill" color="#B484E8"></ui-node>
  <ui-node icon="book-half" color="rgb(255 85 48)"></ui-node>
</ui-network>

v1.0.0：線條透明度固定

stroke: var(--un-line);
stroke-opacity: 0.8;   /* 無法調整 */

v1.1.0：line-color 帶透明度時以該值為準

line-color="shell"        → 透明度 0.8（預設）
line-color="#FFFFFF"      → 透明度 0.8（預設）
line-color="#FFFFFFD9"    → 透明度約 0.85
line-color="#FFFFFF80"    → 0.5 低於下限，調整為 0.78

屬性與 API 參考

<ui-network> 屬性

屬性預設值說明
padding40圓圈可擺放區域的內距，單位 px，寫法比照 CSS 的 1 到 4 個數值。線條仍會延伸到整個畫布邊緣。
seed每次載入隨機亂數種子，可為數字或文字。相同種子與相同節點會得到相同版面。
densitynormal連線密度：sparse、normal、dense。
height無固定高度，單位 px。設定後會忽略 ratio。
ratio16:9未設定 height 時，依寬度維持此比例。
fixed-size未啟用布林屬性。啟用後圓圈尺寸不隨容器寬度縮放，也不自動縮小以避免重疊。
bg-from、bg-toblue、bg-alternative背景放射漸層的中心色與外圍色。
line-colorshell線條顏色。未指定透明度時為 0.8，以 #RRGGBBAA 或 rgba() 指定時以該值為準。
line-activekey滑鼠移入圓圈時，相連線條與圓圈外框的顏色。
line-width1.5線條粗細，單位 px。
node-fillvanilla所有圓圈的底色。
float未啟用布林屬性，啟用圓圈漂浮動畫。
animateon設為 off 時，載入與重新隨機不播放線條描繪與圓圈彈出動畫。
random-black未啟用布林屬性。圖示顏色依種子隨機產生，圓圈固定為黑色底，忽略 color、fill、node-fill。

<ui-node> 屬性

屬性預設值說明
iconcircleBootstrap Icons 名稱，可省略 bi- 前綴。
sizemdxs (72)、sm (96)、md (120)、lg (150)、xl (210)，或直接寫直徑數字。數值以 1280px 寬為基準自動縮放。
color自動輪替圖示顏色。
fill繼承 node-fill單一圓圈的底色。
href無以 # 開頭時平滑捲動到同頁書籤，其他網址則正常跳頁。
target無搭配 href 使用，例如 _blank 另開分頁。
title無滑鼠停留時的提示文字。

方法與事件

名稱類型說明
shuffle(seed?)方法重新隨機排列並播放動畫，可傳入種子，回傳實際使用的種子。
refresh()方法以目前種子重新建構。
currentSeed唯讀屬性目前使用中的種子。
node-click事件detail 含 index、node、icon、href，可呼叫 preventDefault() 取消跳轉。
network-render事件每次重繪後觸發，detail 含 seed、nodes、edges。

顏色格式

格式範例說明
色票名稱key見下方色票清單。名稱優先，因此 red、blue 等代表色票色，不是 CSS 具名顏色。
#RGB、#RRGGBB#FFF、#FFFFFF不透明色碼，大小寫不拘。
#RGBA、#RRGGBBAA#FFFFFFD9帶透明度的色碼。
rgb()、rgba()rgba(255, 255, 255, 0.9)支援逗號與空白兩種寫法，例如 rgb(255 255 255 / 0.9)。

任何顏色的透明度都不得低於 0.78，低於時會提示並自動調整為 0.78。CSS 具名顏色（例如 white、black）不支援。
