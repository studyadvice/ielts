使用說明

點擊左側「展開面板」區域的項目，可切換此內容區域的顯示狀態。
使用 target="#id" 屬性設定目標；animate="fade" 加入淡入淡出效果。

佈景設定

這個面板由左側「佈景設定」控制。再點一次即可收起。
item 的 active 狀態與目標面板的顯示同步：開啟 = active，收起 = 非 active。

快捷清單 A：同一個 target 屬性可以控制多個元素（逗號分隔 CSS 選擇器）。
快捷清單 B：這兩個面板同時被「快捷清單」這個 menu-item 控制。

JS API

// 取得 side-menu 元素
const menu = document.querySelector('side-menu');

// 切換主題
menu.setTheme('light');

// 監聽選取事件
menu.addEventListener('menu-select', e => {
  const { title, section, col, icon } = e.detail;
});

// 監聽主題切換
menu.addEventListener('theme-change', e => {
  console.log(e.detail.theme);
});

// 全域預設值

<menu-item> 屬性

屬性預設說明
title 必填主標題
icon — Bootstrap Icon class
subtitle — 副標題（單欄推薦）
target — 切換目標的 CSS 選擇器，逗號分隔可多個
toggle-mode displaydisplay / class
toggle-classis-hiddenclass 模式使用的 class 名稱
animate — fade：淡入淡出（display 模式）
