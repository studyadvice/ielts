ui-btn 基本功能

展開/收合目標元素的控制按鈕，支援三種外觀、三種尺寸與群組行為

<ui-btn>
外觀變體 variant="fill" variant="outline" variant="ghost"

三種視覺樣式：fill（填色，預設）、outline（外框）、ghost（透明），點按後展開緊鄰的下方元素。

fill — 展開內容
fill：主色填滿背景，文字用深色。視覺最強烈，適合主要 CTA。
outline — 展開內容
outline：透明背景＋主色外框，懸停時填入淡色背景。適合次要操作。
ghost — 展開內容
ghost：完全透明，只顯示主色文字，懸停填入極淡背景。最低調。
尺寸 size="sm" size="md" size="lg"

三種預設尺寸：sm（0.85rem）、md（1rem，預設）、lg（1.1rem），同時調整內距與圓角。

小 sm
size="sm"：字 0.85rem / padding 5px 12px / border-radius 20px。適合工具列。
中 md（預設）
size="md"：字 1rem / padding 8px 16px / border-radius 24px。一般行內使用。
大 lg
size="lg"：字 1.1rem / padding 10px 20px / border-radius 28px。頁面主要 CTA。
圖示與箭頭 icon="bi-*" icon-active="bi-*" chevron

icon 接受 Bootstrap Icons 類別名；icon-active 在展開時切換圖示；chevron 加入可旋轉箭頭。無文字 label 時按鈕呈圓形，右下角出現狀態小點。

純圖示（icon only）
icon only：沒有文字 label，按鈕呈圓形，展開後右下角顯示狀態點。
圖示 + 文字 開啟資料夾
圖示在文字左側，尺寸與文字相稱。
icon-active 切換 播放
展開時圖示換為 bi-stop-fill；再次點擊收合，圖示恢復 bi-play-fill。
chevron 箭頭 展開詳情
chevron 布林屬性：標籤右側加入 SVG 箭頭，展開時自動旋轉 180°。
全組合示例 顯示說明
icon-active + label-open + chevron 同用：圖示切換、標籤切換、箭頭翻轉，三者同步。
標籤、提示與停用 label-open="..." tooltip="..." disabled open

label-open 展開時顯示替代文字；tooltip 設置原生 title；disabled 停用；open 初始展開。

展開所有項目 ▼
label-open：展開後標籤切換為「收起所有項目 ▲」，再點恢復原始文字。
懸停查看 tooltip
tooltip 屬性設置 button 的 title，於懸停時顯示原生提示。
停用按鈕（disabled） disabled：50% 透明度，pointer-events:none，無法點擊。
展開說明
open 屬性：頁面載入後此區塊已展開，按鈕初始呈「已開啟」狀態（chevron 已翻轉、label 顯示 label-open 文字）。
群組手風琴 group="name"

同一 group 值的按鈕形成互斥群組：展開任一個時，其餘自動收合。group 值為任意字串。

第一節：海洋藍
group="demo-acc" — 展開此節時，其他三節自動收合。每個按鈕可指定不同 theme。
第二節：薰衣草
group="demo-acc" — 第二節內容。互斥邏輯確保同時只有一節展開。
第三節：特別色
group="demo-acc" — 第三節內容。展開後，其餘節以 animClose 收合。
第四節：鮭魚色
group="demo-acc" — 第四節內容。可任意加入更多群組成員。
動畫類型與時長 animation="slide" animation="fade" animation="none" anim-duration="ms"

slide（預設）：高度＋透明度同時動畫；fade：只做透明度；none：即時顯示/隱藏。anim-duration 控制毫秒數（預設 320）。

Slide（預設）
animation="slide"：max-height + opacity 雙動畫，最自然的展開效果。
Slide 800ms
anim-duration="800"：展開動畫延長為 800ms，可明顯感受速差。
Fade
animation="fade"：只做 opacity 淡入淡出，元素高度無動畫。
Fade 600ms
anim-duration 同樣適用於 fade 模式。
None（無動畫）
animation="none"：立即 display:block / display:none，無任何 transition。

遠端目標 target="#elementId"

預設按鈕控制緊鄰的下一個兄弟元素。設定 target="#id" 可控制頁面任意位置的元素（兩個按鈕可指向同一目標）。

控制 #rmt-a 控制 #rmt-b 再控制 #rmt-a

這是 #rmt-b，由第二個按鈕透過 target 屬性控制。可與 #rmt-a 同時展開。
捲動閘門（視覺模擬） scroll-gate

scroll-gate 讓按鈕扮演「解鎖繼續閱讀」的角色：目標元素半透明鎖定，按鈕帶脈衝光暈（.ubtn-gate-cue），按下後 .ubtn-gate-locked 移除，頁面恢復可捲動。以下為視覺模擬，展示鎖定→解鎖全流程。

目標內容（.ubtn-gate-target）：鎖定時 opacity 0.45，pointer-events:none。
點擊按鈕後移除 .ubtn-gate-locked，內容完整可見，捲動恢復。
再次點擊可重新鎖定，示範雙向切換。
真實使用：<ui-btn scroll-gate theme="indigo">解鎖</ui-btn> — 組件會在 window 層級綁定 wheel / touchmove / keydown 事件，防止使用者捲過按鈕位置。
解鎖 Chunk unlock-chunk="demoId:chunkIdx, ..."

按鈕展開時呼叫目標元素的 .unlockChunk(idx)；收合時呼叫 .lockChunk(idx)。多組以逗號分隔。目標元素需自行實作這兩個方法（通常由 chunk-demo.js 提供，此演示在頁面中自訂實作）。

解鎖 Chunk 0
unlock-chunk="uc-box:0"：展開時呼叫 document.getElementById("uc-box").unlockChunk(0)
解鎖 Chunk 1
unlock-chunk="uc-box:1"：同樣方式解鎖第二個 slot。
解鎖 Chunk 2
unlock-chunk="uc-box:2"：解鎖第三個 slot。
一次解鎖全部
unlock-chunk="uc-box:0,uc-box:1,uc-box:2"：逗號分隔，一次解鎖多個 chunk。

text-morph 文字切換

在原始版本與升級版本之間淡入淡出，帶主題色狀態標章

<text-morph>
基本切換 theme="sky" duration="400" label-from="..." label-to="..."

點擊標章在兩個版本間切換。已升級顯示綠色（safe），可再切換顯示原始主題色。morph-from / morph-to 內可包含任意 HTML。

read-pulse 閱讀進度條

段落左側彩色條動畫，可由進入可視區、點擊或懸停觸發

<read-pulse>
觸發模式 trigger="visible" trigger="click" trigger="hover" repeat

visible：進入可視區自動觸發（預設）。click：點擊觸發。hover：移入觸發。加 repeat 屬性可重複播放。

trigger="visible"（預設）：此段落進入可視區域後自動播放一次進度條。速度 2800ms，預設不可重複。 trigger="click" + repeat：點擊此段落觸發動畫。加 repeat 屬性，每次點擊均可重新播放。 trigger="hover"：滑鼠移入此段落即觸發動畫（無 repeat，離開後再移入不會再次觸發）。 trigger="click" + repeat + speed="4500"：點擊觸發，速度 4.5 秒，適合配合長段落閱讀節奏。
進度條寬度與間距 pulse-width="5px" gap="22px" speed="1200"
pulse-width="5px" / speed="1200" / gap="20px"：點擊觸發。1.2 秒快速掃過，進度條粗（5px），文字與條之間距 20px。 pulse-width="2px" / gap="10px"：細條（2px），緊湊間距，視覺更低調。
