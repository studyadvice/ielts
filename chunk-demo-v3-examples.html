chunk-demo v3 — 新屬性範例

show-dots · width / dropdown-width / button-width · level-colors · mask-mode

新屬性 1

show-dots — 圓點顯示開關

預設 show-dots="true"（顯示圓點）。 設為 false 時，下拉選單內的彩色圓點元素直接不渲染，版面更簡潔。

show-dots="true"（預設）

went hurried rushed excitedly yesterday early in the morning

show-dots="false"

went hurried rushed excitedly yesterday early in the morning 
<chunk-demo
  sentence="She {0} to the market {1}."
  show-dots="false"
  theme="sky"
>
  <cd-chunk id="0" label="動詞">
    <cd-level level="1">went</cd-level>
    <cd-level level="2">hurried</cd-level>
  </cd-chunk>
  ...
</chunk-demo>

// 或用 data-config：
data-config='{"showDots": false}'
新屬性 2

width / dropdown-width / button-width

width 控制整個元件寬度； dropdown-width 固定下拉選單寬度（同時覆蓋 min/max-width）； button-width 設定語塊按鈕的最小寬度，讓多個按鈕對齊。 三者均接受任意 CSS 寬度字串（px / % / rem 皆可）。

Listening Active listening with note-taking Comprehensive input processing adult intermediate-level adult highly motivated adult 
<chunk-demo
  sentence="{0} is a key skill for {1} learners."
  width="100%"
  dropdown-width="300px"
  button-width="160px"
  theme="focus"
>...</chunk-demo>

// 或用 data-config：
data-config='{"width":"100%","dropdownWidth":"300px","buttonWidth":"160px"}'
新屬性 3

level-colors — 簡化色彩設定

逗號分隔，依序對應 Level 1, 2, 3（及更多）的圓點與選取左側線條顏色。 比 data-config 的 JSON 更簡潔，且可被 data-config.levelDotColors 覆蓋用於精細調整。

level-colors="#F08080, #b3de73, #95c9de"（紅 / 黃綠 / 天藍）

do carefully complete diligently and thoroughly complete almost without fail with great consistency 
<chunk-demo
  sentence="I {0} my homework {1} every day."
  level-colors="#F08080, #b3de73, #95c9de"
  theme="lavender"
  show-preview="true"
>...</chunk-demo>

// 等效的 data-config 寫法（可混用，屬性優先）：
data-config='{"levelDotColors":{"1":"#F08080","2":"#b3de73","3":"#95c9de"}}'
新屬性 4

mask-mode — 遮罩填空模式

開啟後，所有語塊按鈕初始顯示深色遮罩（文字存在於 DOM 但視覺隱藏）。 使用者點擊展開下拉選單並選取任一 Level 後，該語塊即揭露真實內容。 適合做成「先思考再確認」的互動填空練習。 遮罩色可透過 data-config 的 maskColor 自訂。

mask-mode="true"　　點擊各語塊，選取 Level 後揭露內容 ↓

acquisition natural acquisition subconscious natural acquisition depends heavily depends critically and heavily relies consistent consistent daily focused and consistent daily 
<chunk-demo
  sentence="The {0} of a language {1} on {2} practice."
  mask-mode="true"
  theme="safe"
  show-preview="true"
  button-width="130px"
>
  <cd-chunk id="0" label="主語">
    <cd-level level="1">acquisition</cd-level>
    <cd-level level="2">natural acquisition</cd-level>
    <cd-level level="3">subconscious natural acquisition</cd-level>
  </cd-chunk>
  <!-- 其餘 cd-chunk... -->
</chunk-demo>

// 自訂遮罩顏色（透過 data-config）：
data-config='{"maskMode":true,"maskColor":"#1a1b1a"}'
組合範例

全部屬性組合使用

mask-mode + show-dots="false" + level-colors + button-width + dropdown-width 同時套用。

revise carefully revise and edit meticulously revise, edit, and proofread before well before at least one day before 
<chunk-demo
  sentence="Students should {0} their essays {1} submitting them."
  mask-mode="true"
  show-dots="false"
  level-colors="#EDA109, #299459, #C3A5E5"
  button-width="180px"
  dropdown-width="280px"
  width="100%"
  theme="orange"
  show-preview="true"
  data-config='{"maskColor":"#1e1f1e"}'
>...</chunk-demo>
