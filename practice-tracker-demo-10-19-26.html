新增開放屬性一覽

data-* 屬性 JS config key 預設值 說明
data-font-size-panel fontSizePanel 0.85rem 面板整體基礎字體大小（其餘字體繼承於此）
data-font-size-title fontSizeTitle 0.78rem 標題列「進度」文字大小
data-font-size-count fontSizeCount 0.76rem 格子下方進度計數「N / Total 完成」
data-font-size-complete fontSizeComplete 0.80rem 全部完成時顯示的主訊息
data-font-size-complete-sub fontSizeCompleteSub 0.73rem 全部完成時的副訊息（completeSubText）
data-cell-size cellSize 16px 每個完成方塊的寬高（正方形）
data-cell-gap cellGap 6px 方塊與方塊之間的間距
data-cell-radius cellRadius 4px 方塊圓角半徑（已存在，一併列出）
data-cells-per-row cellsPerRow 5 每排顯示幾個方塊（已存在，一併列出）

範例 A　預設尺寸（方塊 16px，間距 6px）

<practice-tracker data-inline data-prefix="ex-a-" data-title="預設進度" data-complete-text="全部完成！" data-complete-sub="繼續保持" data-watch-stepper="false"> </practice-tracker>

範例 C　放大字體（各部位字體獨立設定）

Live Demo

範例 D　透過 window.PracticeTrackerConfig 設定

JS 全域設定（適合整站統一調整）
window.PracticeTrackerConfig = { cellSize: '20px', cellGap: '8px', cellRadius: '6px', fontSizePanel: '0.9rem', fontSizeTitle: '0.85rem', fontSizeCount: '0.82rem', fontSizeComplete: '0.88rem', fontSizeCompleteSub: '0.78rem', };

data-* 屬性的優先序高於 window.PracticeTrackerConfig，可針對個別 tracker 做覆蓋。
