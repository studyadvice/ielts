ui-toast

浮動提示訊息。任何元素加上 toast 屬性，點擊就跳出提示，不必寫 JavaScript。提示放在瀏覽器的最上層，所以 <dialog> 開著時也看得到。

1. 最簡單的用法

原生按鈕、連結、文字都可以。沒有指定外觀時，使用綠色實心、顯示在畫面上方中間、3 秒後消失。滑鼠停在提示上會暫停倒數，點提示可以立刻關掉。

連結 
<button toast="已儲存">儲存</button>

<button toast="已複製到剪貼簿" toast-icon="clipboard-check">
  複製
</button>

2. 外觀：顏色、樣式、位置、寬度、時間

toast-theme 可用色票名稱、色碼或任何 CSS 顏色；toast-variant 有 fill（實心，預設）、outline（外框）、square（長方形實心）與 square-border（長方形空心，只有上下 3px 邊框）；位置有六種。toast-duration="0" 不會自動消失，要自己關閉。

3. 訊息放在 <ui-toast>（可含 HTML）

訊息較長或要用粗體、連結時，寫在 <ui-toast> 裡，再用 toast-target 指向它的 id。<ui-toast> 本身不會顯示，外觀屬性寫在它上面；觸發元素的 toast-* 屬性優先。同一則訊息可以給多個按鈕共用。

練習完成，成績已經記錄。 小提醒：答案可以先寫關鍵字，再補成完整句子。 
<ui-toast id="t-done" theme="green" icon="check-circle-fill">
  <b>練習完成</b>，成績已經記錄。
</ui-toast>

<ui-toast id="t-tip" theme="yellow" variant="outline"
          icon="lightbulb" duration="6000">
  小提醒：答案可以<b>先寫關鍵字</b>，再補成完整句子。
</ui-toast>

<button toast-target="t-done">完成</button>
<button toast-target="t-done" toast-position="bottom">
  完成（改放下方）
</button>
<button toast-target="t-tip">提醒</button>

4. 在其他元件裡面使用

元件內容裡的原生按鈕、可點擊的小標籤都可以直接帶 toast，之後才產生或重繪的元素也一樣有效。即使元件自己攔截點擊事件（stopPropagation），提示仍會跳出。

ui-btn：寫在 <ui-btn> 上即可（取代原本的 alert 屬性）

送出 刪除 停用 
<ui-btn size="md" icon="bi-send-fill" theme="key"
        toast="已送出" toast-icon="check-lg">送出</ui-btn>

<ui-btn icon="bi-trash" theme="red" variant="outline"
        toast="已刪除" toast-theme="red"
        toast-position="bottom">刪除</ui-btn>

ui-cards：卡片內文、背面裡的按鈕與小標籤

意思 
<card-item label="resilient" note="內文裡的按鈕">
  <button toast="已標記為熟悉">我會了</button>
  <span class="chip" toast="有韌性的"
        toast-theme="yellow">意思</span>
</card-item>

<!-- 背面（back）裡面也可以 -->
<card-item label="mitigate"
  back="減輕、緩和
    <button toast='已加入收藏'>收藏</button>">
</card-item>

ui-table：儲存格裡的按鈕

Part 2 題目 Describe a skill you learned. 提示 先說是什麼技能 下一步 
<ui-col>
  Describe a skill you learned.
  <button toast="已複製題目"
          toast-icon="clipboard-check">複製</button>
</ui-col>

<ui-col>
  先說是什麼技能
  <span class="chip" toast="再說為什麼學、怎麼學"
        toast-theme="playful">下一步</span>
</ui-col>

目前只有 <ui-btn> 會自動把 toast 屬性帶到畫面上的按鈕。元件自己用屬性產生的 badge（例如 ui-cards 的 badge）還不能直接帶 toast，要用內容裡的標籤；之後可以逐一補上。

5. <dialog> 開著時

提示放在瀏覽器最上層，所以 showModal() 開啟的對話框不會蓋住它。注意：對話框開著時，對話框外的東西（包括提示的 ×）無法點擊，提示會照常倒數後自己消失。

對話框

在這裡按按鈕，提示會顯示在對話框上方。

 
<dialog id="dlg">
  <button toast="對話框內的提示">跳出提示</button>
</dialog>

<button onclick="dlg.showModal()">開啟對話框</button>

6. 屬性速覽

屬性預設說明
toast無寫在任何元素上。點擊時顯示這段文字（純文字）。
toast-target無指向 <ui-toast> 的 id，顯示它的內容（可含 HTML）。與 toast 同時寫時，以 toast-target 為準。
toast-themegreen色票名稱、色碼或 CSS 顏色。
toast-variantfillfill 實心、outline 外框、square 長方形實心、square-border 長方形空心（只有上下 3px 邊框）。
toast-positiontoptop、top-left、top-right、bottom、bottom-left、bottom-right。
toast-duration3000顯示毫秒數，0 表示不會自動消失。
toast-width自動固定寬度，只接受 px 或 %。
toast-icon無Bootstrap Icons 名稱，bi- 前綴可寫可不寫。

<ui-toast> 上的 theme、variant、position、duration、width、icon 是這則訊息的預設外觀。全頁預設值可以在載入 ui-toast.js 之前設定 window.UiToastConfig。
