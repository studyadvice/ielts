<ui-timeline> 圓點時間軸

每一項的上方小字是 sub-heading，元件最上方是 heading。圓點顏色來自主題，可以逐一出現或逐一點亮，最後的連結可以展開隱藏的 div 或 template。

1. 九套內建主題

arc、cool、warm 使用你的色票，顏色固定循環；ember、ocean、forest、dusk、aurora、mono 是我另外配的，會依項目數重新計算漸層，越上面越亮（aurora 是色相漸變）。

2. 逐一出現＋展開 template

play-mode="reveal"、autoplay="visible"：捲到畫面中才開始。全部出現後才顯示「查看全部紀錄」。template 裡放了一個 ui-play，第一次展開時才初始化，收合再展開會保留播放狀態。

ui-play 新增小畫家外框 稿紙外框改為深色 新增滑鼠點擊推進 next-by 劇本製作器 play-maker 上線 元件串接 link-when ui-fillin 合併示範檔 bp-stepper 推進模式 色名標籤全面統一 

  


  
  

    

      
3. 逐一點亮，循環播放

      
play-mode="highlight"、loop：目前那一項的圓點放大、文字變亮，其他項目變暗。變暗用不透明的混色，不使用透明度。sub-heading 不一定是時間，這裡當成步驟名稱。

4. 點一下才播放＋展開 div（一次性）

      
沒有 autoplay 時，點時間軸任何地方開始播放，適合錄影。more-target 指向頁面上的 div，元件載入時自動先隱藏；裡面的 ui-fillin 照常運作。more-mode="once" 展開後連結就消失。

5. 自訂顏色與單項顏色

      
dot-colors 用 | 分隔，不夠時循環；單一項目可用 color 覆寫。bg-color="none" 讓元件透明，融入頁面背景。

  改寫後重新提交

      

    

    

  


  
  

    

      
6. 圓點的替代形狀

      
dot-shape 設定整個元件的形狀。number 與 icon 會自動放大到 22px；number 預設顯示 1、2、3，可用 dot-text 改成任何字；icon 使用 Bootstrap Icons。

      

    

  


  
  

    

      
7. 數字形狀＋逐一點亮

      
dot-shape="number" 很適合步驟流程。dot-text 可以把單一項目改成英文字母或符號，shape 可以讓單一項目換形狀，例如最後一項換成星形。

8. 圖示形狀

      
dot-shape="icon" 搭配 dot-icon 設定全部項目的圖示，單一項目用 icon 覆寫。需要頁面載入 Bootstrap Icons。

屬性對照

      
<ui-timeline>：內容與主題

      

        
屬性說明預設值

        
heading元件最上方的標題，不寫就不顯示。無

        
themearc、cool、warm（你的色票，循環）；ember、ocean、forest、dusk、aurora、mono（依項目數計算漸層）。主題同時決定底色、連接線與文字色。arc

        
dot-colors自訂圓點顏色，以 | 分隔，可填色名或色碼，不夠時循環；設了就忽略主題的圓點色。無

        
bg-color line-color heading-color sub-color text-color more-color覆寫主題的底色、連接線、標題、sub-heading、內容文字、連結文字。bg-color="none" 為透明。依主題

        
dot-shapecircle、square、rounded、diamond、ring、ring-square、triangle、hexagon、star、number、icon。circle

        
dot-iconicon 形狀的預設圖示，Bootstrap Icons 類別名稱。bi-circle-fill

        
ring-width number-colorring 形狀的框線粗細（px）、number 形狀的數字顏色。3、同底色

        
dot-size dot-top gap圓點直徑、圓點距離項目頂端的位置、項目間距（px）。number 與 icon 形狀預設為 22 與 1。12、6、16

        
width padding radius寬度、內距（px，最多四個值）、圓角。100%、20 24、12

        
font-size heading-size內容字級、標題字級；純數字視為 rem。1、1.25

      

      
<ui-timeline>：播放

      

        
屬性說明預設值

        
play-modereveal（逐一出現）、highlight（逐一點亮）；不寫就是靜態顯示。無

        
autoplaytrue（載入就播）、visible（捲到畫面中才播）、false（點時間軸才播）。false

        
interval speed每一項之間的間隔、單一項目的動畫時間（ms）。800、400

        
effectfade、slide-up、slide-left、none；也用於展開內容。fade

        
loop只對 highlight 有效，播到最後一項再從頭開始。關閉

      

      
<ui-timeline>：查看全部

      

        
屬性說明預設值

        
more-target點擊後要顯示的 div 或 template（寫不寫 # 都可以）。沒設定就不顯示連結。div 會在載入時自動隱藏，展開時在原位置出現；template 第一次展開時才把內容放到元件正下方，裡面的元件此時才初始化。無

        
more-text less-text展開前、展開後的連結文字。查看全部紀錄、收合

        
more-arrow設為 false 不顯示 → 與 ↑ 箭頭。true

        
more-modetoggle（可收合，收合後再展開保留裡面元件的狀態）、once（展開後連結消失）。toggle

      

      
<tl-item>

      

        
屬性說明預設值

        
sub-heading項目上方的小字，可以是時間、步驟名稱或任何文字；不寫就不顯示。無

        
color單獨指定這一項的圓點顏色。依主題

        
shape單獨指定這一項的形狀，值同 dot-shape。同元件

        
dot-textnumber 形狀裡顯示的文字，例如 A、✓。項目順序

        
iconicon 形狀的圖示。同 dot-icon

      

      
內容可寫任何 HTML，支援 <c-key> 等色名標籤。

      
事件與方法

      

        
名稱說明

        
timeline-end播完時發出（loop 時不發出）。link-when 的 event="done" 會自動對應到這個事件。

        
timeline-more展開或收合時發出，detail.open 為 true 或 false。

        
el.play() el.stop() el.toggleMore(open)開始播放、停止並顯示全部、展開或收合。link-when 的 do="play" 可直接使用。
