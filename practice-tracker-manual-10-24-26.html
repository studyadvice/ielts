practice-tracker 使用手冊

涵蓋 practice-tracker.js 的全部屬性與功能，並搭配 phrase-chip.js。忘記怎麼用的時候，從目錄找到對應章節即可。

0. 這份手冊在講什麼

practice-tracker.js 是一個「學習進度面板」元件：自動把頁面上 id 帶有指定前綴的 section 變成一個個進度格子，使用者完成一段就點亮一格。它還附帶三個可選功能：內建的「標記完成」按鈕、片語收藏區塊（搭配 phrase-chip.js）、以及定時彈出的金色 Modal。

phrase-chip.js 是另一支獨立的檔案，提供兩個元件：<phrase-chip>（可點擊的片語標籤，彈出解釋卡並可收藏）與 <phrase-upgrade>（點擊後逐階段升級的動畫文字）。兩支檔案透過 pt:phrase-collected 事件溝通，彼此不直接相依。

項目內容
檔案practice-tracker.js、phrase-chip.js，兩者都是獨立 .js，不使用 shadow DOM，樣式由 js 自行注入。
必要相依無。只有進度格子與完成按鈕時，不需要任何其他函式庫。
選用相依Bootstrap 5 的 JS bundle：片語收藏清單（offcanvas）與定時 Modal 需要。Bootstrap Icons 的 CSS：phrase-chip 的圖示需要。
載入順序兩支檔案誰先載入都可以，也不必等 Bootstrap 先載入。Bootstrap 只在使用者點擊或 Modal 彈出的當下才會被呼叫。
本手冊對應版本2026-10-24 版，已包含定時 Modal 與內建標記完成按鈕。
提示：這份手冊的「設定鍵」欄，是給 window.PracticeTrackerConfig 用的駝峰命名；「HTML 屬性」欄是寫在標籤上的版本。兩者設定的是同一件事。

1. 快速開始

最小可用版本只需要三件事：幾個 id 帶前綴的 section、一個 <practice-tracker> 標籤、載入 js。

最小範例
<section id="ex-intro">...</section>
<section id="ex-part1">...</section>
<section id="ex-part2">...</section>

<practice-tracker data-prefix="ex-" data-click-go="true"></practice-tracker>

<script src="practice-tracker.js"></script>

載入後，畫面右下角會出現面板，裡面有 3 個格子。要點亮格子，必須有人呼叫「標記完成」，方式有四種，見第 4 節。最省事的是第 5 節的內建按鈕：

在 section 加一個屬性，就自動長出按鈕
<section id="ex-intro" data-btn-text="標記完成">...</section>

元件做了什麼（執行順序）

  1. 等到 DOMContentLoaded（若頁面已載入完成則立刻執行）。
  2. 讀取設定：預設值，被 window.PracticeTrackerConfig 覆蓋，再被 <practice-tracker> 上的屬性覆蓋。
  3. 用 section[id^="前綴"] 找出所有要追蹤的 section，依文件順序各建立一個格子。找不到任何一個時直接結束，什麼都不建立。
  4. 掃描頁面上的 phrase-chip[data-phrase]，若有可收藏的片語，建立片語收藏區塊與收藏清單。
  5. 清空 <practice-tracker> 原本的內容，重建標題列、格子、計數。
  6. 為帶有 data-btn* 屬性的 section（或內含 <pt-done-btn> 的 section）建立標記完成按鈕。
  7. 若設定了 data-promo-target，開始計時並監看 section 瀏覽。
  8. 建立 window.PracticeTracker，並開始監聽三種外部事件。
注意：頁面上有多個 <practice-tracker> 時，只有第一個會被使用。若頁面上完全沒有這個標籤，元件會自己建一個附到 body 底部，此時設定只能靠 window.PracticeTrackerConfig。

2. 設定的三個來源與優先順序

由低到高：內建預設值 小於 window.PracticeTrackerConfig 小於 標籤上的 data 屬性。同一個設定出現在多處時，優先順序高的贏。

全站預設 + 單頁覆蓋
<script>
  /* 必須在 practice-tracker.js 之前定義 */
  window.PracticeTrackerConfig = {
    prefix: 'ex-',
    cellShape: 'circle',
    btnStyle: 'pill'
  };
</script>
<script src="practice-tracker.js"></script>

<!-- 標籤上的屬性優先：這個頁面的格子會是 star，不是 circle -->
<practice-tracker data-cell-shape="star"></practice-tracker>

屬性值的解讀規則

型別規則範例
string原樣使用。data-title="第一課進度"
bool只有值恰好等於字串 false 才算 false，其餘一律算 true，包含沒有值的寫法。data-collapsed 為 true；data-collapsed="false" 為 false；data-collapsed="0" 仍為 true。
int用 parseInt 轉整數。data-cells-per-row="10"
float用 parseFloat 轉小數，用於定時 Modal 的時間與比例。data-promo-minutes="0.5"
說明：data-inline 是唯一不在設定表內的屬性，元件用 hasAttribute 直接判斷，不看值，所以也沒有對應的設定鍵。

4. 標記 section 完成的四種方式

格子只有一種點亮方式：呼叫內部的 markDone(sectionId)。它是冪等的，同一個 section 重複標記不會有任何作用，也不會重複發出事件。以下四種入口最終都會走到它。

方式寫法適合情境
內建按鈕section 加 data-btn-text 等屬性最省事，不必自己寫按鈕與函式。第 5 節詳述。
呼叫 APIPracticeTracker.markDone("ex-intro")自己的按鈕、測驗答對、影片播完等任何自訂時機。
自訂事件document.dispatchEvent(new CustomEvent("pt:stage-complete", {detail:{sectionId:"ex-intro"}}))元件之間鬆耦合，不想直接依賴 window.PracticeTracker 時。事件名稱可用 data-event-name 改。
bp-stepper自動，不需寫任何東西bp-stepper 完成時發出 bps:complete，tracker 找到該元件最近的、id 帶前綴的 section，標記它完成。可用 data-watch-stepper="false" 關閉。
舊式手寫按鈕的寫法（仍然可用）
function handleDone(sectionId, btn) {
  if (window.PracticeTracker) window.PracticeTracker.markDone(sectionId);
  btn.disabled = true;
}
注意：沒有任何符合前綴的 section 時，window.PracticeTracker 根本不會存在。呼叫前一定要先檢查，例如 if (window.PracticeTracker)，否則會丟出例外。
說明：只有透過內建按鈕完成時，section 才會被加上 is-done class。用 API、事件或 bp-stepper 完成時不會加。若你的樣式依賴這個 class，請注意這個差異。

5. 內建「標記完成」按鈕

讓元件替你長出按鈕，不必再手寫 <button> 與 handleDone。按下後行為與舊寫法一致：點亮格子、按鈕變成已完成並停用、section 加上 is-done。

5.1 按鈕什麼時候會出現

情況結果
section 上有任何以 data-btn 開頭的屬性（如 data-btn-text、data-btn-style、data-btn="true"）在 section 結尾自動插入一個按鈕。
section 內有手寫的 <pt-done-btn></pt-done-btn>按鈕出現在那個位置，不再另外插入。即使 section 沒有任何 data-btn* 屬性也會生效。
section 沒有任何標記，也沒有 <pt-done-btn>不插入按鈕。
section 上寫 data-btn="false"這個 section 完全不處理，也不插入。
<practice-tracker> 上寫 data-btn="false"整個功能關閉。
注意：寫在 <practice-tracker> 上的 data-btn-text 等屬性只是「全域預設值」，不會讓任何 section 長出按鈕。長不長按鈕，只看 section 自己有沒有標記。

5.2 七種樣式（data-btn-style）

樣式外觀備註
solid實心色塊，深色字
outline細邊框、透明底，滑過時填滿預設樣式。

ghost只有文字加底線，無邊框最低調。

split左邊色塊打勾圖示，右邊文字完成後文字會自動去掉開頭的「✓」，避免與圖示重複。

5.5 行為細節

  • 完成後按鈕固定變成綠色（#27AE60）並停用，不受 data-btn-color 影響。
  • 按鈕可用鍵盤操作：Tab 聚焦，Enter 或空白鍵觸發。
  • 從其他途徑（API、事件、bp-stepper）標記該 section 完成時，按鈕也會同步變成已完成狀態。
  • 元件內部不顯示任何提示訊息。想要提示，就監聽 pt:section-done，再用 Bootstrap alert 呈現。
  • 若同一個 section 同時有舊的手寫按鈕與內建按鈕，會出現兩顆。請移除舊的。
  • 你原有的手寫按鈕、bp-stepper 的 btn-js 完全不受影響，可以並存。
用 Bootstrap alert 顯示完成提示
document.addEventListener('pt:section-done', e => {
  const box = document.getElementById('alerts');
  box.insertAdjacentHTML('beforeend',
    '<div class="alert alert-success alert-dismissible fade show">' +
    '已標記完成：' + e.detail.sectionId +
    '<button type="button" class="btn-close" data-bs-dismiss="alert"></button></div>');
});

6. 片語收藏區塊（tracker 這一側）

只要頁面上有 <phrase-chip data-phrase="...">，面板就會自動多出一個「片語收藏」區塊：每個片語一個格子，收藏一個點亮一格，並提供「查看收藏清單」按鈕，打開側邊欄列出所有已收藏片語的例句與翻譯。頁面上沒有任何 phrase-chip 時，這個區塊完全不存在，面板與原本一模一樣。

6.1 哪些片語會被計入總數

  • 依 data-phrase 的內容去重：同一個片語在頁面出現多次，只算一格，收藏一次，所有出現處同步變色。
  • data-disable-collect（無值或值不是 false）的 chip 是「純字典模式」，不會觸發收藏。若某片語所有出現處都是純字典模式，它不計入總數；只要有一處可收藏，就照常計入。
  • 總數在 tracker 初始化的那一刻，依 HTML 標記決定，之後不再變動。
注意：用 JavaScript 在初始化之後才動態新增的 phrase-chip，不會有對應的格子。它被收藏時，tracker 會直接忽略。這類內容請在頁面載入前就寫進 HTML。

說明：收藏清單的側邊欄使用 Bootstrap 的 offcanvas，需要載入 Bootstrap JS bundle。它掛在 body 底下，不受面板收合影響，也不會被面板的 overflow 裁切。

7. phrase-chip.js：`<phrase-chip>` 片語標籤

在文章裡把一個片語做成可點擊的標籤。點擊後在標籤附近彈出解釋卡，卡片上有例句、中文翻譯，以及「收藏這個片語」按鈕。收藏後會發出事件，由 practice-tracker 接收並點亮格子、加入清單。

7.1 HTML 結構

<phrase-chip data-phrase="stick to" data-theme="ocean" data-icon="bookmark">
  stick to
  <phrase-card>
    <phrase-example>
      I usually <mark>stick to</mark> simple dishes that don't leave a mess.
    </phrase-example>
    <phrase-translation>我通常只做簡單、不會弄得一團亂的菜。</phrase-translation>
  </phrase-card>
</phrase-chip>
  • data-phrase 是必填，也是收藏的唯一識別。缺少時元件不會初始化。它同時是解釋卡的標題。
  • 標籤上顯示的文字，依序取：data-label、<phrase-card> 以外的文字、data-phrase 本身。
  • <phrase-example> 內可以放 HTML，通常用 <mark> 標出片語。<phrase-translation> 只取純文字。
  • 兩者都是選用的。沒有 <phrase-card> 時，卡片只有標題與收藏按鈕。
  • data-phrase 的比對會先去除前後空白，但大小寫與中間空白必須完全一致，否則視為不同片語。

7.3 行為細節

  • 卡片關閉方式：再點一次標籤、點卡片右上角的 ×、按 Esc、點頁面其他地方。同一時間只會開一張卡片。
  • 卡片附掛在 body，用 fixed 定位，捲動與縮放視窗時會自動跟著標籤重新定位。層級為 1200，高於 Bootstrap 的 modal 與 offcanvas。
  • 同一片語出現在多處時，收藏一次，所有處的標籤同步顯示已收藏狀態（多一個打勾圖示，整體略為變淡）。
  • 收藏狀態只存在記憶體，重新整理頁面即歸零，不會跨頁累積。
  • 收藏時發出的事件帶有完整內容：片語、主題色、例句 HTML、翻譯文字，所以 tracker 不必回頭查 DOM。

8. phrase-chip.js：`<phrase-upgrade>` 漸進升級文字

同一支 phrase-chip.js 還提供第二個元件：一段文字，每點一下就以動畫「升級」成下一個階段的文字，單向前進，到最後一階段停止。用來示範「基本說法如何一步步改成高分說法」。它不彈卡片，也不參與收藏，與 practice-tracker 沒有關係。

<phrase-upgrade data-anim="strike-fade" data-theme="ocean">
  <phrase-stage>I do exercise</phrase-stage>
  <phrase-stage text-color="shell">I work out</phrase-stage>
  <phrase-stage text-color="salmon">I hit the gym</phrase-stage>
</phrase-upgrade>
  • 至少要有兩個 <phrase-stage>，否則元件不會初始化，內容維持原樣。
  • 每個 stage 可用 text-color 屬性覆蓋該階段的文字顏色，接受色票名稱（如 shell）或任意 CSS 色碼。沒設定則用 data-theme 的主色。
  • 動畫進行中點擊無效；到達最後階段後，提示圖示消失、底線由虛線變實線，之後點擊無效。
  • 沒有「倒退」功能，重新整理頁面才會回到第一階段。

讀者在頁面上待夠久、也讀過足夠多段落之後，彈出一個金色的 Modal，內容取自頁面上一個隱藏的 div。適合放公告、廣告、問卷邀請。它是獨立的子功能：沒設定 data-promo-target 就完全不啟動。

9.3 判定邏輯

  • 時間：牆鐘時間，從 tracker 初始化那一刻起算。切換分頁也照常累積。使用者切回分頁時會立刻重新檢查條件。
  • 有效瀏覽：只計算符合 data-prefix 的 section。一個 section 要同時滿足兩點才算：可見面積達到 view-ratio，或可見高度達到視窗高度乘以 view-ratio（這是為了讓比視窗高很多的長 section 也能被計入）；並且連續停留 view-seconds 秒。快速捲過不算。每個 section 只計一次。
  • 觸發：時間與瀏覽數兩個條件都成立才進入「準備彈出」，之後還要同時滿足：分頁可見、捲動已停止 idle-seconds 秒、頁面上沒有其他開著的 modal 或 offcanvas。全部滿足才彈出。
  • 只彈一次：不使用 sessionStorage 與 localStorage。同一次載入只會自動彈出一次，重新整理後重新計算。
  • 內容：開啟時複製目標 div 的 innerHTML，並移除複製內容裡的所有 id（避免與原頁面重複）。原 div 維持隱藏。
  • 降級：找不到目標 div、沒載入 Bootstrap JS、瀏覽器不支援 IntersectionObserver，或要求的 section 數超過頁面實際數量時，只在 console 警告，其他功能不受影響。

9.4 常見設定組合

9.5 外觀

Modal 用金色（#D4AF37、#F3E1A0、#9A7B1F 三階）做特殊內容的視覺區隔：深色底、金色雙層邊框、頂部金色漸層條、金色漸層標題、菱形裝飾線、金色圓形關閉鈕與金色膠囊按鈕。內容區的標題、連結、分隔線、清單符號也會變金色。金色不在品牌色票內，且寫死在樣式裡，沒有屬性可以改。若要覆寫，請用第 11 節列出的 .pt-promo-* class。

  4. 舊的 handleDone 函式裡的 showToast，改成監聽 pt:section-done 後用 Bootstrap alert 顯示。
  5. bp-stepper 的 btn-js="handleDone(...)" 不用動。

13. 疑難排解

症狀最可能的原因怎麼處理
面板完全沒出現，window.PracticeTracker 是 undefined沒有任何 section 的 id 以 data-prefix 開頭。檢查前綴有沒有打錯、預設前綴是 ex-。console 輸入 document.querySelectorAll('section[id^="ex-"]') 驗證。
格子出現了，但按鈕沒有長出來section 上沒有任何 data-btn* 屬性，也沒有 <pt-done-btn>。在 section 加 data-btn-text。只寫在 <practice-tracker> 上不會讓按鈕出現。
出現兩顆標記完成按鈕舊的手寫按鈕與內建按鈕並存。刪除手寫按鈕。
按鈕出現了但樣式沒變寫了不認得的樣式名稱（會退回 outline），或屬性名稱拼錯。樣式名只有七種：solid、outline、pill、ghost、block、check、split。
片語收藏區塊沒出現頁面沒有 phrase-chip[data-phrase]；或所有 chip 都是 data-disable-collect；或 data-phrase-block="false"。確認至少有一個可收藏的 chip 在 HTML 標記裡。
點收藏後，格子沒亮事件名稱不一致；或 chip 是動態新增的；或 data-phrase 的大小寫、空白與格子不同。確認 chip 的 data-event-name 與 tracker 的 data-phrase-event-name 相同（預設都是 pt:phrase-collected）。
「查看收藏清單」按鈕點了沒反應沒載入 Bootstrap JS bundle。載入 bootstrap.bundle.min.js（要 bundle 版，內含 Popper 與 offcanvas）。
phrase-chip 的圖示是空白沒載入 Bootstrap Icons CSS，或 data-icon 誤寫了 bi- 前綴，或 data-collected-icon 漏寫了 bi- 前綴。data-icon="bookmark"；data-collected-icon="bi-check-circle-fill"。
定時 Modal 一直沒彈看 console 警告：找不到目標、沒載入 Bootstrap、section 數不足。也可能是一直在捲動，或有其他 modal 開著。用 PracticeTracker.promoState 檢查已瀏覽數與已過秒數；用 PracticeTracker.showPromo() 確認 Modal 本身可正常顯示。
定時 Modal 彈得太早或太晚時間單位是「分鐘」，不是秒。data-promo-minutes="0.5" 才是 30 秒。
改了 js 檔，線上頁面沒變化使用 jsDelivr 的 CDN 有快取。據我所知，jsDelivr 對分支連結的快取最長可達十數小時，可到 jsDelivr 的 purge 功能清除快取，或改用帶版本號、commit 的網址。
PracticeTracker is not defined 之類的例外在 tracker 初始化之前就呼叫，或根本沒有符合的 section。呼叫前先檢查 window.PracticeTracker；或在 DOMContentLoaded 之後才呼叫。

14. 已知問題與限制

已知問題：片語收藏的完成提示，顯示條件是錯的。 我用模擬環境驗證過：片語全部收藏完、但章節還沒全完成時，「片語獵人認證！」不會顯示；反過來，章節全部完成、但片語還沒收藏完時，它卻會顯示（與章節的完成提示同時出現）。原因是樣式規則只認面板本身的完成狀態，不認片語區塊自己的完成狀態。在修正之前，不建議依賴 data-phrase-complete-text。這個問題是原本就存在的，不是這次新增功能造成的。
注意：面板主體最高 600px，超出的部分會被裁切，且沒有捲軸。 章節格子加片語格子加完成提示加收藏按鈕，總高度要留意。格子很多時，請加大 data-cells-per-row 與面板寬度，把高度壓下來。
注意：原本就有幾處半透明顏色的透明度低於 0.78，例如面板邊框與陰影。若你的規範要求不得低於 0.78，這些需要另外調整。這次新增的樣式都符合。
  • 進度與收藏都只存在記憶體，重新整理頁面全部歸零。這是刻意的設計，沒有任何儲存機制。
  • 同一頁只支援一個 <practice-tracker>。
  • 片語格子的大小、間距、每列數量沿用章節格子的設定，無法單獨指定。
  • 片語總數在初始化時就固定，之後動態新增的 phrase-chip 不會被計入。
  • 標記完成後沒有「取消完成」的功能。
  • 定時 Modal 的金色是寫死的，沒有屬性可以改色。
  • 預設字體小於 1rem 的屬性（見 3.4），需要在每個頁面自行調大。
