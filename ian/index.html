<ui-icon-anim>v1.1.0

將多個 Bootstrap Icons 以逗點分隔，依 interval 播放動畫。支援原地取代與由左至右排出兩種模式，可指定色彩、尺寸、播放完畢自動移除，以及結束時顯示隱藏區塊。v1.1.0 新增按鈕模式（點擊後才播放），以及從 <div id="global_icon_list"> 等元素擷取圖示清單。每張卡片右上角的「重新執行」會重新建立元件。

預設讀取 #global_icon_list

三個元件都沒有設定 icons，自動讀取頁面上的 #global_icon_list。來源內容可用逗點、空白或換行分隔。修改下方清單後，所有元件會自動重新開始。
<!-- 來源元素加上 hidden，避免文字顯示在頁面上 -->
<div id="global_icon_list" hidden>bi-star, bi-square, bi-circle</div>

<ui-icon-anim size="lg" colors="yellow,blue,pink" effect="scale"></ui-icon-anim>
<ui-icon-anim mode="sequence" size="md" colors="green" interval="400" hold="1000"></ui-icon-anim>
<ui-icon-anim button-text="開始" size="lg" colors="energetic,violet,blue" loop="false" button-restore></ui-icon-anim>

// 修改來源內容，元件自動重新開始
document.getElementById('global_icon_list').textContent = 'bi-heart, bi-gem';

屬性預設說明
icons無Bootstrap Icons 類別名稱，逗點或空白分隔，可省略 bi-
icons-from 1.1global_icon_list從指定 id 元素的文字擷取圖示，可帶 #；icons 有值時優先
colors-from 1.1無從指定 id 元素的文字擷取色彩；colors 有值時優先
interval1000切換間隔（毫秒），最小 100
modereplacereplace 原地取代；sequence 由左至右排出
effectfadefade、scale、flip、none
colors繼承文字色調色盤名稱或 HEX，逗點分隔一一對應，不足時循環
sizemd（2rem）sm、md、lg、xl、數字（rem）或含單位值，可逗點分隔
gap8sequence 模式間距（px）
hold同 intervalsequence 模式排滿後停留時間（毫秒）
looptrue設為 false 只播一輪
autoplaytrue設為 false 需呼叫 play()
remove-on-end關閉播完移除或隱藏元件，需搭配 loop="false"
remove-delay0播完後等待多久才移除（毫秒）
remove-effectfadefade、shrink、none
remove-moderemoveremove 刪除；hide 隱藏，可再 play()
reveal-on-end無播完要顯示的元素 id，逗點分隔，可帶 #；需搭配 loop="false"
reveal-effectfadefade、slide、none
reveal-delay0顯示前延遲（毫秒）
button-text 1.1無設定後進入按鈕模式，點擊前顯示這段文字，autoplay 失效
button-icon 1.1無按鈕文字前的圖示；只設定圖示也會進入按鈕模式
button-color 1.1blue按鈕色彩，調色盤名稱或 HEX
button-keep 1.1關閉保留按鈕外框，動畫在按鈕內播放
button-restore 1.1關閉播完回到按鈕狀態；需 loop="false" 且未設定 remove-on-end
方法 / 屬性說明
play()播放；已結束或已隱藏時從頭重播
pause()暫停，保留剩餘時間
reset()回到起點，維持原本播放狀態；按鈕模式下回到按鈕
goTo(i)跳至第 i 個圖示（從 0 起算）
index目前圖示索引（唯讀）
playing是否播放中（唯讀）
armed 1.1是否停在按鈕狀態（唯讀）
事件說明
trigger-click 1.1按鈕被點擊，可 preventDefault() 阻止播放
icon-change顯示新圖示，detail：index、icon、mode、cycle
cycle-end完成一輪，detail：cycle、mode
anim-end播放結束（loop="false"）
before-remove移除前，可 preventDefault()
removed刪除後於原父元素觸發
hiddenremove-mode="hide" 隱藏後觸發
revealedreveal-on-end 目標顯示後觸發

版本紀錄

  • v1.1.0（11-04-26）：新增按鈕模式（button-text、button-icon、button-color、button-keep、button-restore）、trigger-click 事件與 armed 屬性；新增 icons-from、colors-from，未設定圖示時自動讀取 #global_icon_list，來源內容變動時自動重新開始；icons 支援空白與換行分隔。
  • v1.0.0（11-04-26）：初版。replace 與 sequence 兩種模式、四種轉場、調色盤名稱與 HEX 色彩、尺寸關鍵字與逐一尺寸、播放完畢移除或隱藏、結束時顯示指定 id 的區塊、方法與事件、離開可視範圍自動暫停。

版本對照 v1.0.0 與 v1.1.0

點擊後才開始播放

v1.0.0：關閉自動播放，自行加按鈕呼叫 play()
<button id="startBtn">開始</button>
<ui-icon-anim id="anim" autoplay="false" loop="false"
  icons="bi-hourglass-top,bi-hourglass-split,bi-hourglass-bottom"></ui-icon-anim>

<script>
startBtn.addEventListener('click', () => {
  startBtn.hidden = true;
  anim.play();
});
anim.addEventListener('anim-end', () => {
  startBtn.hidden = false;
  anim.reset();
});
</script>
