<ui-fillin> 挖空練習

把一段文字中用大括號標記的位置換成空格，學生從下拉選單選答案，或直接輸入。文末附答案總表與「提交」「重做」按鈕，提交後逐格標示對錯。本頁合併了先前的兩個示範檔（11-12-26），每個範例左邊是實際元件，右邊是同一段原始碼。

1. 選擇題 2. 複選題 3. 輸入題 4. 跳脫字元與例外 5. 清單、隨機與文字 6. 結果輸出 7. 配色 8. 字級與內距 9. 事件與方法 10. 錯誤處理 11. 屬性速查 12. 舊示範檔對照

1. 選擇題

用 {*正確答案|選項二|選項三} 標記空格，正確答案前加 *。題目寫在獨立的來源區塊，<main-box source="id"> 載入時把它複製進來，再把來源清空並隱藏。

單選題，答案總表自動產生

點空格，選項在旁邊浮出，選完自動關閉，答案表同步更新。沒作答就提交的題目顯示為未作答；提交後空格鎖定，按「重做」重新作答。

2. 複選題

標記兩個以上的 * 就是複選，選單上方顯示「可複選」，可以連續勾選，點選單外或按 Esc 關閉。必須選中全部正確選項、而且沒有多選，才算答對。

單選與複選混用

3. 輸入題

mode="text" 時直接在空格內打字。大括號內用直線列出所有可接受的答案，符合任一個即算對，不使用 *。比對區分大小寫，前後空白會被忽略；空格寬度依最長的可接受答案估算。

全形自動轉半形，答錯時顯示正確答案

normalize-width 讓全形英數也能比對成功；show-answer-on-wrong 在答錯或未作答的空格旁顯示正確答案。試著在第一格輸入全形的 ｆｏｒ。

4. 跳脫字元與例外

答案裡要用 |、{、} 或開頭的 * 時，前面加反斜線。每個選項頭尾空白自動去除。只有一個選項的大括號不會變成空格，原樣保留為文字。

符號當選項、空白、單一選項

第一格正確答案是直線本身；第二格的選項前後有空白；句尾的 {only one} 維持原文。

5. 清單、隨機與介面文字

來源可以是 <ol> 或 <ul> 清單。題號依出現順序自動編排；所有按鈕與提示文字都能用 label-* 屬性改寫。

隨機排序、數字代號、自訂按鈕文字、指定答案表位置

random 打亂每個清單的項目順序，reshuffle-on-reset 按重做時再洗一次；option-style="digit" 把選項代號改成 1、2、3；no-number-dot 拿掉題號後的句點；把 <ans-box> 放在想要的位置，答案表就出現在那裡。

天干代號、隱藏題號與答案總表

option-style="cjk" 以甲、乙、丙標示選項；hide-number 不在空格上顯示題號；hide-answer-table 只保留按鈕。適合一句話內的小練習。

6. 結果輸出

加上 results-id，提交時元件在該元素內寫入每題一個 <div class="uf-result">，帶有 data-no、data-state（correct、incorrect）與 data-answered（true、false）。元件只動帶 data-uf-results 的位置，其他內容不會被重建，排版完全由頁面決定。

結果區塊裡的其他元件不受影響

下方的計時器是另一個小元件，提交與重做時都持續運作。結果的樣式寫在本頁的 <style> 裡，列在右側程式碼下方。

本頁為結果區塊寫的樣式：

#q6-results [data-uf-results]{display:flex;flex-wrap:wrap;gap:12px;}
#q6-results [data-uf-results]:empty::before{content:"提交後，結果會出現在這裡。";}
#q6-results .uf-result{padding:8px 12px;border:1px solid;border-radius:6px;}
#q6-results [data-state="correct"]{color:#71CD76;}
#q6-results [data-state="incorrect"]{color:#EF6661;}
#q6-results [data-answered="false"]{border-style:dashed;}

7. 配色

每個部位用 部位-color 設定，可以直接寫品牌色名稱（不分大小寫，bg、background 等於 base），或 名稱/不透明度，例如 energetic/0.85；低於 0.78 會自動提高到 0.78。未設定的部位多半沿用 accent-color。

品牌色票

點色塊複製名稱。

直接寫色名

色名加不透明度、細分部位

空格、已選答案、滑過選項、按鈕、提示框、外框各自設定。

即時調色

改變下拉選單，元件立即套用，下方的開頭標籤同步更新。

The proportion of students who cycle to school {*doubled|double|doubling} over the decade, {*while|whereas|but} car use {*fell|fall|fallen} slightly.

8. 字級與內距

font-size 是基礎字級，純數字視為 rem，題幹、空格、選單、答案表與按鈕都依它縮放。七個部位的內距只接受 px 或純數字，最多四個值；無效值會被忽略並改用預設。下面的欄位都是即時套用，留空即還原。

Every student {*must|musts|musting} bring a {*valid|validly|validate} ticket to the hall.

9. 事件與方法

元件發出 fillin-change、fillin-submit、fillin-reset 三種會冒泡的事件，並提供 submit()、reset()、closeMenu()。下方按鈕在元件外面直接呼叫方法，事件紀錄顯示每次帶出的資料。

const f = document.getElementById('ev-demo');
document.getElementById('ev-submit').onclick = () => f.submit();
document.getElementById('ev-reset').onclick  = () => f.reset();

['fillin-change', 'fillin-submit', 'fillin-reset'].forEach(name => {
  f.addEventListener(name, e => console.log(name, e.detail));
});

10. 錯誤處理

來源區塊找不到，或來源裡沒有任何可用的空格時，元件會顯示提示框說明原因，不會讓頁面出錯。提示文字可用 label-no-source、label-no-blanks 改寫。

11. 屬性速查

屬性值（預設）說明

標籤與挖空語法

<main-box source>元素 id，必填題目來源區塊。載入時複製進來，再把來源清空並隱藏。
<ans-box>選用答案總表與按鈕的位置，未放置時自動建立在題目下方。
{*答案|選項|選項}選擇題至少兩個選項；兩個以上的 * 為複選。
{答案一|答案二}輸入題mode="text" 時使用，符合任一個即算對。
\| \{ \} \*跳脫讓選項能出現這些符號。

題目與行為

modechoice、text（choice）選擇題或輸入題。
option-stylealpha、digit、cjk（alpha）選項代號 A/B/C、1/2/3、甲/乙/丙。
random、reshuffle-on-reset布林清單項目隨機排序；重做時重新洗牌。
hide-number、no-number-dot布林不顯示題號；題號後不加句點。
hide-answer-table布林隱藏答案總表，只保留按鈕。
normalize-width布林輸入題比對前把全形英數與全形空白轉為半形。
show-answer-on-wrong布林輸入題提交後，答錯或未作答的空格旁顯示正確答案。
results-id元素 id提交後把每題結果寫進該元素。

介面文字

label-correct、label-incorrect、label-unanswered正確、錯誤、未作答答案表中的狀態文字。
label-submit、label-reset提交答案、重做按鈕文字。
label-submitted已批改，請查看每題的對錯。提交後的提示。
label-multi-hint可複選複選題選單上方的提示。
label-correct-answer-prefix正確答案：輸入題顯示正確答案的前綴。
label-no-source、label-no-blanks內建訊息錯誤提示文字。

外觀

font-size（1.125rem）基礎字級，純數字視為 rem。
line-height（1.4）只接受純數字，最大 1.5。
btn-font-size、btn-radius（字級 0.8 倍、5px）按鈕字級與圓角。
border-width、radius（2px、6px）外框粗細；空格與選單圓角。
blank-max-width、menu-max-width、menu-max-height（20rem、24rem、60vh）空格與選單的最大尺寸。
root-、main-、blank-、menu-、option-、ans-、btn-paddingpx 或純數字各部位內距，最多四個值。
line-color、line-alpha（shell、0.78）外框與分隔線顏色與不透明度，不透明度最低 0.78。

顏色（部位-color）

bg-color、text-color、accent-color（base、shell、shell）底色、文字、強調色；強調色是多數部位的預設值。
ok-color、bad-color（green、warning）答對、答錯。
blank-color、picked-color沿用 accent、blank空格外框與文字；已作答空格底色。
menu-color、hover-color沿用 bg、accent選單底色；選項滑過底色。
head-color、btn-color、alert-color沿用 accent答案表表頭；按鈕；批改提示框。

事件與方法

fillin-change{ no, selected } 或 { no, value }作答內容改變時。
fillin-submit{ results }提交時，每題含 no、correct、answered。
fillin-reset無按下重做時。
submit()、reset()、closeMenu()方法提交批改；重做；關閉開啟中的選單。
UF.brand、UF.colorParts、UF.resolveColor()靜態UF = customElements.get('ui-fillin')；色票、可設定顏色的部位、把顏色值轉成 CSS 色值。
