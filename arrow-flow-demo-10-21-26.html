屬性速查表

屬性（kebab-case） 預設值 說明
theme"shell"主色系，palette key 或任意 hex 值
header-color同 themeheader 背景色覆寫（可於 flow-step 個別設定）
border-color同 theme邊框色覆寫
arrow-color同 theme箭頭填色覆寫
arrow-tip"md"箭頭尖端大小：sm / md / lg / xl
arrow-style"solid"箭頭桿樣式：solid / dashed
arrow-glowfalse（布林屬性）啟用箭頭 SVG drop-shadow 發光效果
gap"72px"箭頭欄寬度，可用任意 CSS 長度單位
reveal"cumulative"步驟顯示模式：cumulative（累積）/ single（單次）
animation"fade"進場動畫：fade / slide / none
equal-heightfalse（布林屬性）強制所有步驟盒子等高
current0初始已展開到第幾個主流程步驟（從 0 起算）
step-widthnull（flex:1）固定步驟欄寬，如 "240px"
box-shadow"none"盒子 CSS box-shadow，可疊加多層用逗號分隔
border-width"2.5px"邊框粗細
border-radius"5px"盒子圓角大小
header-gradient"none"header 背景漸層方向：down / up / none
header-accent-line"none"header 強調線位置：left / top / none
header-font-size"1.125rem"header 文字大小
header-letter-spacing"0"header 字距（em 單位建議）
content-font-size"1.125rem"內容區文字大小
content-line-height"1.5"內容區行高
branch-label-theme"teal"分支選擇按鈕顏色，palette key 或 hex
branch-dim"0.80"未選中分支路徑的透明度
