// Salmon 主題：numberColor → 自動同步 themeColor + borderHoverColor
NumericList.setup({
  numberColor:      '#E5C3B3',   // ← 觸發自動同步
  numberBg:         '#200f0a',
  borderColor:      '#3d1e14',
  numberDivider:    '#3a1a10',
  activeBackground: '#1a0e0a',
});
// 結果：themeColor = '#E5C3B3'，borderHoverColor = '#E5C3B3'

// 手動覆蓋 hover 色（不跟 theme 走）：
NumericList.setup({
  numberColor:      '#E5C3B3',
  borderHoverColor: '#DECA4B',   // ← 明確傳入，不自動同步
});

// 恢復 accentColors 循環：
NumericList.setup({ themeColor: null });

滑入看顏色

gap="24px" hover="#FFB3D9"

gap 很寬

hover → pink

滑入看顏色

gap = 24px

 
<ui-list
  width="100%"

  <list-item>...</list-item>
</ui-list>

屬性速覽

<ui-list>

屬性型別預設值說明
width選用 string 100% CSS 寬度值。"80%/360px" → width:80%; min-width:360px。
gapv2.1 CSS length Config.rowGap 項目之間的間距。寫入 CSS 自訂屬性 --nl-gap，僅影響此清單。
hoverv2.1 color Config.borderHoverColor hover 時邊框色。寫入 --nl-hover-color，僅影響此清單。
未設定 active 時，active 邊框色也跟隨此值。
active選用 color 同 hover active（點擊後）邊框色。寫入 --nl-active-color，需與 source/target 搭配使用。

<list-item>

屬性型別預設值說明
number選用 string 自動遞增 左側數字欄文字，支援數字、字母或短文字。
accent選用 color themeColor 或循環 優先序最高，覆蓋 themeColor 與 accentColors 循環。
source選用 id — 指定 div ID，初始化時自動隱藏該 div。需與 target 同時設定。
target選用 id — 點擊時，將 source div 的 innerHTML 注入此 ID 的容器。

使用者體驗設計

好的 UX 設計讓複雜的事情看起來簡單。三個核心原則：

  • 一致性——同樣的操作在任何地方都有相同結果
  • 可預測性——使用者能預期下一步會發生什麼
  • 即時回饋——每個動作在 100ms 內要有反應

開發流程規範

採用迭代式開發，每個 Sprint 以可交付的功能增量為目標。

  • Sprint 長度：兩週
  • 每日站立會議：15 分鐘上限
  • Definition of Done：PR 獲兩位 reviewer 核准

測試策略

  • 單元測試——覆蓋率目標 80%，jest + vitest
  • 整合測試——API 合約驗證
  • 端對端測試——Playwright，主要流程全覆蓋

部署流程

  • Dev → 每次 PR merge 自動部署
  • Staging → 每週五 16:00 手動觸發
  • Production → Tech Lead 核准，藍綠部署
