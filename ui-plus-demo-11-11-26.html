ui-btn 移除元素

ui-plus.js 的 <ui-btn> 新增 remove-target 屬性：點擊後把指定 id 的元素從網頁移除，重新整理網頁前不會復原。建立日期 11-11-26。
修訂二（11-12-26）：<read-pulse> 新增 style="fuse" 燃燒引信樣式，見最下方範例。

範例一：移除一個 div

最常見的用法：讀完就關掉的說明框。按鈕只負責移除，目標移除後按鈕自動停用。

範例二：一次移除多個元素，淡出

remove-target 和 targets 一樣，可以寫多個 id，逗號或空白分隔，# 可省略。動畫沿用 animation 與 anim-duration；animation="none" 時立即移除。

HTML

範例三：展開答案，同時移除提示

和 target 一起使用時，同一次點擊會展開答案並移除提示。按鈕還有展開與收合的功能，所以不會停用；提示移除後不會再出現。

HTML

修訂二（11-12-26）：read-pulse 燃燒引信

<read-pulse> 新增 style="fuse"：色條由上往下燒，條身從燒過的暗色漸變到火花處的亮色，底端有閃爍的火花與飛濺的火星，跑完後淡出。spark-size 調整火花大小。下方三段都設了 trigger="click" 與 repeat，點段落可以重播。

HTML

修改前：style 只有 solid、gradient、glow、segmented、double
<read-pulse style="glow" color="green">...</read-pulse>

修改後：新增 fuse 與 spark-size（火花直徑，預設 8，最小 4）
<read-pulse style="fuse" color="playful" spark-size="12">...</read-pulse>
全域預設：window.UiReadingConfig = { pulseStyle: 'fuse', pulseSparkSize: 10 }

新增的屬性與事件

項目範例說明
remove-targetremove-target="a, b #c"新增。點擊後要移除的元素 id，逗號或空白分隔，# 可省略。元素先依 animation 收合，再從網頁刪除；重新整理網頁前不會復原。找不到的 id 會在主控台提示。
按鈕停用按鈕只設定 remove-target，沒有 target、href、alert、mini-table-id、unlock-chunk 時，目標全部移除後按鈕自動停用。
緊鄰元素只寫 remove-target 時，按鈕不會再去開合緊接在後面的元素。
ubtn-removed 事件e.detail.ids新增。從 <ui-btn> 冒泡，e.detail 含 ids（這次移除的 id）與 button。
 
修改前：沒有移除功能，只能用 target 收合，收合後仍留在網頁裡，再按一次就會回來
<ui-btn target="tip-intro">關掉說明</ui-btn>

修改後：remove-target 直接把元素從網頁刪除，不會再出現
<ui-btn remove-target="tip-intro">我讀完了，關掉說明</ui-btn>
