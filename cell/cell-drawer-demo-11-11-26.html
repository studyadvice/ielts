cell-drawer 顏色屬性支援品牌色名稱

修正前，slide-color、surface-bg、dot-color、dot-active-color、badge-color、countdown-color、start-bg、start-color 只認 #hex 或 CSS 原生色名，填 vanilla、key 等品牌色名稱會失效，填 pink 會變成 CSS 原生粉紅。修正後一律先轉換品牌色名稱，不分大小寫，theme 也不分大小寫。

修正後的實際元件

第一頁：slide-color="vanilla" 第二頁：surface-bg="bg-alternative" 第三頁：dot-active-color="Energetic"

程式碼對照

修正前

<cell-drawer theme="key"
  slide-color="#DBEDD8"
  surface-bg="#3B2A20"
  dot-active-color="#B6FF00">
  ...
</cell-drawer>

修正後（11-11-26）

<cell-drawer theme="KEY"
  slide-color="vanilla"
  surface-bg="bg-alternative"
  dot-active-color="Energetic">
  ...
</cell-drawer>
