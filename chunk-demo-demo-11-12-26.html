<chunk-demo> 意群替換示範

把一個句子拆成固定文字與可替換的意群，每個意群可以在不同程度的寫法之間切換，示範同一句話如何由簡到繁。本頁合併了先前所有的示範檔（11-12-26），每個範例左邊是實際元件，右邊是對應的程式碼。

1. 基本用法 2. 三種切換模式 3. 預覽、翻譯與備註 4. 遮罩與鎖定 5. 外觀 6. 主題一覽 7. 進階設定 8. 屬性速查 9. 舊示範檔對照

1. 基本用法

句子樣板用 {0}、{1} 標出意群的位置，每個 <cd-chunk> 對應一個位置，裡面的 <cd-level> 依序是程度 1、2、3 的寫法。點意群按鈕即可切換。

子元素語法，含圖示與標籤

icon 與 label 顯示在下拉選單上方；show-preview 在句子下方組出目前的整句。

寫法裡可以放 HTML，id 可省略

沒寫 id 時依順序對應 {0}、{1}；<cd-level> 內可用 <strong>、<em>。border-style 改變按鈕邊框樣式。

2. 三種切換模式

dropdown 點意群展開下拉選單；dots 點意群在旁邊彈出一排圓點；dots-ext 把所有意群的圓點集中到句子上方或下方的面板。

同一個元件即時切換模式

按下方按鈕改寫 mode 與 dots-pos 屬性，元件會立即重繪，目前選擇的寫法會保留。

dots：圓點浮層，最多可到第 5 級

不寫 label 時浮層只有圓點。level 決定圓點顏色，可以超過三級。

dots-ext：有無 label 的差別

面板每一列前會顯示 label；沒有 label 時只顯示圓點，意群多時較難對應，建議加上。

3. 預覽、翻譯與備註

句子下方可以疊三列：show-preview 整句預覽、show-translation 翻譯、show-note 備註。翻譯樣板同樣用 {id} 標位置，填入各寫法的 trans；沒填 trans 時沿用英文。

三列全開，翻譯語序可以和英文不同

id 不必從 0 開始；翻譯樣板依中文語序排列 {3}{1}去{2}。note 可寫 HTML。

dots-ext 面板加上翻譯與縮排

translation-indent、preview-indent 讓下方各列往右縮，和句子文字對齊。

4. 遮罩與鎖定

mask-mode 讓意群先顯示為色塊，點開過才露出文字，適合先讓學生想再對答案。lock-chunks 鎖住的意群顯示目前寫法但不能切換，可用 unlockChunk() 解鎖，也能搭配 ui-plus.js 的 ui-btn unlock-chunk。

遮罩，搭配翻譯

翻譯列的對應位置也會一起遮住。

鎖定意群，用按鈕解鎖

第二個意群（id 1）一開始鎖住。按鈕呼叫 unlockChunk(1) 與 lockChunk(1)。

5. 外觀

按鈕配色由 theme 決定；程度圓點的顏色用 level-colors 覆寫，可以寫品牌色名稱，不分大小寫。寬度、邊框、外距與句子框內距都能調整。

level-colors 用品牌色名稱

依序覆寫第 1、2、3 級圓點。寫 green 會是品牌綠 #71CD76，不是 CSS 原生的綠；theme 也不分大小寫。

隱藏圓點，固定按鈕與選單寬度

show-dots="false" 隱藏按鈕上的程度圓點；button-width 讓按鈕寬度一致，切換時句子不會跳動；dropdown-width 設定選單最小寬度。

長意群自動獨佔一行，調整句子框

意群按鈕寬度超過句子框的 long-chunk-threshold（預設 0.52）時自動換到獨立一行；選第 3 級試試。bar-padding、bar-line-height、margin-bottom 調整句子框與外距。

6. 主題一覽

17 個品牌色主題，寫法 theme="名稱"，不分大小寫。以下由同一段 HTML 依序套用各主題產生。

<chunk-demo theme="green" sentence="The weekend trip was {0}.">
  <cd-chunk>
    <cd-level>fun</cd-level>
    <cd-level>a real breath of fresh air</cd-level>
    <cd-level>exactly the escape I had been craving</cd-level>
  </cd-chunk>
</chunk-demo>

7. 進階設定

設定的優先順序：元素屬性 > data-config > window.ChunkDemoConfig > 內建預設。

以 JSON 提供意群

沒有 <cd-chunk> 子元素時，改讀 chunks 屬性的 JSON。適合由程式產生內容。

data-config 一次覆寫多項設定

鍵名同 ChunkDemoConfig，例如預覽列文字色 previewTextColor、遮罩色 maskColor、句子框底色 sentenceBg。

全頁預設值與 JavaScript API

ChunkDemoConfig 要在載入 chunk-demo.js 之前設定，會影響整頁，所以這裡只列程式碼。

<script>
  window.ChunkDemoConfig = {
    defaultTheme: 'blue',      // 沒寫 theme 時使用
    showPreview: true,
    mode: 'dots',
    chunkBorderWidth: '1.5px',
    chunkBorderStyle: 'solid',
    previewBorderColor: null   // null 表示跟隨 theme 色
  };
</script>
<script src="chunk-demo.js"></script>

<script>
  const cd = document.querySelector('chunk-demo');
  cd.unlockChunk(1);   // 解鎖 id 為 1 的意群
  cd.lockChunk(0);     // 鎖定 id 為 0 的意群
</script>
