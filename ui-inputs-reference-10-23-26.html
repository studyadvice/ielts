ui-inputs 全屬性對照手冊

涵蓋 <ui-otp> 與 <ui-blank> 兩個元件的完整屬性，每一項皆為「左側程式碼、右側即時效果」對照。頁面本身採深色中性配色，避免干擾元件自身的配色判讀。

ui-otp／數量與分組 ui-otp／內容限制 ui-otp／尺寸外觀 ui-otp／顏色 ui-otp／Focus ring ui-otp／驗證 ui-otp／文字標籤 ui-otp／完整組合 ui-otp generate／格式與字元集 ui-otp generate／複製按鈕 ui-otp generate／後端查重 ui-blank／內容比對 ui-blank／按鈕 ui-blank／尺寸外觀 ui-blank／Focus ring ui-blank／驗證 ui-blank／訊息 ui-blank／完整組合

一、ui-otp

單一 input 版 OTP 輸入／驗證元件。畫面上每一格是展示用 div，背後有一個透明的真正 input 接收鍵盤輸入。

1. 數量與分組

屬性可接受值預設值說明
length數字6總格數
groups逗號分隔的數字，總和須等於 length（無，單一整組）分組，例如 "3,3"
separator任意字元-分組之間的分隔符號

length="8"

<ui-otp length="8"></ui-otp>

groups="2,3,3" + separator="·"

<ui-otp length="8" groups="2,3,3" separator="·"></ui-otp>

2. 內容限制

屬性可接受值預設值說明
typenumeric / alpha / alnum / anynumeric決定過濾規則與 inputmode
caseupper / lower（不轉換）type 非 numeric 時可強制大小寫
mask布林屬性關顯示圓點取代實際字元

type="alnum" case="upper"

<ui-otp length="6" type="alnum" case="upper"></ui-otp>

英數混合，自動轉大寫。

mask

<ui-otp length="6" mask></ui-otp>

3. 尺寸外觀

屬性可接受值預設值說明
cell-sizepx48px單格寬高（正方形）
gappx10px格子間距
font-sizerem1.25rem格內字級
radiuspx8px格子圓角
border-widthpx1px格子外框粗細

大尺寸格子

<ui-otp length="4" cell-size="64px" gap="14px"
  font-size="1.6rem" radius="14px" border-width="2px"></ui-otp>

緊湊小尺寸

<ui-otp length="6" cell-size="34px" gap="6px"
  font-size="0.95rem" radius="4px"></ui-otp>

4. 顏色（統一走色票系統）

屬性說明
border-color格子預設外框色
bg-color格子底色
text-color格內文字色
accent-color作用中格子的外框色，也是 focus ring 的預設色來源
error-color驗證失敗時的外框與訊息色
valid-color驗證成功時的外框與訊息色

可用色票名稱：background, shell, lavender, sky, warning, salmon, ocean, safe, teal, vanilla, yellow, focus, special, info, indigo, pink, orange（亦可直接填 hex／rgba）。

自訂底色與文字色

<ui-otp length="6" bg-color="indigo" text-color="focus"
  border-color="rgba(255,255,255,.3)" accent-color="pink"></ui-otp>

5. Focus ring

屬性可接受值預設值說明
focus-ring-widthpx3px聚焦格子外圍光暈粗細
focus-ring-color色票／hex跟隨 accent-color光暈顏色（hex 會自動換算半透明版本）

粗、顯眼的 focus ring

<ui-otp length="6" accent-color="warning"
  focus-ring-width="6px" focus-ring-color="warning"></ui-otp>

點擊任一格聚焦即可看到效果。

6. 驗證

屬性可接受值預設值說明
expected-value字串（無）有給就走前端比對模式
clear-on-invalid布林屬性關驗證失敗後自動清空重輸
clear-delay毫秒700清空前的延遲時間

expected-value="654321"

<ui-otp length="6" expected-value="654321"
  valid-color="safe" error-color="warning"></ui-otp>

填滿 6 碼即自動比對。

clear-on-invalid + clear-delay="1200"

<ui-otp length="6" expected-value="111111"
  clear-on-invalid clear-delay="1200"></ui-otp>

答錯 1.2 秒後自動清空（比預設的 700ms 慢）。

7. 文字標籤與行為

屬性說明
label-invalid驗證失敗訊息文字
label-valid驗證成功訊息文字（留空則不顯示）
show-message"false" 關閉訊息顯示，其餘值視為開啟
disabled布林屬性，鎖定整個元件

自訂訊息文字

<ui-otp length="4" expected-value="9999"
  label-invalid="碼不對，再試一次"
  label-valid="OK，驗證通過"></ui-otp>

disabled

<ui-otp length="6" disabled></ui-otp>

8. 完整組合範例

多屬性同時套用

<ui-otp
  length="6" groups="3,3" separator="-"
  cell-size="52px" gap="10px" font-size="1.3rem" radius="10px"
  accent-color="teal" valid-color="safe" error-color="warning"
  focus-ring-width="4px"
  expected-value="246810" clear-on-invalid clear-delay="900"
  label-invalid="驗證碼錯誤" label-valid="驗證成功"></ui-otp>

一之二、ui-otp mode="generate"

同一個 <ui-otp> 標籤加上 mode="generate"，連結到畫面即自動隨機產生一組碼（唯讀展示），旁邊附複製到剪貼簿按鈕。尺寸／顏色／focus ring 等外觀屬性與 mode="input" 完全共用，這裡只列生成模式新增的屬性。

9. 格式與字元集

屬性可接受值預設值說明
modeinput / generateinput切換輸入驗證／生成展示
length數字16（generate 模式預設值跟 input 的 6 不同）生成碼的總長度，沒有 format 時生效
groups / separator同 input 模式（無）/ -分組與分隔符號
format版型字串，O 代表一個字元格（無）有給就優先於 length/groups，例如 "OOOO-OOOOO-OOOOOO"
typenumeric / alpha / alnum / anynumeric字元池；any 會退回英數混合
caseupper / lower（混合大小寫）type 含英文字母時可指定只用大寫或小寫
exclude-ambiguous"false" 關閉；其餘視為開啟開排除 0/O、1/I/l 這類容易看錯的字元
auto-generate"false" 關閉；其餘視為開啟開關閉後不會自動產生，需自行呼叫 el.generate()

format 版型 + alnum 字元集

<ui-otp mode="generate" format="OOOO-OOOOO-OOOOOO"
  type="alnum" accent-color="lavender"></ui-otp>

length="20" + groups + 關閉 exclude-ambiguous

<ui-otp mode="generate" length="20" groups="5,5,5,5"
  exclude-ambiguous="false" accent-color="orange"></ui-otp>

10. 複製按鈕

屬性可接受值預設值說明
copy-iconBootstrap Icons classbi-clipboard平時顯示的圖示
copy-icon-successBootstrap Icons classbi-clipboard-check複製成功後短暫顯示的圖示
copy-text字串（無，純圖示）按鈕文字
copy-positionleft / rightright按鈕相對於格子的位置
copy-feedback-duration毫秒1500成功圖示停留多久後變回原圖示

按鈕在左側 + 自訂文字與圖示

<ui-otp mode="generate" length="10" groups="5,5"
  copy-position="left" copy-text="複製"
  copy-icon="bi-stickies" copy-icon-success="bi-stickies-fill"
  accent-color="special"></ui-otp>

11. 後端查重（check-url，generate／input 共用）

屬性可接受值預設值說明
check-url網址（無）後端驗證端點；有給就會自動呼叫
check-methodGET / POSTPOSTHTTP 方法
check-param字串code送出碼時使用的參數名稱
check-field字串exists回傳 JSON 中「是否存在」布林欄位的名稱
check-max-retries數字5generate 模式下，重複就重骰的次數上限

PHP 端點範例：收到 POST 的 code 參數、查資料庫後 echo json_encode(['exists' => $found]); 即可直接搭配使用。generate 模式下撞號會自動重骰，直到抽到沒用過的碼，或達到 check-max-retries 次數上限為止（此時會 dispatch otp-check-exhausted 事件）；input 模式則是把查詢結果當作驗證結果（存在＝valid）。

generate 模式自動查重（下方用假 fetch 模擬後端）

<ui-otp mode="generate" length="6" type="numeric"
  check-url="/your/check_code.php"
  check-max-retries="5" accent-color="teal"></ui-otp>

實際使用時把 check-url 換成你自己的 PHP 端點即可，這裡的假後端只是讓示範頁能獨立運作。

二、ui-blank

單行輸入填充題元件，永遠區分大小寫，送出鈕可用 Bootstrap Icons。

1. 內容比對

屬性可接受值預設值說明
expected-value字串，多個答案用 | 分隔（無）有給就走前端比對模式，永遠區分大小寫
trim-whitespace"false" 關閉；其餘視為開啟開比對前去除頭尾空白（不影響畫面顯示）
normalize-width布林屬性關比對前把全形數字／字母／符號轉半形
placeholder字串（無）輸入框提示文字

多個可接受答案

<ui-blank expected-value="cat|Cat"
  placeholder="輸入 cat 或 Cat"></ui-blank>

normalize-width

<ui-blank expected-value="2024" normalize-width
  placeholder="可用全形輸入法打數字"></ui-blank>

2. 送出按鈕

屬性可接受值預設值說明
button-iconBootstrap Icons class（如 bi-send）（無）圖示固定不隨驗證結果變化
button-text字串（無，兩者都空則顯示「送出」）按鈕文字
button-positionicon-left / icon-righticon-right圖示相對文字的位置
disable-enter-submit布林屬性關（Enter 預設會送出）加上此屬性後 Enter 鍵不會觸發送出

icon-left + 按鈕文字

<ui-blank expected-value="go"
  button-icon="bi-arrow-right-circle" button-text="送出"
  button-position="icon-left"></ui-blank>

disable-enter-submit

<ui-blank expected-value="go" disable-enter-submit
  button-icon="bi-send"></ui-blank>

按 Enter 不會送出，必須點按鈕。

3. 尺寸外觀

屬性可接受值預設值說明
widthpx／%／ch220px輸入框寬度
font-sizerem0.95rem輸入框字級
paddingpx5px 10px輸入框內距
radiuspx6px整體圓角（輸入框與按鈕外側）
border-widthpx1px外框粗細
btn-paddingpx5px 12px按鈕內距
btn-font-sizerem0.95rem按鈕字級

加大版

<ui-blank expected-value="big" width="320px"
  font-size="1.1rem" padding="10px 14px" radius="10px"
  btn-padding="10px 18px" btn-font-size="1.1rem"
  button-icon="bi-send"></ui-blank>

窄版（ch 單位）

<ui-blank expected-value="ok" width="10ch"
  button-icon="bi-check2"></ui-blank>

4. 顏色與 Focus ring

屬性說明
border-color / bg-color / text-color輸入框外框／底色／文字色
btn-bg / btn-color按鈕底色／文字色，未設定時跟隨 accent-color
accent-color按鈕預設底色，也是 focus ring 的預設色來源
focus-ring-width / focus-ring-color聚焦時整個輸入列的外圍光暈
valid-color / error-color驗證成功／失敗時的外框與訊息色

自訂按鈕配色 + 粗 focus ring

<ui-blank expected-value="hi"
  btn-bg="indigo" btn-color="focus"
  focus-ring-width="5px" focus-ring-color="indigo"
  button-icon="bi-send"></ui-blank>

5. 驗證行為

屬性可接受值預設值說明
clear-on-invalid布林屬性關驗證失敗後自動清空重輸
clear-delay毫秒700清空前的延遲時間
disabled布林屬性關鎖定輸入框與按鈕

clear-on-invalid，延遲 1.5 秒

<ui-blank expected-value="dog" clear-on-invalid
  clear-delay="1500" button-icon="bi-send"></ui-blank>

disabled

<ui-blank disabled placeholder="已鎖定"
  button-icon="bi-send"></ui-blank>

6. 訊息顯示

屬性可接受值預設值說明
label-invalid字串「答案不正確，請重新輸入。」驗證失敗訊息
label-valid字串（無，留空不顯示）驗證成功訊息
show-message"false" 關閉；其餘視為開啟開是否顯示訊息
message-styleplain / bordered / filled / accent-bar / icon-bannerplain內建訊息區塊的呈現樣式（見下方五種示範）
message-font-sizerem0.85rem訊息字級
message-paddingpx依樣式而異訊息內距，設定後覆蓋各樣式的預設值
message-radiuspx6pxbordered／filled／icon-banner 的圓角
message-icon-validBootstrap Icons classbi-check-circleicon-banner 樣式成功時的圖示
message-icon-invalidBootstrap Icons classbi-x-circleicon-banner 樣式失敗時的圖示
message-target頁面上某個元素的 id（無，用內建區塊）指定後把純文字訊息改顯示在該 div，不套用 message-style

message-style="bordered"

<ui-blank expected-value="ok" message-style="bordered"
  label-valid="答對了！" label-invalid="不對喔"
  button-icon="bi-send"></ui-blank>

message-style="icon-banner" + 自訂圖示

<ui-blank expected-value="ok" message-style="icon-banner"
  message-icon-valid="bi-emoji-smile"
  message-icon-invalid="bi-emoji-frown"
  label-valid="太棒了！" label-invalid="再想想"
  button-icon="bi-send"></ui-blank>

message-target（顯示在外部 div，不套樣式）

<ui-blank expected-value="ok" message-target="refMsgBox"
  label-valid="答對了！" button-icon="bi-send"></ui-blank>
<div id="refMsgBox" style="font-weight:700;margin-top:6px;"></div>

  focus-ring-width="4px"
  button-icon="bi-send" button-text="確認" button-position="icon-left"
  clear-on-invalid clear-delay="900"
  message-style="filled"
  label-valid="答對了！" label-invalid="再檢查一次"></ui-blank>
