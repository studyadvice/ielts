ui-table 詳細手冊

涵蓋全域設定、所有標籤與所有屬性。每個範例左側為即時結果，右側為對應程式碼，可按「重新載入」重播動畫與計時效果。

總覽與結構

ui-table 以語意標籤描述表格。元件不使用 shadow DOM，樣式自動注入 <style id="uit-css">。原始的 ui-table 元素會被隱藏，渲染結果插在它的前面。

要顯示 bi- 開頭的圖示、show-next 的箭頭，以及 auto-number 的 1 到 9 圓圈數字，頁面需有 Bootstrap Icons 字型。內建的 i- 圖示為 SVG，不依賴字型。

ui-table ├─ ui-col[hidden][id] 提示訊息來源（選用，供 alert-msg 引用） ├─ ui-group 群組（選用） │ ├─ ui-row 一列，欄數以第一個有儲存格的 ui-row 為準 │ │ └─ ui-col 儲存格 │ │ └─ cell-item 輪播項目（只用於 carousel-interval） │ └─ ui-row-enhance 一列，欄數由本列自行決定 └─ ui-row / ui-row-enhance 無群組時，列直接放在 ui-table 下

最小範例

顏色來源：所有顏色參數都接受色名（見「全域 API 與色彩」）、# 色碼或 rgb(...)。內部由色碼產生 rgba 時，透明度一律不低於 0.78。

全域設定 UiTableConfig

全域設定是所有表格的預設值，可被 ui-table、ui-row、ui-col 上的屬性覆寫。設定物件需在元件渲染表格之前準備好。

ui-table 屬性

互動調整

調整下方選項，觀察整表層級屬性的效果，右側程式碼會同步更新。

ui-table 屬性試玩

  

  
文字顏色優先順序

  
文字顏色的優先順序為 ui-col、ui-row、ui-table 的 font-color，最後才是 theme。邊框與群組標題列永遠使用 theme。

  





  
ui-group

  
群組會產生有標題列的區塊，點擊標題列可收合或展開。遮罩的 mask-order 與 show-next 都以群組為單位獨立運作。

  

  





  
ui-row

  
ui-row 與 ui-row-enhance 共用同一組屬性。ui-row 的欄數以整張表第一個有儲存格的 ui-row 為準。

  

  
  
  
  





  
ui-row-enhance

  
ui-row-enhance 的欄數由該列自己的儲存格數決定，所以同一張表可以混用不同欄數的列，col-widths 的比例數也只需符合該列自己的欄數。

  





  
ui-col 基本屬性

  

  
  
  
  
  
固定欄的實際效果取決於容器寬度與儲存格寬度，只有在表格水平捲動時才看得出來。






  
expandable 可展開文字

  
加上 expandable 後，內容預設只顯示兩行，點擊文字或右側箭頭可展開與收合。與 mask-text 互斥。

  





  
extra-info 額外資訊

  
在儲存格右側顯示一個圖示，點擊後彈出浮動視窗，內容取自頁面上另一個元素。來源元素在元件載入時自動隱藏，視窗會自動避開視窗邊緣，點擊其他地方或按 Esc 關閉。

  
互斥：與 mask-text、carousel-interval 互斥。屬性值不可為空，且對應 id 的元素必須存在。

  





  
show-next 逐步展開

  
點擊帶有 show-next 的儲存格，會展開緊接在下方、且標有 hidden 的列。右側會出現一個會翻轉的箭頭。

  

  
  
  





  
遮罩 mask

  
遮罩蓋住儲存格內容，點擊後揭開。可選擇純色、反色、漸層，也可以設成雙層或依序解鎖。

  

  
內建漸層編號：1 靛紫、2 海藍、3 橘黃、4 粉紅、5 青綠、6 藍紫。

  
  
  
  
注意：mask-order 需從 0 起連續且不可重複。重複時，console 會顯示錯誤並視為無序。順序以群組為範圍，沒有群組時以整張表為範圍。






  
輪播 carousel

  
以 cell-item 放入多筆內容，儲存格會依設定的間隔向上輪播。只有一筆時不會輪播。若同時有 mask-text 或 alert-msg，輪播會被忽略。

  

  





  
提示 alert

  
儲存格可以每隔一段時間自動浮現提示，每次顯示的時間由全域的 alertDuration 決定。提示內容可直接寫文字，也可引用 ui-table 底下一個 hidden 且有 id 的 ui-col。

  

  
  
提示首次出現在一個間隔之後。請稍候數秒，或按「重新載入」重新計時。






  
欄間箭頭 arrow

  
箭頭畫在相鄰兩欄的交界線上，可以設在整列，也可以只設在個別儲存格。兩側儲存格會自動預留空間，避免壓到文字。

  

  
  





  
自動揭示列 auto-reveal-interval

  
在 ui-table 上設定 auto-reveal-interval，標有 hidden 的列會依序自動出現：第 n 列在 n 倍間隔後出現。也可以在全域設定 autoRevealInterval。

  





  
JSON 資料來源

  
表格內容可由 JSON 產生：data-id 讀取全域變數，src 以 fetch 讀取檔案。JSON 只會建立群組與列，頂層需有 groups 陣列。

  
欄位對照

  
JSON 的欄位名稱為屬性名稱的駝峰寫法，例如 col-widths 對應 colWidths。

  

  
JSON 不支援：theme（請寫在 ui-table 標籤上）、mask-gradient，以及 show-next 的 col 與 row 指定值（showNext 固定寫入 true，同列有多個時自動各欄展開）。alert 引用的隱藏 ui-col 需直接放在 ui-table 底下，才會在清空前被保留。

  
  
  
說明：此頁的 src 範例以瀏覽器內的暫存網址模擬 demo-data.json，實際使用時請改成真實檔案路徑。

互斥與注意事項

  
下列組合會在 console 顯示警告或錯誤，元件會依表格中的方式處理。

  

  
其他注意事項

  
    
    
  • 點擊 expandable 與 extra-info 時會停止事件冒泡，所以不會同時觸發 show-next。
    • 
    
  • 箭頭只在左右兩欄位於同一行時顯示。欄位換行時箭頭會自動隱藏。
    • 
    
  • 輪播儲存格的內容只取 cell-item，其餘文字不會顯示。
    • 
    
  • alert 位置 B 與其他位置使用固定定位，儲存格被隱藏或群組收合時不會顯示。
    • 
    
  • 同一個 ui-table 只會初始化一次，重複呼叫 UiTable.init() 是安全的。
    • 
    
  • 單一表格初始化失敗時，錯誤只影響該表格，並輸出在 console。
