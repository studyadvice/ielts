<text-splitter> 元件展示

將一段文字（含 HTML 標籤）大約等分至頁面任意處的多個目標區塊。

範例 1

delimiter 模式 — 強制切割（最精準）

文字中含 |||（預設符號）時，無論 mode 為何皆優先以符號切割。
幾個符號就分幾份，目標數量自動對應。

學習語言最重要的一步，是開口說。別等到完全準備好才說話，在錯誤中積累的語感，比任何教材都有效率。

|||

閱讀是輸入，寫作是輸出，口說則是即時整合兩者的能力。每天花 15 分鐘進行影子跟讀，效果往往超乎預期。

|||

詞彙量決定表達的上限，而文法則是讓詞彙有序排列的工具。兩者缺一不可，但初學者可以先以溝通為目標，再逐步精確。

<!-- 來源容器（隱藏） -->
<div id="src-delim" style="display:none">
  <p>第一段落...</p>
  |||
  <p>第二段落...</p>
  |||
  <p>第三段落...</p>
</div>

<!-- 控制元件 -->
<text-splitter
  src="#src-delim"
  targets="#blk-d1, #blk-d2, #blk-d3"
></text-splitter>
範例 2

sentence 模式 — 自動依句子均分（預設模式）

以句末標點（。！？.!?）為單位，依字元數均衡分配至兩個區塊。
文字直接寫在 text 屬性。同時展示 font-size 與 color 的套用。 

<text-splitter
  mode="sentence"
  font-size="1.05rem"
  color="#DBEDD8"
  targets="#blk-s1, #blk-s2"
  text="在學習英語的路上……"
></text-splitter>
範例 3

paragraph 模式 — 區塊元素各自為單元，四欄分配

將 HTML 頂層區塊元素（<p>、<h2> 等）視為獨立段落單元， 按字元數均衡分配至四個欄位。目標欄可散落在頁面任意位置。

發音基礎

英語的音節結構與中文差異極大。母音的長短、子音的清濁，都直接影響溝通是否成功。建議在學習初期就投資時間在 KK 音標上。

字彙策略

詞彙的積累應以「頻率」為優先。掌握最常見的一千個單字，便能理解日常對話的絕大多數內容。使用間隔重複系統（SRS）效率最高。

聽力訓練

聽力是輸入的核心。大量接觸母語者的真實語音，而非教材中刻意放慢的語速，才能訓練出對「真實英語」的辨識能力。

口說練習

語言輸出不能只靠背誦，需要在真實情境中使用。即使找不到母語者，與 AI 對話或自言自語也是有效的練習方式。

<div id="src-para" style="display:none">
  <h2>發音基礎</h2><p>...</p>
  <h2>字彙策略</h2><p>...</p>
  <!-- 共 8 個頂層元素，分配到 4 欄 -->
</div>

<text-splitter
  src="#src-para"
  mode="paragraph"
  targets="#blk-p1, #blk-p2, #blk-p3, #blk-p4"
></text-splitter>
範例 4

跨位置散落 — 目標區塊不相鄰

第一區塊與第二區塊之間刻意插入其他頁面內容， 展示 targets 可指向頁面任意位置的元素。

↑ scatter-a　　　　 頁面的其他內容區域（可以是圖片、表格、廣告等任何元素）　　　　 scatter-b ↓
範例 5

自訂分割符號 — delimiter="---"

使用 delimiter 屬性改為 --- 作為切割符號。 

<text-splitter
  mode="delimiter"
  delimiter="---"
  targets="#blk-cust1, #blk-cust2"
  text="第一區：<strong>強調</strong>---第二區：<em>斜體</em>"
></text-splitter>
範例 6

互動展示 — JS API：setText() 與 clearOverride()

透過 el.setText(html) 動態更新內容並立即重新分割； el.clearOverride() 回復原始 text 屬性。
元件會在分割完成後發出 text-split 事件。

模式 分割符號 字色
text-split 事件 log： 
// 取得元件參考
const ts = document.querySelector('#ts-dyn');

// 動態更新文字
ts.setText('新內容 A |||新內容 B |||新內容 C');

// 回復原始 text 屬性
ts.clearOverride();

// 手動重新分割（如 DOM 已更新）
ts.split();

// 監聽分割完成事件
ts.addEventListener('text-split', e => {
  console.log(e.detail.parts);       // 各區塊 HTML 陣列
  console.log(e.detail.targetCount); // 目標區塊數
});
參考

全域設定 TextSplitter.config()

在載入元件後立即呼叫，可為所有 <text-splitter> 設定預設值， 個別元件的屬性值仍可覆蓋全域設定。 

// 引入元件
<script src="text-splitter.js"></script>

// 設定全域預設
TextSplitter.config({
  mode      : 'sentence',  // sentence | word | paragraph | delimiter
  delimiter : '|||',       // 強制切割符號
  trimEmpty : true,        // 是否去除空白段落
  balance   : 'char',      // 等分計算依據
  fontSize  : '1rem',      // 套用到目標區塊的字體大小
  color     : '#C6C7BD',   // 套用到目標區塊的文字色彩
});

// 回復所有預設值
TextSplitter.resetConfig();
屬性 預設值 說明
src—隱藏容器的 CSS 選擇器，取其 innerHTML 作為來源
text—直接傳入 HTML 字串（支援標籤）
targets—逗號分隔的目標區塊 CSS 選擇器，可散落頁面任意位置
modesentencesentence / word / paragraph / delimiter
delimiter|||強制切割符號；文字中含此符號時最優先使用
balancechar等分計算依據（目前支援 char）
trim-emptytrue是否略過空白段落
font-size—套用至每個目標區塊的字體大小
color—套用至每個目標區塊的文字色彩
