card-badge v2 · 品牌主題

需在同目錄放置 card-badge.js

安裝

<!-- 1. 載入 Bootstrap Icons（icon 功能用到時需要）--> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css"> <!-- 2. 載入元件（放在 </body> 前，或 head 加 defer）--> <script src="card-badge.js"></script>
元件採用 Light DOM，不使用 Shadow DOM，外部 CSS 可直接作用於 .badge 元素。每個實例透過 data-badge-id 屬性作 CSS 作用域隔離。

基本語法

<!-- 最簡單用法：文字 + 主題色 --> <card-badge theme="lavender" text="標籤"></card-badge> <!-- 加圖示 --> <card-badge theme="sky" icon="bi-bell" text="通知" size="re"></card-badge> <!-- 外框樣式：theme 加 -outline，或加 outline="true" --> <card-badge theme="safe-outline" text="完成"></card-badge> <card-badge theme="safe" outline="true" text="完成"></card-badge>

外觀（Appearance）

屬性值預設說明
themestringshell主題色。可用品牌色名稱（lavender、sky、safe…）或任意 hex。
加 -outline 後綴切換外框模式（如 sky-outline）。
outlinebooleanfalse外框樣式，與 theme="xxx-outline" 效果相同。
sizexs|sm|md|re|lg|xlre預設尺寸。re = 1.01rem / lg = 1.363rem / xl = 1.758rem。md 保留向後相容（0.838rem）。
font-sizestring—自訂字體大小，覆蓋 size 的字體設定。例如 "0.9rem"。
paddingstring—自訂內距，覆蓋 size 的間距設定。例如 "4px 14px"。
textstring—顯示文字內容。
iconstring—bi-xxx 顯示 Bootstrap Icon；其他字串（含 emoji）以 span 包裝顯示。
disabledbooleanfalse停用狀態：禁止點擊，顯示半透明灰色。

格式化類型（Type）

屬性值預設說明
typedate|time|datetime|deadline—格式化模式，需搭配 value 使用。
valuestring—格式化來源值。date → YYYY-MM-DD；time → HH:mm:ss；deadline → 日期字串。
formatstring—date 可選 YYYY-MM-DD / MM/DD / MM-DD；datetime 目前為 MM/DD HH:mm。
warning-daysnumber3deadline 類型：距截止日幾天內顯示黃色警告。逾期自動切換為紅色。

計數（Count）

屬性值預設說明
countnumber—設定此屬性進入計數模式。count=0 且 show-zero=false 時自動隱藏整個元件。
max-countnumber99超出此值顯示 N+（如 99+）。
show-zerobooleanfalsecount=0 時是否仍顯示 badge。
dot-modebooleanfalse小圓點模式：只顯示有色圓點，不顯示數字。
count-animatebooleantruecount 改變時的彈跳動畫。設 false 停用。

互動行為（Interactive）

屬性值預設說明
clickablebooleanfalse啟用點擊互動，hover 效果和 focus 光暈才會生效。
actionstring—點擊動作類型：filter / copy / rotate-content / rotate-self / rotate-self-auto / font-increase / font-decrease / font-reset
hover-effectlift|scale|glow|pulse|rotate|nonelifthover 動畫效果，需 clickable=true 或 toggle-target 才會啟用。
focus-colorstring同 theme鍵盤 focus 時光暈顏色，可用品牌色名稱或 hex。
hrefstring—點擊跳轉 URL。
href-targetstring_self連結開啟方式（_blank / _self 等）。
toggle-targetstring (id)—折疊目標元素的 id，點擊展開/收合。icon 自動旋轉 180°。
data-filterstring—搭配 action="filter"，過濾 data-filter-group 相符的元素。
removeselfbooleanfalse點擊後從 DOM 移除自身（淡出動畫）。
sourcestring (id)—copy 動作的來源元素 id。
targetstring (id)—copy / rotate-content 的目標元素 id。
copy-htmlbooleanfalsecopy 時複製 innerHTML 而非純文字。
font-controlstring (id)—字體大小控制目標 id，配合 action=font-increase/decrease/reset。
font-stepnumber2每次調整字體大小的步長（px），上限 32、下限 12。

提示訊息（Alert）

屬性值預設說明
alert-messagestring—點擊後在頁面顯示的浮動提示訊息。
alert-typeinfo|success|warning|dangerinfo提示樣式（顏色）。
alert-durationnumber4000提示顯示時長（毫秒）。
alert-positionstringtop顯示位置：top / top-left / top-right / bottom / bottom-left / bottom-right。
alert-sourcestring (id)—從指定元素讀取訊息文字（優先級低於 alert-message）。

輪播（Rotate）

屬性/元素值預設說明
action="rotate-self"——點擊時輪替自身的顯示（text/icon/theme 來自 <badge-item> 子元素）。
action="rotate-content"——點擊時把當前 badge-item 的 innerHTML 注入 target 元素。
action="rotate-self-auto"——自動輪播，點擊時展開當前項目到 target 元素。
intervalstring3s自動輪播間隔，支援 3s / 1.5s / 0.5m 格式。
<badge-item>——輪播子元素（隱藏）。屬性：text / icon / theme（可覆蓋父元件主題）。
