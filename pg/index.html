ui-progrid

緊湊的屬性面板元件。同一個標籤，用屬性在「教材資訊卡」和「後台表單」兩種用途之間切換。建立日期 2026-11-02。

即時調整

右側每個控制項都直接改左邊這張面板的屬性，事件會即時列在下方。

顯示在片頭字卡的名字，最多 20 字。 代表週一到週日，可選 1 至 4 天。

這一列示範 rating-mode="pick"：每一格獨立切換，值是陣列。

搭配 rating-min 與 rating-max 限制可選數量，超過時會跳出提示。

 
按上方按鈕查看回傳值

兩種用途

左邊是放在教材頁裡的唯讀資訊卡，右邊是後台填寫用的表單。差別只在屬性。

readonly density="compact" no-desc accent="violet"

This unit focuses on describing a change you experienced, with three model answers.

三組都可以接動名詞，示範句在第二張卡。

field-style="boxed" show-actions，加上 required 等驗證屬性

口說 寫作 字彙

試著直接按標題列的打勾圖示驗證，錯誤列會出現紅色左邊條，訊息顯示在底部說明區。

密度對照

同一份內容，compact 列高 24px，comfortable 列高 30px，loose 列高 42px。

density="compact"（24px）

density="comfortable"（30px，預設）

density="loose"（42px）

標記寫法

<ui-progrid heading="講者設定" field-style="boxed" show-actions>
  <pg-cat name="基本資料" numbering>
    <pg-row key="name" label="姓名" icon="person" required maxlength="20">
      <pg-desc>顯示在片頭字卡的名字，<b>最多 20 字</b>。</pg-desc>
    </pg-row>
    <pg-row key="role" label="身分" type="select" options="講師|助教|來賓"></pg-row>
    <pg-row key="level" label="分類" type="select" placeholder="請選擇">
      <pg-opt value="spk">口說</pg-opt>
      <pg-opt value="wrt">寫作</pg-opt>
    </pg-row>
  </pg-cat>
  <pg-cat name="系統" collapsed>
    <pg-row key="token" label="API 金鑰" type="secret" value="sk-..."></pg-row>
    <pg-row key="days" label="可錄影日" type="rating" rating-style="square" rating-count="7" value="1,3">
      <pg-note>顯示在這一列正下方的註解</pg-note>
      <pg-more>點「⋯」才會開啟的詳細說明，可寫 HTML</pg-more>
    </pg-row>
  </pg-cat>
</ui-progrid>

修改紀錄

第 2 版：密度改為三段（2026-11-02）

compact 由 18px 放寬為 24px，新增 loose 42px；comfortable 30px 維持預設。字級、控制項、開關與說明區留白都跟著三段同步調整。

  --pgx-row: 30px; --pgx-ctl: 24px; --pgx-px: 10px;
  --pgx-fs: 0.9rem; --pgx-fs-sm: 0.8rem; --pgx-ic: 0.95rem;
  --pgx-sw-w: 28px; --pgx-sw-h: 16px; --pgx-knob: 12px;
}
ui-progrid[density="compact"] {
  --pgx-row: 18px; --pgx-ctl: 16px; --pgx-px: 6px;
  --pgx-fs: 0.72rem; --pgx-fs-sm: 0.66rem; --pgx-ic: 0.72rem;
  --pgx-sw-w: 20px; --pgx-sw-h: 11px; --pgx-knob: 7px;
}
修改後

第 1 版：全新改寫（2026-11-02）

由舊版 property-grid-v69351 的 class 加 JSON 設定，改寫為 <ui-progrid> 語意標籤與子標籤，套用新配色。舊版欄位對照見下方表格。

屬性參考

<ui-progrid>

屬性說明
heading標題文字
densitycompact（24px）、comfortable（預設，30px）、loose（42px）
field-styleghost（預設）或 boxed
readonly整張唯讀
accent強調色，配色表名稱或色碼，預設 blue
label-ratio名稱欄比數值欄，例如 3:7，範圍 2:8 至 8:2
max-height屬性區最大高度（px）
no-desc隱藏底部說明區
show-actions顯示驗證與匯出圖示按鈕
silent不跳提示，只寫 console

<pg-cat>

屬性說明
name分類名稱
collapsed預設摺疊
color分類標題顏色，預設 violet
numbering自動編號，搭配 number-start、number-prefix、number-suffix、number-color

事件與方法

名稱說明
pg-change值改變，detail 含 key、value、old、source
pg-select選取列改變
pg-invalid某列驗證失敗
getValue／setValue單一欄位取值、設值，設值只更新該格
getValues()回傳 { key: value }
validate()驗證全部，回傳 { valid, errors }
toJSON(full)／download(full)取得或下載 JSON
collapse／collapseAll摺疊分類
rebuild(html)換一組子標籤重建

<pg-row>

屬性說明
key欄位代號，請保持唯一
label顯示名稱
typetext、number、select、date、date-roc、bool、rating、readonly、secret
value初始值；bool 寫 true／false，rating pick 寫 1,3，scale 寫數字
iconBootstrap Icons 名稱，person 或 bi-person
desc簡短純文字說明；要 HTML 用 <pg-desc>
unit數值後的單位
placeholder提示文字；select 會多一個空白選項
readonly／wrap此列唯讀／名稱允許換行
optionsselect 選項，以 | 分隔；值和文字不同時用 <pg-opt value>
on-text／off-textbool 開關旁的文字
rating-count項目數，預設 5，最多 10
rating-stylestar、circle、square、heart
rating-modepick（個別多選）或 scale（亮到第 N 個）
rating-min／rating-maxpick 為數量上下限，scale 為分數上下限
驗證required、min、max、minlength、maxlength、pattern、exact、min-date、max-date
