⑦ data-content-opacity 與 data-content-opacity-done

預設（0.9 / done 0.65）
📁 歸檔完成 done 狀態下內文透明度預設為 0.65，視覺上明顯偏暗。 ⚡ 執行中 一般狀態透明度預設為 0.9，略帶透明感。 🔒 待執行 尚未進入的步驟同樣套用 0.9 透明度。
data-content-opacity="1"（完全不透明）
📁 歸檔完成 done 狀態透明度設為 1，與其他步驟一致，不再變暗。 ⚡ 執行中 一般狀態透明度設為 1，文字完全清晰。 🔒 待執行 所有步驟的內文顏色與亮度完全一致。
data-content-opacity-done 未設定時，fallback 沿用 data-content-opacity 的值； 若兩者都未設定，才回到內建預設（0.9 / 0.65）。

屬性 API 一覽

屬性（data-*） CSS 變數 預設值 說明
data-compact-header — 未設定（關閉） 設於 bp-stepper：啟用所有步驟的單行 header 模式。
設於 bp-step：個別覆寫（="false" 可關閉）。
data-header-pad-y --bps-header-pad-y 2px header 行的上下 padding，控制 badge/icon/title 一行的緊湊程度。
data-header-gap --bps-header-gap 6px badge、icon、title 三者在同一行內的水平間距。
data-content-opacity --bps-content-opacity 0.9 bp-step-content 在一般與 active 狀態下的透明度。
設為 "1" 可完全取消透明效果。
也作為 data-content-opacity-done 未設定時的 fallback。
data-content-opacity-done --bps-content-opacity-done 0.65 bp-step-content 在 done 狀態下的透明度。
未設定時 fallback 至 data-content-opacity， 因此只需設定 data-content-opacity="1" 即可同時取消兩者。
