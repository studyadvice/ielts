<maze-quiz> 迷宮填空動畫元件 1.0.0

每次重新整理都會生成新的唯一解迷宮，從左下入口描繪路徑到右上出口，噴出彩帶後答案飛入空格。

迷宮以遞迴回溯法生成，屬於完美迷宮：任兩格之間只有一條路，因此入口到出口的路徑必定唯一。彩帶不使用透明度，改以縮小或落出畫面的方式退場。
快捷鍵：Ctrl + Shift + 數字鍵盤 5，啟動目前畫面中露出最多的迷宮。

範例一：基本用法（預設 10 × 12）初版

捲動到畫面中自動播放。按「重播」重畫同一條路徑，按「換一個迷宮」生成新迷宮。

範例二：題庫隨機出題，寬版 18 × 11，加快速度初版

元件內放 JSON 題庫，每次重新整理或換迷宮都會隨機換題，不會連續出現同一題。

範例三：手動開始，小迷宮 6 × 6，固定種子初版

設定 autoplay="false" 後需按「開始解謎」或快捷鍵。設定 seed 後每次重新整理的第一個迷宮都相同，方便上課固定版面。

範例四：外部題目面板，指定迷宮寬度，路徑漸層修改一

迷宮設定 id="m4"、maze-width="420"、route-colors="#51DBCF,#FF91D7"、controls="maze"。右側課堂卡片裡的 <maze-quiz-panel for="m4"> 就是它的題目區，答案標籤和彩帶會依迷宮大小等比縮小。

Unit 3：Daily Routines

這張卡片是一般網頁內容，題目面板可以放在任何位置，例如課文說明的下方。

面板之後也可以繼續放其他內容。

範例五：固定每格大小，按鈕放在迷宮下方修改一

設定 cell-size="24"，迷宮寬度依格數自動計算為 16 × 24 加上外框留白。路徑漸層為 #E3D322,#FF2E63。

範例六：面板放在頁面最底部，示範自動捲動修改一

這個迷宮的題目面板放在本頁最底部。按「開始解謎」或快捷鍵後，答案從出口跳出時會自動平滑捲動到底部的空格再飛進去。

範例七：自訂按鈕文字與尺寸，跳過彩帶，開始前隱藏迷宮修改二

設定 label-play="Start!"、label-replay="Again"、play-size="lg"、confetti="false"、hide-until-play。按下開始後，迷宮從左下入口展開，抵達出口時不噴彩帶，答案直接跳出。

範例八：數字尺寸、色票名稱漸層、自訂遮罩文字修改二

設定 play-size="1.5"（字級 1.5rem，內距等比放大）、label-play="走迷宮"、label-cover="準備好了嗎？按下走迷宮"、route-colors="energetic,violet"，保留彩帶。

標籤／事件／方法說明
<maze-quiz-panel for>修改一外部題目面板，for 填迷宮的 id，可放在同一網頁任何位置。沒有對應面板時，迷宮維持內建左右版面。

answer-revealed答案填入空格時觸發，右下角的通知就是監聽這個事件。

play()播放或重播目前的迷宮。
regenerate(autoPlay)生成新迷宮，題庫模式下同時換題。

修改紀錄與程式碼對照

開發過程經過兩次修改，全部收錄在正式版本 1.0.0。每次修改都相容先前的寫法，不需改動既有頁面。

修改一

1. 快捷鍵 Ctrl + Shift + 數字鍵盤 5

以實體按鍵位置判斷，不論 NumLock 開關都能觸發；同頁多個迷宮時啟動露出面積最大的那一個。

初版
// 只能按按鈕開始
this.$play.addEventListener('click', () => this.play());
修改一
document.addEventListener('keydown', (e) => {
  if (e.repeat || !e.ctrlKey || e.altKey || e.metaKey
      || e.code !== 'Numpad5') return;
  if (!e.shiftKey && e.key !== 'Clear') return;
  // 找出畫面中露出面積最大的迷宮
  let best = null, bestArea = 0;
  for (const m of INSTANCES) { ...計算可見面積... }
  if (!best) return;
  e.preventDefault();
  best.play();
});

2. 路徑雙色漸層 route-colors

路徑會來回彎折，一般空間漸層會忽深忽淺，所以改為沿路徑長度切成 72 段插值上色，再用遮罩控制描繪進度。

初版
<!-- 單色路徑，直接對路徑做描繪動畫 -->

      stroke="#51DBCF" .../>

route.style.strokeDashoffset = L - len;
修改一
<mask id="mq-mask-1">
  <path class="mq-reveal" d="..." stroke="#FFFFFF" .../>
</mask>
<g class="mq-route" mask="url(#mq-mask-1)">
  <path d="第 1 段" stroke="#51DBCF"/>
  ...
  <path d="第 72 段" stroke="#FF91D7"/>
</g>

reveal.style.strokeDashoffset = L - len;

4. 迷宮寬度 maze-width 與 cell-size，答案標籤與彩帶等比縮放

以迷宮實際顯示尺寸計算縮放倍率（基準 560px，範圍 0.4 到 1.25 倍），套用到答案標籤字級、內距與彩帶大小；線條另設最細下限，迷宮很小時仍看得清楚。

初版
/* 迷宮與題目區固定 3 比 2，高度上限 72vh */
maze-quiz .mq-stage{flex:3 1 0}
maze-quiz .mq-svg{max-height:72vh}

/* 答案標籤固定大小 */
.maze-quiz-chip{font-size:1.75rem;padding:8px 22px}
修改一
<maze-quiz maze-width="420">
<maze-quiz cell-size="24">

this._k = clamp(迷宮顯示尺寸 / 560, 0.4, 1.25);
chip.style.fontSize = (1.75 * k) + 'rem';
chip.style.padding = `${8 * k}px ${22 * k}px`;
Confetti.burst(x, y, { size: k });
