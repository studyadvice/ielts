chunk-demo v4 — 翻譯行功能

選取不同等級，句子與翻譯同步更新。

範例一：日常行程句

walk ride my bike take the bus school the park the supermarket every day every week sometimes

範例二：只顯示翻譯行（不搭配整句預覽）

cried laughed stayed silent was sad was happy felt confused

範例三：遮罩模式 mask-mode 搭配翻譯

city beach forest busy peaceful vast vibrant relaxing mysterious

v4 新增 API 一覽

屬性／位置 值 說明
<chunk-demo>
translation		 字串，含 {id} 佔位 翻譯句模板，佔位符與 sentence 相同
<chunk-demo>
show-translation		 true | false 是否顯示翻譯行，預設 false
<cd-level>
trans		 字串 該等級對應的翻譯詞；未設定時退回顯示英文 text
ChunkDemoConfig
.translationColor		 CSS 色彩字串 翻譯文字顏色，預設 #8C9088
ChunkDemoConfig
.translationBorderColor		 CSS 色彩字串 翻譯行左側線顏色，預設跟隨主題 border 色
<!-- 最小寫法 --> <chunk-demo sentence="I {1} every day." translation="我每天{1}。" show-translation="true"> <cd-chunk id="1" label="動詞"> <cd-level level="1" trans="走路">walk</cd-level> <cd-level level="2" trans="騎腳踏車">ride my bike</cd-level> </cd-chunk> </chunk-demo>
