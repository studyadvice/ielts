v1 別名向下相容

v1 color 值 v2 實際對應 顏色 說明
accent lavender ● #C3A5E5 原始預設強調色
correct safe ● #27AE60 正確答案綠
wrong wrong（直接對應） ● #E6374B 錯誤/警告紅
warning yellow（黃色，bp-notice 原行為保留） ● #E3D322 注意黃（bp-notice 專屬語意）
special special（直接對應） ● #B3DE73 特殊/強調綠
note yellow ● #E3D322 注記黃（別名）
success safe ● #27AE60 成功綠（別名）
highlight special ● #B3DE73 螢光綠（別名）

所有 v1 別名都可直接繼續使用，行為與 v1 完全相同。
注意：bp-popnote THEMES 的 warning 代表紅色（獨立命名空間），與 bp-notice 的 color="warning"（黃色）不同，兩者互不影響。

事後標注 API（BpPopnote.annotate）

PDO（PHP Data Objects）是 PHP 內建的資料庫抽象層，支援多種資料庫驅動。 使用 prepared statement 可有效防止 SQL 注入攻擊。 設定時區可確保所有 SQL 時間操作以台北時間（UTC+8）為基準。

全域設定範例

// ── bp-notice 設定 ──────────────────────────────
BpNotice.config.stickyOffset = '64px';     // 避開 navbar
BpNotice.config.theme.accent  = '#FF91D7';  // 覆寫預設邊框色
BpNotice.config.theme.ctaBg   = '#0DA591';
BpNotice._reCSS();                            // 重新注入 CSS

// ── bp-notice 程式操作 ──────────────────────────
BpNotice.show('notice-id');              // 重新顯示（清除記憶）
BpNotice.close('notice-id');             // 關閉
BpNotice.setContent('notice-id', html);  // 動態更新內容
BpNotice.init();                             // 掃描新增的 <bp-notice>

// ── bp-popnote 設定 ─────────────────────────────
PopoverConfig.set({
  theme      : 'sky',
  placement  : 'bottom',
  maxWidth   : '400px',
  borderStyle: 'dashed',
  carousel   : { animation: 'crossfade', interval: 5000 },
  modal      : 'dialog',
  modalSize  : 'lg',
});

PopoverConfig.addTheme('brand', {
  bg         : '#100820',
  titleColor : '#A080FF',
  borderColor: '#A080FF',
});

// ── 共用調色盤 ──────────────────────────────────
console.log(BpNotice.palette);  // { lavender, sky, ocean, ... }
