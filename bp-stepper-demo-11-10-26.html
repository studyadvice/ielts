bp-stepper 範例

橫向或縱向的步驟流程元件：多種主題、完成與錯誤狀態、單行標題、逐步推進按鈕，以及自訂呼叫按鈕。每個範例左邊是實際效果，右邊是對應的程式碼。建立日期 11-10-26，合併並改寫自 bp-stepper-demo.html、bp-stepper-demo-10-19-26.html、bp-stepper-demo-singleheader.html、bp-stepper-progress-demo.html。

一、基本與狀態 二、主題 三、連接線 四、縱向版型 五、自訂外觀 六、單行標題 七、內文透明度 八、逐步推進 九、逐步揭示 十、自訂呼叫按鈕 十一、標題、換行與點選 十二、JavaScript API 屬性參考

範例一：基本用法與三種狀態

不加任何屬性時使用預設外觀（violet）。步驟寫 data-state="done"、"active" 或 "error"，編號徽章會分別變成 ✓、數字與 !。

範例二：主題

data-theme 可用 17 色的任一色名，一次決定主色、進行中、完成與標題顏色。下面列出其中八種，其餘見文末色票。

範例三：連接線樣式

data-connector 可用 solid（預設）、dashed、dotted。data-stroke 調整線條粗細，data-arrow-size 調整箭頭大小。

範例四：縱向版型

data-layout="vertical" 改為上下排列。縱向時 data-card-width 是卡片的固定寬度；不寫則填滿容器。

範例五：自訂外觀

每個 data-* 都能單獨覆寫，不必依賴主題。顏色可以寫色名（例如 energetic）或色碼；只改了進行中、完成或錯誤的顏色時，卡片背景會自動配合。

範例六：單行標題 compact-header

data-compact-header 把編號、圖示與標題排成一行，下方加一條隨狀態變色的漸層細線。個別步驟寫 data-compact-header="false" 可恢復原本排版；data-header-pad-y 與 data-header-gap 調整這一行的上下內距與間距。圖示寫在 <span class="bp-step-icon"> 裡，沒有圖示時只排編號與標題。

範例七：內文透明度

data-content-opacity 控制一般與進行中步驟的內文透明度（預設 0.9），data-content-opacity-done 控制完成步驟（預設 0.65）。後者沒寫時沿用前者，所以只寫 data-content-opacity="1" 就能讓所有內文都不透明。

範例八：逐步推進 progress

data-mode="progress" 在每張卡片右下角放一顆推進按鈕，按下後這一步完成、下一步變成進行中。按鈕可以只有圖示（預設 ›）、只有文字，或圖示加文字；最後一步改用 data-progress-done-icon 與 data-progress-done-text。個別步驟也能覆寫圖示與文字，data-prog-btn-size 調整按鈕大小。下方灰色列顯示 bps:change 與 bps:complete 事件。

範例九：逐步揭示 progress-show

data-mode="progress-show" 一開始只顯示第一步，按下推進按鈕，下一步才帶著動畫出現；縱向時由下往上滑入。data-show-ending 指定一個元素的 id，最後一步按下後才顯示它。

範例十：自訂呼叫按鈕 btn-js

任一步驟寫 btn-js="JavaScript 運算式"，卡片左下角就會出現一顆按鈕，顏色跟著主題與狀態。運算式裡可以直接用 step（這個步驟）、stepper（整個元件）與 BPStepper。btn-js-label 是按鈕文字，btn-js-icon-class 是圖示；文字留空時按鈕變成正圓形。可以和 progress 的推進按鈕並存。範例裡的 demoAlert() 與 showStepInfo() 是本頁定義的函式。

範例十一：內建標題、換行、連接線標籤與點選切換

data-ui-title 把標題放進元件裡（可寫 HTML），data-wrap="3" 每列三步、第四步起轉彎換到下一列，data-connector-label 在連接線上加文字（步驟上也能個別寫），data-clickable="true" 讓步驟可以點選或用 Enter 切換。

範例十二：JavaScript API

BPStepper.setActive(el, i) 把第 i 步設為進行中、前面全部完成；i 等於步驟數時全部完成並觸發 bps:complete。setError(el, i) 標記錯誤，resetStates(el) 清除所有狀態。結果用 Bootstrap alert 顯示在右上角。

屬性參考

bp-stepper：版型與功能

屬性預設說明
data-theme無（violet）主題，17 色的任一色名。
data-layout橫向vertical 改為縱向。
data-connectorsolid連接線樣式：solid、dashed、dotted。也可寫 data-connector-style。
data-auto-numbertrue自動加上編號徽章，false 關閉。
data-compact-header關閉編號、圖示、標題排成一行。步驟上寫 ="false" 可個別關閉。
data-header-pad-y2px單行標題的上下內距。
data-header-gap6px單行標題內編號、圖示、標題的間距。
data-content-opacity0.9一般與進行中步驟的內文透明度，也是下一項沒寫時的預設。
data-content-opacity-done0.65完成步驟的內文透明度。
data-ui-title無放在元件內的標題，可寫 HTML。搭配 data-ui-title-fs（字級）、data-ui-title-pb（下內距）、data-ui-title-gap（與步驟的距離，預設 8px）。
data-wrap無每列幾步，超過的步驟轉彎換到下一列。
data-clickable無true 時可點選步驟或按 Enter 切換。
data-connector-label無連接線上的文字；寫在步驟上只影響該步。data-connector-label-color 調整顏色。
data-mode無progress 逐步推進、progress-show 逐步揭示。也可寫 mode。
data-show-ending無元素 id。最後一步按下推進按鈕後才顯示，resetStates() 會再隱藏。

bp-stepper：推進按鈕（progress、progress-show）

屬性預設說明
data-progress-icon›按鈕圖示文字或 HTML，留空則不顯示圖示。
data-progress-icon-class無圖示 class，例如 bi bi-arrow-right，優先於上一項。
data-progress-text無按鈕文字；圖示與文字都有時兩者並排，只有圖示時是圓形按鈕。
data-progress-done-icon、data-progress-done-icon-class、data-progress-done-text同上最後一步按鈕的圖示與文字，沒寫時沿用一般按鈕。
data-progress-hide-lastfalse最後一步不放按鈕。
data-prog-btn-size28px按鈕高度（圓形時為直徑）。btn-js 按鈕也用這個大小。

bp-stepper：顏色與尺寸

屬性預設說明
data-color#B484E8主色：邊框、連接線、徽章外框。顏色類屬性都能寫色名。
data-color-active、data-color-done、data-color-error依主題進行中、完成、錯誤的顏色；改了之後對應的卡片背景自動配合。
data-title-color、data-text-color依主題標題與內文顏色。
data-badge-bg依主題編號徽章背景。
data-card-bg、data-card-bg-active、data-card-bg-done、data-card-bg-error依主題各狀態的卡片背景，寫了就不再自動配合。
data-card-width220px卡片寬度；縱向時不寫則填滿容器。
data-card-padding8px卡片內距。
data-gap36px步驟間距，也就是連接線長度。
data-stroke2px邊框與連接線粗細。
data-radius12px卡片圓角。
data-arrow-size、data-arrow-min-len6px、0px箭頭大小與連接線最短長度。
data-badge-size、data-badge-font-size28px、0.82rem編號徽章大小與字級。
data-title-size、data-font-size1rem、0.9rem標題與內文字級。
data-pad-top、data-pad-bottom、data-pad-x8px元件外圍內距。

bp-step

屬性或子元素預設說明
data-state無done、active、error。
<bp-step-title>、<bp-step-content>無標題與內文。
<span class="bp-step-icon">無步驟圖示，可放 Bootstrap Icons。
data-compact-header沿用元件個別開關單行標題。
data-progress-icon、data-progress-icon-class、data-progress-text沿用元件個別覆寫這一步的推進按鈕。
data-connector-label、data-connector-label-color沿用元件這一步連接線上的文字與顏色。
btn-js無按下時執行的 JavaScript 運算式，可用 step、stepper、BPStepper。
btn-js-label執行按鈕文字，空字串時是圓形圖示按鈕。
btn-js-icon-class、btn-js-icon無圖示 class，或圖示 HTML；前者優先。

JavaScript API 與事件

名稱說明
BPStepper.setActive(el, i)第 i 步設為進行中，前面全部完成；i 等於步驟數時全部完成。
BPStepper.setError(el, i)第 i 步標記為錯誤。
BPStepper.resetStates(el)清除所有狀態；progress-show 會再隱藏後續步驟。
BPStepper.progressShowNext(el, i)progress-show 模式下從第 i 步揭示下一步。
BPStepper.init(root)初始化 root 內的元件，動態加入時使用。
BPStepper.defaults、THEMES、BRAND全域預設、主題表與色票，載入後可修改 defaults 改變全站預設。
bps:change切換步驟時觸發，e.detail 含 index、prevIndex、el。
bps:complete全部完成時觸發。
