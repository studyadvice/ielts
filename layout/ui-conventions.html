ui 元件共同約定

適用 ui-drill、ui-steps、ui-cards 及之後的新元件。學會一個元件，其他元件的屬性就能直接套用。

一、內容來源約定

屬性說明
source指向 div 或 template 的 id，填入元件的主要內容區。
detail指向 id，填入元件的細節區。項目本身、或已顯示的內容裡的任何元素都可以帶這個屬性。
detail-title寫在觸發元素上，覆蓋細節區標題。
  • 內容一律複製，來源用加上 hidden 的 div，或 template。
  • 同一份來源可被多個元件、多個項目共用。
  • 找不到 id 時，在該區顯示紅框警告，不會中斷其他功能。
  • 帶 detail 的元素會自動套用按鈕樣式；已有 Bootstrap 的 btn 類別時不覆蓋。

二、外觀約定

屬性說明
title容器標題，顯示在元件頂端。讀取後會從元素移除，避免出現瀏覽器原生提示。
label項目名稱。
note項目的次要說明文字。
tooltip滑鼠提示。
iconBootstrap 圖示，star-fill 或 bi-star-fill 皆可。
badge角標文字。
bordered外框。
divider分隔線：solid、dashed、dotted、none。
gap、padding、size、height、min-height、*-width數字，單位一律是 px。
icon-size數字，單位是 rem。
color、accent、icon-color、*-color可填配色名稱或色碼。accent 一律表示選中或目前狀態的顏色。
columns區塊比例，例如 2,5,5。
cols每列項目數量。
placeholder尚未選擇時的提示，設空字串則不顯示。
arrows 系列arrows、arrow-size、arrow-shape、arrow-style、arrow-icon、arrow-color、arrow-active-color，所有元件共用同一組名稱與值。

區域性的屬性加上區域前綴，例如 tile-、node-、card-、panel-、arrow-、rightup-。看到前綴就知道它作用在哪個區域，後半段的意思和通用屬性相同。

配色名稱： shell violet blue warning energetic blue green green vanilla yellow focus green info indigo pink dreamy

三、互動約定

屬性說明
trigger項目觸發方式：click、hover。
detail-trigger內容裡帶 detail 的元素觸發方式：click、hover。
toggle寫在容器上，再點一次已選項目時取消；寫在觸發元素上，再點一次收起細節。
active初始選中的項目，值為該項目的 source。
active-detail初始開啟的細節，值為 detail 的 id。
disabled停用項目或按鈕。
href、target項目改為連結，不開啟內容。
  • 屬性只在載入時讀取一次，之後修改屬性不會更新畫面。
  • 純標籤操作，不提供事件與方法。
  • 沒有切換動畫。
  • 元件可以放在其他元件的內容來源裡，複製出來時會自動建立，可一層一層嵌套。
