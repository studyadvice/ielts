<ui-drill> template 快速分欄

source 或 detail 指向的 <template> 裡，一行寫上 | 就會自動分欄；連續幾行共用欄位、上下對齊。分欄內可以放 detail 按鈕。沒有 | 的 template 完全不受影響。

範例 1：單字表（中欄）與對照（右欄）

中欄每行三欄：單字、中文、例句按鈕，欄寬用 cols="auto 1fr auto"。右欄是錯誤與正確的對照，加上欄間虛線。

<ui-drill title="Speaking 主題字彙" accent="key" split-divider-color="calm" …>
  <drill-tile icon="house" label="居住" source="v-home"></drill-tile>
  <drill-tile icon="briefcase" label="工作" source="v-work"></drill-tile>
</ui-drill>

<template id="v-home" cols="auto 1fr auto">
  <b>cosy</b> | 溫馨舒適 | <button detail="e-cosy" label="cosy">例句</button>
  <b>spacious</b> | 寬敞 | <button detail="e-spacious" label="spacious">例句</button>
  <b>in the suburbs</b> | 在郊區 | <button detail="e-suburbs" label="in the suburbs">例句</button>
</template>

<template id="e-cosy" col-divider="dashed">
  <c-red>My room is very warm and good.</c-red> | <c-green>My room is small but cosy.</c-green>
  太籠統 | 一個字就有畫面
</template>

範例 2：不受影響與關閉分欄

「說明」的 template 沒有 |，照原樣顯示。「符號」的 template 加了 split="false"，| 照字面顯示；也可以在一般 template 裡寫 \| 顯示直線本身。

<template id="o-plain">
  <p>這個 template 沒有直線，所以完全照原樣顯示。</p>
</template>

<template id="o-nosplit" split="false">
  <p>Unix 管線：cat notes.txt | grep IELTS</p>
</template>

新增屬性

屬性預設值說明
|（template 內容）一行內用 | 分欄。一行是 template 裡的一個換行，或一個 <p>、<div> 區塊。連續含 | 的行共用欄位；欄數不同時，較短那行最後一欄延伸到底。\| 顯示直線本身。只作用於 <template>，一般元素來源不分欄。
splittrue寫在 ui-drill 上，設為 false 關閉分欄。template 上也可寫 split="false" 單獨關閉。
split-cols（等寬）欄寬，寫法同 CSS grid-template-columns，例如 auto 1fr auto。template 上用 cols 覆蓋。
split-dividernone欄間直線：none、solid、dashed、dotted。template 上用 col-divider 覆蓋。
split-divider-coloraccent欄間直線顏色，可用色票名稱。
split-col-gap、split-row-gap16、6欄距、列距（px）。
