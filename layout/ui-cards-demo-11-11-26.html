ui-cards：翻面牌組 flip-deck

有 auto-flip 的翻面卡片，可以把連續 N 張合成同一格：翻面後倒數結束（或點擊翻回），這一格直接換成下一張的正面，右下角顯示「目前 / 總數」。 不寫 flip-deck 或寫 flip-deck="false" 時維持原狀，每張各佔一格。 格子高度取組內最高的一張，換張時版面不會跳動。

同一組六張單字卡：維持現狀 vs 合併成牌組

不寫 flip-deck（六張各佔一格）

flip-deck="3"（每三張合成一格）

ui-cards:deck 事件會顯示在這裡。

flip-deck="all"、deck-start 與 deck-loop="false"

  • flip-deck="all"：連續、有 auto-flip 的卡片全部合成一格。
  • deck-start：寫在卡片上，從這張另起一組，所以 Part 1 與 Part 2 分成兩格。
  • 最後一張「Part 3」寫了 auto-flip="0"，不符合條件，維持獨立一格。卡片也可以寫 flip-deck="false" 排除自己。
  • deck-loop="false"：最後一張翻回後停在那張的正面，不會回到第一張。

程式碼對照

原本（每張各佔一格）

<ui-cards cols="3" auto-flip="2500" flip-toggle>
  <card-item label="mitigate" back="減輕"></card-item>
  <card-item label="pervasive" back="普遍的"></card-item>
  <card-item label="resilient" back="有韌性的"></card-item>
</ui-cards>

11-11-26（三張合成一格）

<ui-cards cols="3" auto-flip="2500" flip-toggle
  flip-deck="3">          <!-- 2 以上的整數或 all；false 為維持原狀 -->
  <card-item label="mitigate" back="減輕"></card-item>
  <card-item label="pervasive" back="普遍的"></card-item>
  <card-item label="resilient" back="有韌性的"></card-item>
</ui-cards>

<!-- 其他屬性 -->
deck-loop="false"     最後一張翻回後停住（預設回到第一張）
deck-counter="false"  不顯示「目前 / 總數」
<card-item deck-start>      從這張另起一組
<card-item flip-deck="false"> 這張不參與合併

// API 與事件
uc.resetDecks();   // 全部回到第一張的正面
uc.decks;          // [{ cards, index }, ...]
uc.flip(4);        // 牌組裡的卡片會先換到那一張再翻面
uc.addEventListener('ui-cards:deck', e => e.detail); // { card, index, total, from }
