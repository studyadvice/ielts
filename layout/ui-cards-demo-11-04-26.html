修改三：顯示按鈕（reveal）

按鈕文字就是按鈕內容，可自由填寫。按下後讓指定 id 的隱藏區塊顯示；加上 remove-cards 會連同按鈕所在的整個 ui-cards 一起移除。

範例 A：只顯示目標，保留卡片

語塊組合，自由造句
A tiny apartment on the fifth floor of a fifteen-year-old building, conveniently located near the MRT station.

範例 B：顯示目標並移除整個 ui-cards

練習一：把 conveniently located 放進「你常去的咖啡店」這一題。

範例 A 程式碼

<button reveal="reveal-a" color="special">看完整示範</button>

<div id="reveal-a" hidden>...</div>

範例 B 程式碼

<button reveal="reveal-b" remove-cards color="lavender">開始練習</button>

<div id="reveal-b" style="display: none;">...</div>

新增屬性一覽

屬性作用預設值寫法
panel-title-size內容區標題字級1.1rem純數字視為 rem，例如 1.65；也可寫 24px、clamp() 等
panel-title-color內容區標題文字色，未設定底線色時底線跟著改lavender色盤名稱或色碼
panel-title-line內容區標題底線色；寫 none 移除底線同標題文字色色盤名稱、色碼或 none
title-size元件大標題（title 屬性）字級1.2rem同 panel-title-size
title-color元件大標題文字色lavender色盤名稱或色碼
reveal（按鈕）按下後顯示此 id 的區塊，支援 hidden、display: none、d-none 三種隱藏方式無目標 id
remove-cards（按鈕）顯示目標後移除按鈕所在的整個 ui-cards不移除寫上屬性即啟用
reveal-scroll（按鈕）顯示後平滑捲動到目標區塊不捲動寫上屬性即啟用
color（按鈕）按鈕底色，與 detail 按鈕相同button-color 或 ocean色盤名稱或色碼
