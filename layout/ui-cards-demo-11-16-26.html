<ui-cards>：卡片蓋章 stamp

在 card-item 寫 stamp，點卡片時章落在卡片正中央。墨跡效果同 ui-play 的 stamp-fx，沒有聲音。只用在一般卡片的正面，與翻面卡片互斥。前一版範例見 ui-cards-demo-11-11-26.html。

範例 1 到 3屬性總覽版本對照

範例

範例 1：點卡片蓋章

每張卡片各自設定章的文字與顏色。章蓋上後一直留著，再點也不會重複蓋。

<ui-cards id="c1" cols="3" panel="none" stamp-color="red" title="Part 1 題型判斷：哪一個是 Part 1 的題目？">
  <card-item label="Do you like reading?" note="點卡片作答" stamp="正確" stamp-color="green" stamp-icon="check2"></card-item>
  <card-item label="Describe a book you read." note="點卡片作答" stamp="Part 2"></card-item>
  <card-item label="Should schools ban phones?" note="點卡片作答" stamp="Part 3"></card-item>
</ui-cards>

範例 2：stamp-stay 存續時間

ui-cards 上寫的 stamp、stamp-color、stamp-stay 是整組預設值。錯的選項 1.5 秒後章淡出，可以再點一次重新蓋；obtain 設 stamp-stay="0"，一直留著。

<ui-cards id="c2" cols="4" panel="none" stamp="再想想" stamp-color="playful" stamp-stay="1500" title="哪個字最正式？（錯的章 1.5 秒後消失）">
  <card-item label="get"></card-item>
  <card-item label="obtain" stamp="正式" stamp-color="key" stamp-stay="0" stamp-shape="circle"></card-item>
  <card-item label="grab"></card-item>
  <card-item label="pick up"></card-item>
</ui-cards>

範例 3：stamp()、unstamp() 與翻面卡片

錄影時用程式控制蓋章時機。翻面卡片與蓋章互斥，第三張不會蓋章。

事件會顯示在這裡。
<ui-cards id="c3" cols="2" panel="none" stamp-rotate="random" stamp-size="2rem">
  <card-item label="Band 7 範文" stamp="7.0" stamp-color="green"></card-item>
  <card-item label="Band 5 範文" stamp="5.0" stamp-color="red" stamp-offset-y="10"></card-item>
  <!-- 有 back 的翻面卡片不能蓋章，主控台會提示 -->
  <card-item label="翻面卡片" back="…" stamp="不會出現"></card-item>
</ui-cards>

<script>
  const c3 = document.getElementById('c3');
  c3.stamp(0);      // 用索引或卡片元素
  c3.unstamp();     // 省略參數時移除全部
  c3.addEventListener('ui-cards:stamp', (e) => console.log(e.detail));   // { card, index, text }
</script>

屬性總覽

蓋章屬性（寫在 card-item 上；寫在 ui-cards 上為整組預設值，卡片上的設定優先）

屬性預設說明
stamp無章上的文字，用 | 分行。有寫才能蓋章。
stamp-colorred章的顏色，可用色名或色碼。
stamp-icon無Bootstrap Icons 名稱，check2 或 bi-check2 都可以。
stamp-shaperoundrect、round、circle、ellipse。
stamp-size1.4rem字級，只寫數字時單位為 rem。
stamp-rotate-8旋轉角度；random 在正負 12 度之間隨機。
stamp-offset-x、stamp-offset-y0從卡片正中央微調位置（px）。
自動縮小章（含旋轉）比卡片大時，自動縮小到卡片的 92% 以內，不會被裁切。
stamp-stay0存續時間（毫秒）。0 為一直留著；大於 0 時時間到淡出移除，之後可以再點一次重新蓋。

規則、方法與事件

項目說明
適用卡片只蓋在一般卡片的正面。有 back 或 back-source 的翻面卡片（含 flip-deck 牌組）不能蓋章，卡片上寫了 stamp 會在主控台提示。
點擊點卡片本身就蓋章；點卡片裡的按鈕、連結、輸入框不蓋。detail、href 照常運作。disabled 的卡片不蓋。
stamp(卡片或索引)蓋章，回傳 true／false。已經有章時不重複蓋。
unstamp(卡片或索引)移除章；省略參數時移除全部。
ui-cards:stamp蓋章時觸發，detail 為 { card, index, text }，會冒泡。
聲音沒有聲音。落章時卡片輕微震動。

版本對照

修改前：卡片沒有蓋章功能

<card-item label="Do you like reading?"></card-item>

修改後：加上 stamp 屬性，點擊蓋章

<card-item label="Do you like reading?"
           stamp="正確" stamp-color="green" stamp-icon="check2"></card-item>
項目修改前修改後

方法flip()、unflipAll()、resetDecks()新增 stamp()、unstamp()
事件ui-cards:reveal、ui-cards:flip、ui-cards:deck新增 ui-cards:stamp
其他屬性、方法、事件都沒有改動
