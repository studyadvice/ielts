<ui-steps> 流程與時間軸元件

步驟可橫向或直向排列，用連接線與箭頭串起來。帶 source 的步驟可在內容區顯示內容，內容裡帶 detail 的元素在下方細節區顯示更多。屬性約定見 ui-conventions.html。

版本紀錄

v1.0（11-03-26）　初版。

範例一：橫向訂單流程

current="3" 讓前兩步自動成為完成、第三步為目前；完成的步驟改顯示 done-icon。已走過的連接線與箭頭使用啟用色。點擊步驟顯示內容，內容中的按鈕在下方開啟細節。


  

  
  
範例二：直向時間軸，內容區在右側

  
direction="vertical" 時，內容區放在右側，比例由 columns 決定。用 status 個別指定狀態，用 color 個別上色；含停用步驟與外部連結步驟。連接線改用虛線，長度固定。

  

  

  

  
  
範例三：純進度條，不帶內容

  
步驟都沒有 source 時，不會建立內容區，只顯示進度。用 label-width 讓每一步等寬，箭頭改成圓框三角形。

  

  

  

  
  
屬性一覽


  
容器 <ui-steps>

  

    
屬性預設說明

    
      
title無元件標題

      
directionhorizontalhorizontal（橫向，內容在下）、vertical（直向，內容在右）

      
columns4,8直向時步驟與內容區的比例

      
current無目前步驟（從 1 起算），之前的自動成為完成

      
numbered否沒有圖示的節點顯示序號

      
done-icon無完成步驟改顯示的圖示

      
node-size48節點尺寸（px）

      
node-shapecirclecircle、rounded、square

      
icon-size1.3圖示大小（rem）

      
colorshell未完成節點顏色

      
accentblue目前步驟顏色

      
done-colorgreen完成步驟顏色

      
icon-color底層背景色圖示與序號顏色

      
label-width自動橫向時每一步寬度（px）

      
line不顯示連接線：solid、dashed、dotted

      
line-width2連接線粗細（px）

      
line-colorshell連接線顏色

      
line-active-color同 accent已走過的連接線顏色

      
connector-length48連接段最短長度（px）

      
compact否連接段固定為 connector-length，不延展

      
arrows不顯示連接段中央顯示箭頭，直向時自動朝下

      
arrow-size、arrow-shape、arrow-style、arrow-icon、arrow-color、arrow-active-color20、arrow、plain、無、shell、accent與 ui-drill 相同

      
gap24步驟區與內容區距離（px）

      
padding16外框內距（px）

      
bordered否外框與內容區分隔線

      
panel-title無內容區標題，可用 {label}

      
detail-title無細節區預設標題

      
panel-height無內容區最大高度（px），超出時捲動

      
placeholder請點選步驟。未選擇時的提示

      
active、active-detail無初始選取的 source、初始開啟的 detail

      
trigger、detail-triggerclickclick、hover

      
toggle否再點一次已選步驟時取消

      
button-colorblue內容中帶 detail 元素的預設配色

    
  


  
步驟 <step-item>

  

    
屬性說明

    
      
label、note、tooltip名稱、次要文字、滑鼠提示

      
icon、badge圖示、角標

      
statusdone、current、todo，優先於 current

      
color、icon-color本步驟節點顏色（不論狀態）、圖示顏色

      
source內容區顯示的內容

      
detail選取時同時開啟的細節

      
disabled停用

      
href、target改為連結

    
  


  
內容中的觸發元素

  

    
屬性說明

    
      
detail在細節區顯示對應內容

      
color按鈕配色；已有 btn 類別時不套用

      
toggle再按一次收起細節

      
detail-title細節區標題
