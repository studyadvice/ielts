<ui-chart> 靜態圖表

直式長條（column）、橫條（bar）、折線（line）、圓餅（pie、donut）、百分比堆疊橫條（stack）。純 SVG，只負責呈現資料，沒有提示、點擊與縮放。放進 ui-dashboard 的單一格子會自動撐滿，並依格子大小重畫。

圖表也能「被叫出來」：ui-stream 的訊息加上 badge-click，點徽章時用 link-when do="feed" 在目標格子產生圖表；md-editor 裡寫標記為 chart 的程式碼區塊，預覽與送出都會變成圖表。

範例零（11-20-26 新增）：百分比堆疊橫條，用 theme 決定主色

type="stack" 每列一條，各段寬度是該列的佔比，數字放在段內，系列名稱（表頭）在第一條上方。只要寫一個 theme 主色，其餘漸層色由元件算出，二個、三個、四個以上系列都適用。第一段是主色，後面依序變淡；主色很淺時自動改為變深，也可用 ramp="dark"（或 light）強制。colors 有寫時優先於 theme。第一條的某一段太窄放不下表頭時，自動改用下方圖例。theme 同樣能用在 column、bar、line、pie。

範例一：點訊息上的徽章，在右邊格子產生圖表

每則講評的徽章指向各自的圖表（data-chart）。點徽章後，ui-stream 發出 ui-stream:badge，link-when 把 data-chart 指向的 template 複製進目標格子；後點的取代先前的（feed-mode="append" 則疊加）。

範例二：在 md-editor 寫資料，預覽與送出都變成圖表

輸入框裡寫一個標記為 chart 的程式碼區塊：設定列（type、title、series、unit 等）加上「標籤: 數值, 數值」資料列。切到 Preview 就能看到，按送出則在右邊格子產生圖表；md-submit 的 detail.charts 另外帶解析好的資料。

屬性

屬性預設說明
typecolumncolumn 直式長條、bar 橫條、line 折線、pie 圓餅、donut 甜甜圈、stack 堆疊橫條。
title、title-align無、center圖表標題與對齊（center、left）。
series無系列名稱，逗號分隔；多系列的長條與折線用。圓餅只取每列的第一個數值。
unit、prefix、decimals無、無、自動數值後綴（%）、前綴（$）、小數位數。
y-min、y-max、y-step、ticks自動、自動、自動、5數值軸範圍與刻度間距；ticks 是希望的刻度數。長條與折線預設包含 0。橫條圖的數值軸在下方，仍用這幾個屬性。
gridtrue是否畫格線。
show-valuesfalse在長條、折線的點上、圓餅的標籤中顯示數值。
show-percent、hole、start-angle、center、sorttrue、0（donut 為 0.55）、0、無、false圓餅專用：標籤顯示百分比、中空比例（0 到 0.9）、起始角度（0 在正上方，順時針）、中空處的文字、依大小排序。空間不夠放外側標籤時，自動改用圖例。
legend多系列 bottom，否則 nonetop、bottom、right、none；stack 預設 header（系列名稱在第一條上方）。
vary、bar-gapfalse、0.3單一系列的長條每根用不同顏色（並顯示圖例）；長條組之間的空隙比例。
markers、line-widthtrue、2.5折線的資料點與線寬。
x-title、y-title、label-rotate無、無、auto水平軸與垂直軸標題（橫條圖的 x-title 在下方的數值軸）；類別標籤太擠時自動斜放，也可寫角度。
theme、ramp無、auto主色（色票名稱或任何 CSS 顏色），其餘系列色由元件以同色相漸層算出；ramp 可選 auto、light（往淺）、dark（往深）。
normalizetrue只用於 stack：每列換算成 100%；false 時各列寬度依總和相對最大列。
colors內建依序色系列或扇形的顏色，逗號分隔，色票名稱或色碼；預設依序為 key、playful、violet、green、yellow、pink、blue、red…。
text-color、title-color、grid-color、axis-color、bgshell、vanilla、bg-alternative、gray、自動文字、標題、格線、軸線；bg 只用在扇形之間的分隔線，預設自動取用所在位置的背景色。
font-size、height1（rem）、320px基礎字級倍率；單獨使用時的高度（放進撐滿的格子會依格子縮放）。
label-emptyNo data沒有資料時顯示的文字。
src、data-id無資料來源：JSON 網址、window 上的物件名稱。格式見下。

資料來源與方法

寫法說明
<chart-row label values>每列一個標籤與數值；values="30,45" 對應多個系列（逗號或直線分隔），單一系列可寫 value。空白或非數字視為缺值（折線會斷開）。圓餅的每列可用 color 指定顏色。改動子標籤會自動重畫。
JSON{ "type": "line", "series": ["A","B"], "rows": [{ "label": "2010", "values": [1,2] }] }，或直接是 rows 陣列。物件裡的 type、title、unit 等選項只在屬性沒寫時採用。
el.setData(obj)、el.getData()用程式設定或讀取資料（格式同 JSON）。設定後不再讀子標籤。
el.render()手動重畫。
ui-chart:render 事件每次畫完觸發（會冒泡），detail = { type, width, height }。
