<ui-detail-ladder> 元件示範（11-18-26 整合版）

加上 autoplay 屬性，階梯會自動一階一階往上，每階預設停 8 秒，按播放鍵開始。點階梯、按「往上一階」、「重來」或用鍵盤切換時自動暫停；按鈕列多一顆播放與暫停鍵，也可以按 Ctrl+Shift+空白鍵 切換。元件離開畫面、切到別的分頁、收合時暫時停止計時，回來再接著播。內容下方的細線是倒數，暫停時變灰。修訂日期 11-12-26。

新增：mark-fx 文字標記（11-18-26）

在 <step-body>、<step-note>、<step-title> 裡寫 <mark-fx>，切換到該階時，文字先出現，再依序把標記畫上去；切走就清掉。寫法與 ui-post 的 mark-fx 相同，原本的 <mark> 完全保留，可以混用。

mark-fx 範例一：在 mark 之外再畫標記

第一階用刪除線與波浪底線標出要改的地方，第二階用箭頭把結尾接回主詞，並讓一個詞變色。標記的顏色用色票名稱，沒寫時 box、arrow 為 key，strike、wavy、cross 為 red。

mark-fx 範例二：全域屬性與 autoplay

mark-speed="2" 兩倍速、mark-delay="200" 文字出現後 0.2 秒開始畫。搭配 autoplay 時，標記一定在該階停留時間結束前畫完，來不及就直接顯示完成。下方第二個把 mark-fx="false" 關掉，標記全部不畫；mark-animate="false" 則是直接顯示、不播動畫。

mark-fx 屬性速查

寫在 <mark-fx> 上的屬性與 ui-post 的 mark-fx 相同；以下是 ui-detail-ladder 新增的全域屬性。

名稱預設說明
mark-fxtrue寫在 <ui-detail-ladder> 上。false 時所有標記都不畫。
mark-speed1標記動畫的倍速，範圍 0.25 到 4。
mark-delay400切換到該階之後，等幾毫秒才開始畫。
mark-animatetruefalse 時直接顯示完成的標記，不播動畫。
<mark-fx> 的 kindboxbox、strike、wavy、cross、arrow、color。
text、nth、target整段、1要標記的文字與第幾次出現；target 為 CSS 選擇器。
color、thickness、rough、seed、padding、radius顏色可寫色票名稱；其餘同 ui-post。
to、to-nth、to-target、side、bend、head只用於 arrow。
start、delay、speed、stayafter、0與前一個一起畫（with）、延遲、單一標記動畫時間、停留多久後淡出。

限制：標記只能寫在 <step-title>、<step-body>、<step-note> 裡，且要寫成成對標籤（<mark-fx ...></mark-fx>）；元件收合時不畫，展開後才畫。

範例一：只加 autoplay（每階 8 秒，按播放鍵開始，停在最後一階）

其餘全部用預設。按「播放」或 Ctrl+Shift+空白鍵 開始；最後一階到了就停住，播放鍵變回「播放」，再按一次從第一階重新開始。

範例二：改秒數、單階停留、循環播放

autoplay="4" 每階 4 秒；第三階內容較長，用 dwell="10" 單獨停 10 秒；autoplay-end="loop" 最後一階停完後回到第一階繼續。按「播放」開始。

範例三：捲進畫面就開始，游標停留時暫停，收合狀態

autoplay-start="view" 捲進畫面就開始；pause-on-hover="true" 游標停在元件上時暫停計時；搭配 ini-collapse，收合時不計時，展開後才繼續。

範例四：用程式控制，隱藏倒數線與按鈕

show-buttons="false" 與 show-timer="false" 讓畫面只剩內容，適合錄影；改由外部按鈕呼叫 play()、pause()。autoplay-start="load" 載入就開始。

程式碼對照：v1.2 與 v1.3

v1.2 只能手動往上；v1.3 加一個屬性就能自動播放，原有屬性與寫法完全相容。

<!-- v1.2：只能點擊或按鍵往上 -->
<ui-detail-ladder theme="blue">
  <ladder-step label="籠統說法">...</ladder-step>
  <ladder-step label="換成結果">...</ladder-step>
  <ladder-step label="加上數字">...</ladder-step>
</ui-detail-ladder>
<!-- v1.3：加上 autoplay 即自動播放 -->
<ui-detail-ladder theme="blue"
  autoplay="8"              每階秒數，省略數字為 8
  autoplay-start="click"    click、view、load
  autoplay-end="stop"       stop、loop
  pause-on-hover="false"
  show-timer="true">
  <ladder-step label="籠統說法">...</ladder-step>
  <ladder-step label="換成結果" dwell="12">...</ladder-step>
  <ladder-step label="加上數字">...</ladder-step>
</ui-detail-ladder>

v1.3 新增的屬性、方法與事件

名稱預設說明
autoplay關閉開啟自動播放。只寫屬性為每階 8 秒，寫數字改秒數，例如 autoplay="5"。autoplay="false" 視同關閉。
<ladder-step dwell>跟著 autoplay單獨設定這一階停留的秒數。
autoplay-startclickclick 按播放鍵或 Ctrl+Shift+空白鍵 才開始；view 元件捲進畫面就開始；load 載入就開始。
autoplay-endstopstop 停在最後一階；loop 最後一階停完回到第一階。
pause-on-hoverfalsetrue 時游標停在元件上暫停計時。
show-timertrue內容下方的倒數線，顏色跟著主題強調色，暫停時變灰。
play-text、pause-text播放、暫停播放鍵的文字。按鈕列由原有的 show-buttons 控制。
play()、pause()、isPlaying用程式開始、暫停與讀取狀態。在最後一階呼叫 play()（stop 模式）會從第一階重新開始。
ladder-play、ladder-pause、ladder-end事件。ladder-pause 的 detail.reason 為 user（手動）或 end（播完）。
Ctrl+Shift+空白鍵切換播放與暫停，作用對象與 Ctrl+Shift+上下鍵 相同。
自動暫停的時機點階梯、按「往上一階」或「重來」、用鍵盤切換階梯。
暫時停止計時元件離開畫面、切到別的分頁、收合時；條件解除後從原本的倒數位置繼續。

v1.2：顏色屬性支援品牌色名稱與 theme

問題：v1.1 的顏色屬性只認 #hex 或 CSS 原生色名。填 key、base、vanilla、energetic 這類品牌色名稱時，瀏覽器視為無效值，該部位直接變成黑色或透明；填 pink、blue 這類和 CSS 撞名的名稱，則會顯示 CSS 原生的粉紅與純藍，而非品牌色。v1.2 起所有顏色屬性都先轉換品牌色名稱，與 ui-insight 的寫法一致。

同一段設定在 v1.1 與 v1.2 的差異

v1.1（修正前的現象）

  • bg="base"：背景變透明。
  • title-color="key"、body-color="vanilla"：文字變黑色，在深色底上幾乎看不見。
  • pill-bg="energetic"：膠囊標籤沒有底色。
  • current-color="pink"：顯示 CSS 原生粉紅 #FFC0CB，不是品牌 pink。
  • icon-color="yellow"：顯示 CSS 原生純黃 #FFFF00。

v1.2（修正後，實際元件）

原本的說法 The bus was so crowded. 公車很擠。 用結果代替形容詞 The buses were so packed that I couldn't get on. 公車擠到我上不去。 讓結果可以被衡量 The buses were so packed that I let three go by. 公車擠到我讓了三班過去。

v1.2 更新：theme 屬性

寫法與 ui-insight 相同。theme 一次改變外框、階梯（已經過與目前）、垂直線、膠囊標籤、次標題、分隔線、<mark>、進度條、前進按鈕與收合標題列的顏色。優先順序：個別屬性 > theme > 內建預設。未知名稱退回 default。
