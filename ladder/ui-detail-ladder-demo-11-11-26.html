<ui-detail-ladder> v1.2：顏色屬性支援品牌色名稱

問題：v1.1 的顏色屬性只認 #hex 或 CSS 原生色名。填 key、base、vanilla、energetic 這類品牌色名稱時，瀏覽器視為無效值，該部位直接變成黑色或透明；填 pink、blue 這類和 CSS 撞名的名稱，則會顯示 CSS 原生的粉紅與純藍，而非品牌色。v1.2 起所有顏色屬性都先轉換品牌色名稱，與 ui-insight 的寫法一致。

同一段設定在 v1.1 與 v1.2 的差異

v1.1（修正前的現象）

  • bg="base"：背景變透明。
  • title-color="key"、body-color="vanilla"：文字變黑色，在深色底上幾乎看不見。
  • pill-bg="energetic"：膠囊標籤沒有底色。
  • current-color="pink"：顯示 CSS 原生粉紅 #FFC0CB，不是品牌 pink。
  • icon-color="yellow"：顯示 CSS 原生純黃 #FFFF00。

v1.2（修正後，實際元件）

原本的說法 The bus was so crowded. 公車很擠。 用結果代替形容詞 The buses were so packed that I couldn't get on. 公車擠到我上不去。 讓結果可以被衡量 The buses were so packed that I let three go by. 公車擠到我讓了三班過去。

程式碼對照

/* v1.1：只能填 #hex，名稱會失效 */
<ui-detail-ladder
  bg="#0C0D0C"
  title-color="#51DBCF"
  body-color="#DBEDD8"
  pill-bg="#B6FF00"
  current-color="#FF91D7">
  <ladder-step label="籠統說法">
    <step-title icon="chat-square-quote"
      icon-color="#E3D322">原本的說法</step-title>
    ...
  </ladder-step>
</ui-detail-ladder>
/* v1.2：品牌色名稱與 #hex 都可以，名稱不分大小寫 */
<ui-detail-ladder
  bg="base"
  title-color="key"
  body-color="vanilla"
  pill-bg="energetic"
  current-color="pink"
  progress-color="green" progress-color-end="KEY">
  <ladder-step label="籠統說法">
    <step-title icon="chat-square-quote"
      icon-color="yellow">原本的說法</step-title>
    ...
  </ladder-step>
</ui-detail-ladder>

可用的品牌色名稱

shell、vanilla、yellow、pink、red、green、blue、indigo、violet、gray、key、calm、quiet、playful、urgent、energetic、dreamy，另有 base（#0C0D0C）與 bg-alternative（#3B2A20）。

v1.2 更新：theme 屬性

寫法與 ui-insight 相同。theme 一次改變外框、階梯（已經過與目前）、垂直線、膠囊標籤、次標題、分隔線、<mark>、進度條、前進按鈕與收合標題列的顏色。優先順序：個別屬性 > theme > 內建預設。未知名稱退回 default。

即時切換

原本的說法 I like reading. 我喜歡閱讀。 說出讀什麼 I like reading crime novels. 我喜歡讀犯罪小說。 說出什麼時候讀 I like reading crime novels before bed, usually for half an hour. 我喜歡睡前讀犯罪小說，通常讀半小時。 
/* v1.1：每個部位都要各自指定 */
<ui-detail-ladder
  border="true" border-color="#B484E8"
  active-color="#B484E8" current-color="#B484E8"
  line-active-color="#B484E8"
  pill-bg="#B484E8" title-color="#B484E8"
  hl-bg="#B484E8" progress-color="#B484E8">

/* v1.2：一個 theme 搞定 */
<ui-detail-ladder theme="violet" border="true">

/* JavaScript 取得所有主題名稱 */
customElements.get('ui-detail-ladder').themes
// ["default", "shell", "vanilla", ... "dreamy"]

theme 搭配個別屬性覆蓋

原本的說法 My hometown is nice. 說出具體特點 My hometown is right by the sea. 連結到自己 My hometown is right by the sea, so I grew up swimming every summer. 
/* 主色跟著 key，膠囊標籤與 mark 個別覆蓋 */
<ui-detail-ladder theme="key"
  pill-bg="playful" hl-bg="yellow"
  border="true" start="2">
  ...
</ui-detail-ladder>
