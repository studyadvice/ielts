ui-insight11-02-26 修正v1.2 theme

修正一（v1.1）：hl-hot-bg、hl-hot-color 以及其他所有顏色屬性，現在都可以直接填品牌色名稱（例如 sky、lavender、base），不分大小寫。

修正二（v1.2）：新增 theme 屬性，請見第 6 節。

1. 原因

元件把屬性值原封不動寫進 CSS 變數，sky 這類名稱不是合法的 CSS 顏色，瀏覽器會整條規則作廢，所以亮點被游標指到時沒有任何底色變化。hl-hot-color 與 tag-color 也有同樣的問題。

解法是新增品牌色名稱對照表，所有顏色屬性在寫入 CSS 之前先轉成色碼。找不到對照名稱時，維持原值，所以 #hex、rgb()、CSS 內建顏色名稱仍然有效。

6. theme 屬性（v1.2）

影響外觀色彩的個別屬性，預設值都會跟著 theme 走。只有明確寫在標籤上的屬性，才會覆蓋 theme 的顏色。

優先順序：個別屬性 > theme > 內建預設。

主題名稱不存在時，退回 default（維持原本的多色外觀）。其餘主題以單一品牌色為主軸，卡片、面板等底色維持中性。

修改後（v1.2）
// 新增：主題表（只列出與預設不同的顏色）
const accentTheme = (a, on = 'base') => ({ 'hl-hot-bg': a, 'hl-hot-color': on, ... });
const THEMES = { default: {}, lavender: accentTheme('lavender'), ... };

_css(name) {
  const v = this.getAttribute(name);
  const has = v !== null && v !== '';
  if (!COLOR_ATTRS.has(name)) return has ? v : CSS_ATTRS[name];
  if (has) return resolveColor(v);                       // 個別屬性優先
  const tv = THEMES[this._themeName()][name];           // 其次是 theme
  return resolveColor(tv !== undefined ? tv : CSS_ATTRS[name]);  // 最後是內建預設
}
