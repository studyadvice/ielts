<ui-detail-ladder> 細節階梯元件

把籠統說法逐階升級成具體說法。左側為階梯軌道，右側依序為 pill、次標題、本文、註腳、進度條與按鈕，全部可由屬性自訂。

版本紀錄：v1.0 首版（範例一到三）；v1.1 新增預設收合、鍵盤切換、次標題圖示（見頁面下方「v1.1 更新」）。

範例一：全部使用預設值

原本的說法 I live near my school. 我住在學校附近。 先讓距離可以想像 I live within walking distance of my school. 我住的地方走路就能到學校。 換成可衡量的數字 It's about a ten-minute walk from my place to school. 從我家走到學校大約十分鐘。 最後補上一個生活場景 It's a ten-minute walk, so I can roll out of bed at 7:45 and still make my first class. 走路十分鐘，所以我七點四十五分才起床也趕得上第一堂課。

v1.1 更新：預設收合、鍵盤切換、次標題圖示

以下每組左邊是 v1.1 實際效果，右邊是 v1.0 與 v1.1 的寫法對照。

1. ini-collapse 預設收合

原本的說法 Exercise is crucial for me. 運動對我很重要。 說出多常做 I go for a run three times a week. 我一週跑步三次。 放進一個具體時刻 I go for a run three times a week, usually along the riverbank before work. 我一週跑三次，通常是上班前沿著河堤跑。 
/* v1.0：沒有收合功能，元件一律展開 */
<ui-detail-ladder border="true">
  ...
</ui-detail-ladder>

/* v1.1：加上 ini-collapse 即預設收合 */
<ui-detail-ladder ini-collapse
  ini-title="預設收合，點擊展開"
  border="true">
  ...
</ui-detail-ladder>

ini-collapse 不必給值；寫成 ini-collapse="false" 等同不收合。
可搭配 ini-title-size、ini-title-color、ini-title-bg 調整標題列。

2. Ctrl+Shift+上下方向鍵切換階梯

原本的說法 My location is convenient. 我住的地方很方便。 指出具體設施 There's a supermarket and a metro station right around the corner. 轉角就有超市和捷運站。 描述一次真實使用 If I run out of milk, I can grab some in my slippers and be back in five minutes. 牛奶喝完了，我穿著拖鞋就能去買，五分鐘回到家。
把游標移到元件上（或點一下元件），再按 Ctrl+Shift+↑ 或 Ctrl+Shift+↓。 
/* v1.0：只能用滑鼠點階梯或按鈕 */

/* v1.1：預設啟用鍵盤，不需任何設定 */
<ui-detail-ladder direction="down">
  ...
</ui-detail-ladder>

/* 若要關閉 */
<ui-detail-ladder keyboard="false">

規則：
・方向鍵依「畫面上的上下」移動。
  direction="up"   時 ↑ 是下一階。
  direction="down" 時 ↓ 是下一階。
・作用對象：最近一次被游標指到、點擊
  或用 Tab 取得焦點的那一個元件。
・游標在其他 input、textarea 打字時不攔截。
・收合狀態下不作用。
・用鍵盤切換時，目前階梯的圓點外圍會加一圈提示框。

3. step-title 的 icon 屬性

原本的說法 Nightlife here is vibrant. 簡寫也可以（star-fill） There's a night market two streets away. 完整寫法也可以（bi bi-fire） There's a night market two streets away, and you can smell the grilled squid from my balcony. 
/* v1.0：圖示要自己寫在標題裡 */
<step-title><i class="bi bi-star-fill"></i> 標題</step-title>

/* v1.1：直接用 icon 屬性 */
<step-title icon="bi-star-fill">標題</step-title>

/* 三種寫法都可以 */
icon="bi-star-fill"
icon="star-fill"
icon="bi bi-star-fill"

/* 單一圖示改色 */
<step-title icon="bi-fire" icon-color="#EDA109">

/* 整個元件的圖示統一改色（預設 #E3D322） */
<ui-detail-ladder title-icon-color="#FF91D7">
