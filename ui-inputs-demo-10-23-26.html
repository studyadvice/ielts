ui-inputs 示範

兩個輸入／驗證元件：<ui-otp> 單一 input 版 OTP 輸入／驗證，<ui-blank> 單行輸入填充題（自帶 Bootstrap Icons 送出鈕）。

一、ui-otp

點任一格即可聚焦，支援鍵盤輸入、刪除、整段貼上；畫面上的格子只是展示用，實際輸入都發生在背後那個透明的 input 裡。

1. 預設（numeric，6 碼，無分組）

2. 分組 + 分隔符（groups="3,3"，比照 Bootstrap 6 截圖效果）

3. 英文字母、強制大寫

type="alpha" case="upper"：只接受英文字母，自動轉大寫。

4. 前端比對模式（expected-value="123456"，試打 123456 或其他數字）

填滿 6 碼即自動比對；答對顯示綠框＋成功訊息，答錯顯示紅框＋錯誤訊息。

5. 前端比對 + clear-on-invalid（答錯會自動清空重輸）

正確答案是 000000；輸入其他任何 6 碼都會先閃紅框，約 0.7 秒後（clear-delay="700"）自動清空讓你重打。

6. 外部非同步驗證模式（不給 expected-value，自行監聽 otp-complete）

模擬打 API：輸入 888888 會驗證成功，其他 6 碼會顯示失敗（0.6 秒後才回應，模擬網路延遲）。

7. focus ring 粗細／顏色自訂

focus-ring-width="5px" focus-ring-color="pink"：聚焦中的那一格外框變粗、顏色改用 pink。

8. 遮蔽模式（mask，顯示圓點而非實際字元）

9. disabled

一之二、ui-otp mode="generate"（隨機產生＋複製到剪貼簿）

同一個 <ui-otp> 標籤，加上 mode="generate" 就變成唯讀展示＋複製功能，不再是輸入框。

1. 基本生成（預設 16 碼、exclude-ambiguous 預設開啟）

每次重新整理頁面都會是不同的一組碼；已自動排除 0/O、1/I/l 這類容易看錯的字元。

2. format 自訂版型（優先於 length/groups）

3. 關閉 exclude-ambiguous + 指定字元集

exclude-ambiguous="false"：允許出現 0、1 這些字元。

4. 複製按鈕自訂（文字、位置、圖示）

5. check-url 後端查重（這裡用假的 fetch 模擬，實際請指到你的 PHP）

模擬後端：前兩次回報「已存在」自動重骰，第三次才通過。打開主控台可以看到 otp-check-* 事件紀錄。

二、ui-blank

單行輸入填充題，永遠區分大小寫。送出鈕用 Bootstrap Icons（圖示固定不隨結果變化），訊息預設顯示在元件正下方，也可指定顯示在頁面上別的 div。

1. 基本用法（前端比對，單一正解）

正解是 apple（區分大小寫，Apple 算錯）。

2. 多個可接受答案（"|" 分隔）＋ 按鈕文字＋icon-left

3. clear-on-invalid + clear-delay（答錯 0.7 秒後自動清空）

4. normalize-width（全形轉半形後再比對）

用全形輸入法打「２０２４」送出，比對前會自動轉成半形再跟 2024 比對。

5. message-style 五種樣式

plain（預設）

bordered

filled

accent-bar

icon-banner

6. message-target（訊息顯示在頁面上別的 div，不套用元件樣式）

這個 div 本身的排版（字重、顏色、位置）完全由你自己的 CSS 控制，元件只負責把文字塞進去。

7. 外部非同步驗證模式（不給 expected-value）

模擬打 API：輸入 remote 驗證成功，其他任何內容驗證失敗（0.5 秒後才回應）。
