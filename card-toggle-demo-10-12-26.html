card-toggle 示範

按鈕改為縮減 padding，字體維持不變；各部位字體與 padding 皆可由屬性或 CSS 變數調整。

1. 預設小按鈕

2. 各部位字體設定（卡片屬性）

fs-submit="1.5"、fs-input="1.25"、ff-question="serif"、pad-submit="8 24"

3. 群組層級設定（套用到所有子卡片與導覽）

fs-nav、fs-page、fs-counter、pad-nav 設在群組上。

4. 以 CSS 變數全域調整

在任何上層元素設定變數即可，例如下方區塊把提交按鈕調得更緊湊。

5. 額外資訊按鈕

info 直接寫內容；info-source 讀取來源區塊的 HTML；info-color、info-bg、info-fg 覆蓋色彩；fs-info、fs-infobox、ff-infobox 設定字體。

來源區塊可以放任何 HTML：

  • 清單
  • 強調文字
  • 連結
