<ui-post> v1.1：mode="live" 與 add()

原本的 ui-post 照劇本從頭播到尾。live 模式改成由外部一則一則送進留言：每則照樣有「正在輸入」、愛心跳動；best 那則會爆愛心、蓋徽章並置頂，low 變灰或摺疊，tags 講評標籤出現。搭配 ui-contacts 範例 5，可以把人物卡片直接拖進貼文。原本的播放模式不受影響，範例見 ui-post-demo-11-13-26.html、11-14-26.html。

範例 1：用 add() 送留言

沒有控制列；留言依送出順序排隊播放，前一則跑完才輪到下一則，連按也不會亂。

How often do you exercise?
事件會顯示在這裡。
<ui-post id="p1" mode="live" author="IELTS Examiner" badge="Part 1" likes="86">
  How often do you exercise?
</ui-post>

const p = document.getElementById('p1');
p.add({ author: 'Amy', likes: 3, low: true, tags: '照抄題目:red',
        text: 'I exercise almost every day.' });
p.add({ author: 'Ben', likes: 1280, best: true, tags: ['具體運動:green', '慣用語:yellow'],
        html: 'I go <c-key>jogging</c-key> …, <c-yellow>rain or shine</c-yellow>.' });
p.add({ author: 'Dan', reply: true, likes: 12, text: 'Stealing rain or shine!' });
p.add({ author: 'Eve', likes: 1, low: 'fold', text: 'Sometimes.' });
p.add({ author: 'IELTS Examiner', examiner: true, roleLabel: '考官', html: '…' });

/* 鍵名同 post-item 屬性，駝峰或連字號都可以（roleLabel、'role-label'）
   true 代表只寫屬性名；陣列會用逗點接起來；內容用 html 或 text */

p.live;    // true
p.total;   // 目前留言總數（含排隊中）
p.addEventListener('post-add-end', e => e.detail);   // { index, author, best }

範例 2：預先寫好的留言直接顯示

live 模式下，寫在裡面的 post-item 一載入就是最終狀態（愛心數、最佳回答置頂、標籤），不播動畫。之後再用 add() 接著加。

Describe a river you have visited. The river is very beautiful. The river meanders through rice paddies, glinting in the late afternoon sun. 
<ui-post mode="live" author="Tutor Lin" badge="Part 2" theme="indigo" best-label="高分範例" burst="small">
  Describe a river you have visited.
  <post-item author="Kai" likes="8" low>The river is very beautiful.</post-item>
  <post-item author="Mia" likes="530" best tags="畫面感:green">…</post-item>
</ui-post>

/* 上面這兩則在載入時直接顯示完成的樣子；
   新加的最佳回答會排在既有最佳回答的後面，一起置頂 */

v1.1 新增

項目說明
mode="live"接收模式：不顯示控制列，autoplay、play()、pause()、restart() 失效。預先寫好的 post-item 直接顯示最終狀態；之後用 add() 送進的留言逐則播出。
add(item)加一則留言，回傳留言總數。鍵名同 post-item 屬性（駝峰或連字號），內容用 html 或 text。live 模式立刻排入播放；其他模式只加進清單，下次重播才出現。
live-surgelive 模式中，一般留言的愛心跳動時間（毫秒），預設 1200。best 留言仍用 surge（預設 3500）。
live、total唯讀：是否為 live 模式、目前留言總數。
post-add-end事件：add() 送進的一則留言播完（含最佳回答判定、置頂、標籤）時觸發，detail = { index, author, best }。
