🔗 collocation-map

視覺化搭配詞元件 — 加入 ui-reading2.js 的新元件

Demo · 09-08-26  |  依賴：ui-reading2.js（同目錄）

§1 anchor-side="left"　動詞 → 受詞型

錨點在左、搭配詞在右，圓點在文字外側（右）。

trigger: hover
undermine confidence trust the argument
address a problem concerns inequality the root cause
justify a decision the cost inequality 
<collocation-map
  anchor-side="left"
  palette="safe,orange,indigo"
  target="panel-undermine"
  trigger="hover"
  gap="18px"
  point-size="1.5rem">
  <cm-point theme="lavender" weight="bold">undermine</cm-point>
  <cm-item note="ex-u1">confidence</cm-item>
  <cm-item note="ex-u2">trust</cm-item>
  <cm-item note="ex-u3">the argument</cm-item>
</collocation-map>

<div id="panel-undermine"></div>

<!-- 來源 div（JS 自動隱藏）-->
<div id="ex-u1">The scandal <b>undermined public confidence</b> in the government.</div>

§2 anchor-side="right"　形容詞 → 名詞型

錨點在右、搭配詞在左，圓點在文字外側（左）。

trigger: click（點選鎖定，再點解鎖）
problem common pervasive pressing tricky
impact significant lasting positive detrimental measurable
concern growing widespread legitimate 
<collocation-map
  anchor-side="right"
  palette="safe,orange,indigo,sky"
  target="panel-problem"
  trigger="click"
  gap="18px">
  <cm-point theme="shell" weight="bold">problem</cm-point>
  <cm-item note="ex-p1">common</cm-item>
  <cm-item note="ex-p2">pervasive</cm-item>
  <cm-item note="ex-p3">pressing</cm-item>
  <cm-item note="ex-p4">tricky</cm-item>
</collocation-map>

§3 trigger="both"　hover 預覽 + click 鎖定

滑入預覽例句，點擊鎖定；再點同一項解鎖。

trigger: both
assess risk evidence impact quality the situation
change gradual dramatic meaningful irreversible

§4 線條樣式 · 自訂顏色（含 #hex palette）

line-style="dashed"

weigh the pros the cons the trade-offs

line-style="dotted"

trend emerging dominant long-term

anchor-align="start" · line-overhang="28px"

attribute A to B success to hard work failure to bad luck change to policy growth to investment

§5 cm-item 個別覆蓋 target

不同搭配詞的例句可顯示在不同 div，透過 target 屬性指定。

shift focus attention perspective
target="panel-sh-left"（ocean 那項）
target="panel-sh-right"（yellow / lavender 兩項共用）
<cm-item note="ex-sh1" target="panel-sh-left">focus</cm-item>
<cm-item note="ex-sh2" target="panel-sh-right">attention</cm-item>
<cm-item note="ex-sh3" target="panel-sh-right">perspective</cm-item>

§6 屬性總覽

collocation-map

屬性預設值說明
anchor-sideleft錨點位置：left | right
anchor-aligncenter錨點垂直對齊：center | start | end
palette（系統預設）搭配詞自動配色，逗號分隔；支援色票名稱（ocean、yellow…）與 #hex（#FFFFFF）
dot-size12px圓點尺寸
dot-gap8px圓點與文字間距
line-colorshell分隔線顏色，色票名稱或 #hex
line-stylesolidsolid | dashed | dotted
line-width1.5px線條粗細
line-gap18px分隔線兩側水平留白
line-overhang16px線條超出首末搭配詞的距離
point-size1.4rem錨點字體大小
item-size1rem搭配詞字體大小
gap16px搭配詞之間垂直間距
hover-dim0.35非 active 項的透明度（0–1）
triggerhoverhover | click | both
animatetrue透明度過渡動畫
target—全域說明面板 div id（#id 或 id 均可）

cm-point

屬性預設值說明
themeshell文字顏色，色票名稱或 #hex
weightboldbold | normal | 任何 CSS font-weight
size（繼承）字體大小，覆蓋 collocation-map 的 point-size

cm-item

屬性預設值說明
theme（取 palette）覆蓋此項顏色，色票名稱或 #hex
note—例句來源 div id（JS 自動隱藏該 div）
target（繼承全域）覆蓋全域 target，指定此項注入哪個 div

全域預設值 CollocationMapConfig

// 在載入 ui-reading2.js 之前設定，可覆蓋任何預設值
window.CollocationMapConfig = {
  cmPalette:     ['ocean','yellow','lavender','salmon','teal','safe','indigo','pink','sky','focus'],
  cmAnchorSide:  'left',
  cmAnchorAlign: 'center',
  cmDotSize:     '12px',
  cmDotGap:      '8px',
  cmLineColor:   'shell',
  cmLineStyle:   'solid',
  cmLineWidth:   '1.5px',
  cmLineGap:     '18px',
  cmOverhang:    '16px',
  cmPointSize:   '1.4rem',
  cmItemSize:    '1rem',
  cmGap:         '16px',
  cmHoverDim:    0.35,
  cmTrigger:     'hover',
  cmAnimate:     true
};
