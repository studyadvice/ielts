ui-blank：CLI 模式

<ui-blank mode="cli"> 把元件變成模擬的終端機畫面，用子標籤寫成一份「輸入、回應」交替的劇本，自動逐字打出來，看起來像在和電腦對話。內容不必是真實指令。劇本中可以插入 <cli-ask> 換使用者自己打，打什麼都接受，按 Enter 就繼續播放。每個範例左邊是實際元件，右邊是同一段原始碼。

自動播放對話

屬性速查

<ui-blank mode="cli">

屬性預設說明
mode無設為 cli 啟用 CLI 模式；其他值或不設定為原本的填充題。
prompt$預設提示符號，每一行可用自己的 prompt 覆蓋；設為空字串則不顯示。
speed20輸入行每秒打幾個字。
out-speed120系統回應每秒出現幾個字，0 為整段直接出現。
line-delay450每一行輸入之前的停頓（毫秒）。
humanize開啟打字帶隨機快慢，遇到空白與標點稍微停頓；false 為等速。
autoplay自動元件完整進入畫面時開始；false 時按 ▶ 或點畫面才開始。
controls顯示控制列：播放／暫停、重播、快轉（作答時為略過）、0.5×、1×、2×；false 隱藏。
framemac外框：mac、win、none。
titleterminal標題列文字。
cursorblock游標：block、underline、bar。打字時不閃爍，停下來才閃爍。
end-prompt顯示播完後在最後留一個提示符號與閃爍游標；false 不留。
width100%最大寬度。
height、min-height自動、160畫面高度；設定 height 後固定高度並自動捲到最後一行。純數字視為 px。
font-size1rem畫面字級。
bg-color、text-color#0C0D0C、shell畫面底色與一般文字色。
prompt-colorkey提示符號、游標、選中的速度按鈕。
in-color、out-color、ask-colorvanilla、calm、yellow輸入行、系統回應、使用者輸入的文字色。

劇本子標籤

子標籤屬性說明
<cli-in>prompt、speed、delay、theme自動打字的輸入行。
<cli-out>speed、delay、theme、pre系統回應，沒有提示符號。delay 預設 250 毫秒；pre 保留原始換行與空白（自動去掉共同縮排）。
<cli-ask>prompt、placeholder、sample、allow-empty、delay、theme換使用者輸入，不比對答案，按 Enter 繼續；預設不接受空白輸入。
<cli-wait>ms停頓，預設 800 毫秒。

事件與方法

名稱說明
cli-answer使用者在 <cli-ask> 按下 Enter 或略過時觸發，detail = { value, index }。同時送出原有的 blank-submit，valid 為 null。
cli-end劇本播完時觸發。
play()、pause()、restart()播放或繼續、暫停、從頭播放；reset() 等同 restart()。
rate播放倍率，可讀寫，例如 el.rate = 2。

修改紀錄：新增 mode="cli"（11-12-26）

原本的 <ui-blank> 填充題完全不受影響；只有加上 mode="cli" 的元件改走 CLI 流程。下面左邊是原本的填充題，右邊是新的 CLI 模式。

原本的填充題（未設定 mode）

HTML

修改前：只有填充題

connectedCallback() {
  injectBlankStyleOnce();
  if (!this._built) this._build();
  ...
}

修改後：mode="cli" 改走 CLI 流程

connectedCallback() {
  if (this.getAttribute('mode') === 'cli') {
    if (this._cliBuilt) return;
    injectCliStyleOnce();
    // 文件還在解析時，等解析完成再讀取劇本
    if (document.readyState === 'loading') {
      document.addEventListener('DOMContentLoaded', ...);
    } else {
      this._cliInit();
    }
    return;
  }
  injectBlankStyleOnce();
  if (!this._built) this._build();
  ...
}

/* CLI 方法集中在 CLI_METHODS，掛到 UiBlank.prototype */
Object.defineProperties(UiBlank.prototype,
  Object.getOwnPropertyDescriptors(CLI_METHODS));
