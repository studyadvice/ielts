ui-layer-diff

v1.0.0 ／ 建立日期 10-29-26 ／ 獨立檔案：ui-layer-diff.js

把「從籠統到具體」的逐層升級做成一個極簡方框。每一層會自動和上一層比對，新增的部分用增加色，被替換掉的部分用減去色加刪除線。所有外觀都能用屬性設定。

同一元件之後如有修改，會把新的範例與程式碼對照附加在本檔後面。

範例與程式碼對照

1. 預設：手動切換、深色主題
只需 ui-layer 子元素，其餘都用預設值。每層可用 label 與 note 加註。
2. 自動播放、循環、ocean 主題
mode="auto" 搭配 interval 與 loop。仍可按上一層、下一層或圓點跳轉，並用暫停按鈕控制播放。
3. 淺色主題、自訂顏色、寬度、內距、字級、邊框
add-color 與 del-color 可寫色票名稱或 hex。border 的寬度、樣式、顏色可任意省略。
4. 中文內容、不顯示減去的部分、隱藏圖例
中文以單字為單位比對。show-del="false" 只留下新增色，適合更精簡的呈現。
5. 顯示當前完整句子（show-result）
增刪多處時，下方會另外列出該層乾淨的完整句子。第一層的內容和當前句子完全相同，所以不顯示。標題可用 result-label 改字，上方空白用 result-gap 調整。
6. 漸層進度條（progress）
以橫向漸層顯示整體步驟，每一層之間有分隔刻度，也可以直接點進度條跳到該層。progress-position="top" 可放在文字上方。
7. 兩個新功能合用，並自訂漸層與高度
自動播放時，進度條會跟著前進。progress-from、progress-to 可寫色票名稱或 hex，progress-height 的純數字視為 px。這裡的 result-gap 設為 24，完整句子上方的空白比預設更寬。

Playground

layers（一行一層）

離開輸入框時，如果少於兩行會提示。程式端也能直接指定：el.layers = ['第一層', '第二層']。

屬性

屬性預設說明
width100%整個元件寬度。純數字視為 px，也可寫 50%、40rem。
themedarkdark、light、ocean、lavender、teal、pink、orange、salmon、sky、yellow。
padding16內距。純數字視為 px，可寫兩個值，例如 8 24。
font-size1.125內文字級。純數字視為 rem，標題與按鈕會依比例縮放。
border1px solid（主題色）寬度、樣式、顏色可任意省略，順序不限。顏色可用色票名稱或 hex。none 取消邊框。
add-colordark 系為 special，light 為 info增加部分的文字色。
del-colorwarning減去部分的文字色，並加刪除線。
modemanualmanual 為手動切換，auto 為自動播放。
interval2500自動播放的間隔，單位毫秒，最小 300。
loop無布林屬性。有寫時，最後一層之後回到第一層，上一層與下一層也會循環。
start1起始層，從 1 起算。
controlstrue設為 false 隱藏控制列。
legendtrue設為 false 隱藏圖例。
show-deltrue設為 false 不顯示減去的部分。
add-label、del-label增加、減去圖例文字。
show-resultfalse顯示該層乾淨的完整句子。寫成 show-result 或 show-result="true" 開啟，show-result="false" 關閉。第一層不顯示。
result-label完整句子完整句子區塊的標題文字。
result-gap10完整句子上方的空白，也就是虛線上方的距離。純數字視為 px，0 代表緊貼。
progressfalse顯示橫向漸層進度條，寫法同 show-result。點進度條可跳到對應的層。
progress-from、progress-to主題色、增加色漸層的起點與終點顏色，可寫色票名稱或 hex。
progress-height10進度條高度，純數字視為 px。
progress-positionbottombottom 在文字下方、控制列上方，top 在標題與文字之間。
progress-tickstrue設為 false 隱藏各層之間的分隔刻度。
ui-layer 的 label第 N 層該層左上角的標題。
ui-layer 的 note無該層文字下方的補充說明，用強調色顯示。

方法與事件

名稱說明
next()、prev()切換到下一層、上一層。
play()、pause()開始、暫停自動播放。
layer目前層數，從 1 起算，可讀可寫。
layers以陣列重設內容，項目可為字串，或 { text, label, note }。
layerchange切換層時觸發。detail 含 layer、total、label、source（user、auto、api）。
layerend自動播放到最後一層且沒有 loop 時觸發。
