收合時標題行顯示進度（pt-header-count）

點擊右下角面板標題列可以收合面板。收合後，標題右側會立即顯示 已完成 / 總計，讓你隨時確認進度而不佔版面。
全部完成後計數文字切換為完成色（colorComplete）； 展開面板後計數隱藏，由格子陣列和完成訊息接管。

即時切換追蹤面板形狀（PracticeTracker.changeShape）

按下後右下角面板的格子形狀立即切換，不重新初始化元件。

公開 API（window.PracticeTracker）

屬性 / 方法 型別 說明
markDone(sectionId) Function 標記指定 section ID 為完成，重複呼叫無副作用。
changeShape(shape) Function 執行期切換所有格子形狀，接受 square / circle / star / diamond / hexagon / heart，無效值回退至 square。
total Number 偵測到的 section 總數（唯讀）。
doneSet Set<string> 目前已完成的 section ID 集合（唯讀）。
cfg Object 解析後的完整配置物件（唯讀）。
