bp-popnote 摺角便條

在段落加上 data-popover-fold，右上角會出現摺起的紙角。點摺角，便條像紙張翻開一樣展開在段落旁邊，正文位置不動；再點一次摺回去。內容與主題沿用 bp-popnote 原有的 data-popover-title、data-popover-content、data-popover-target、data-popover-theme。新增日期 11-12-26。

範例一：範文批改，一段一張便條

點各段右上角的摺角看評語。下方按鈕呼叫 BpPopnote.foldAll()，一次全部展開或收合，適合複習。

範例二：同組只開一張，固定寬度

data-popover-fold-group 相同的段落，打開一張時其他自動摺回。data-popover-fold-width 設定便條寬度。

範例三：便條在左側或下方，換主題色

data-popover-fold="left" 摺角在左上，便條開在左邊；"below" 便條往下展開，適合窄欄。第二段示範 data-popover-theme="note" 換成黃色，其餘維持預設紫色。

屬性與 API

屬性預設說明
data-popover-foldright開啟摺角便條。right、left、below 決定便條的位置。只寫屬性不給值即為 right。
data-popover-fold-width280px便條寬度（right、left），純數字視為 px。
data-popover-fold-corner22摺角大小（px）。
data-popover-fold-group無同組只能同時開一張。
data-popover-fold-open無載入時就展開。
data-popover-title、data-popover-content、data-popover-target沿用原有屬性：標題、內容（HTML）、讀取 <template> 的選擇器。
data-popover-theme、data-popover-fontsize、data-popover-border沿用全域沿用原有主題與外觀；摺角顏色跟著主題的框線色。
BpPopnote.fold(el, open)開啟或收合單張；省略 open 為切換。el 可以是元素或選擇器。
BpPopnote.foldAll(open, scope)一次開啟或收合，scope 可限定範圍。
BpPopnote.initFolds()手動初始化；動態插入的段落會自動初始化，通常不需要呼叫。
bpn-fold 事件開合時從段落冒泡，e.detail.open 為 true 或 false。
PopoverConfig.set()全域預設：foldSide、foldWidth、foldCorner。
