替 <ui-row-enhance> 加上 can-hide，格子右側會出現眼睛圖示。滑鼠移上去變成劃掉的眼睛，點擊後整列收合隱藏，適合螢幕錄影時逐列帶過教學內容。

1. 基本用法：眼睛放在最後一欄

can-hide 或 can-hide="true" 時，眼睛出現在最右側的格子。表頭列沒有加，所以不會被隱藏。

2. 指定眼睛的欄位，以及與 extra-info 互斥

    
can-hide="1" 把眼睛放在第 1 欄，最後一欄的 extra-info 握把照常保留。若眼睛所在的格子也寫了 extra-info，該格的 extra-info 會被忽略，主控台出現警告；同一列其他格子不受影響。

    這格同時有 can-hide 與 extra-info，只會顯示眼睛

修改 1：屬性與 API

    

      
名稱寫在哪裡說明

      
        
can-hideui-row-enhance空值或 true：眼睛放在最後一欄。數字（1 起算）：放在指定欄，超過欄數時改放最後一欄。false：關閉。寫在 ui-row 上會被忽略並出現警告。

        
can-hide-sizeui-row-enhance眼睛大小。純數字視為 px，也接受 px、rem、em。沒寫時跟隨文字大小。

        
can-hide-colorui-row-enhance眼睛顏色，可用色票名稱（例如 pink）或色碼。沒寫時跟隨格子文字色，inverse 格子自動改成深色。

        
與 extra-info 互斥眼睛所在的格子該格的 extra-info 被忽略，主控台警告；同一列其他格子的 extra-info 照常運作。

        
uit-row-hide 事件原本的 <ui-table>整列隱藏動畫結束後觸發，e.detail.rowEl 是被隱藏的列，e.detail.hasChildren 表示是否連同子列一起隱藏。

        
UiTable.showHidden(target)JavaScript把眼睛隱藏的列全部顯示回來，回傳恢復的列數。target 可以是 <ui-table> 元素、CSS 選擇器，省略則作用於頁面上全部的表格。錄影重拍時使用。

      
    

    
隱藏只影響畫面，重新整理頁面就會恢復。眼睛和 show-next 是各自獨立的：被眼睛隱藏的列，不會因為上一列的 show-next 被點擊而重新出現。

修改 3：屬性與 API

    

      
名稱寫在哪裡說明

      
        
idui-col格子的唯一 id，按鈕靠它找到格子。重複時主控台出現錯誤，按鈕只會找到第一個。注意：同時有 hidden 與 id 的 ui-col 是 extra-info 的來源區塊，不會渲染成格子。

        
<ui-flash>頁面任何地方閃電按鈕。target 填格子 id（必填）；標籤裡的文字當按鈕文字。找不到格子時按鈕會變紅並抖動，詳細原因在主控台。

        
flash-widthui-flash、ui-col光帶粗細，純數字或 px，範圍 1～20，預設 3。

        
flash-speedui-flash、ui-col繞一圈的時間，數字越小越快。純數字視為毫秒，也接受 1.6s、1600ms，範圍 200～20000，預設 1600。

        
flash-loopsui-flash、ui-col繞幾圈，範圍 1～20，預設 2。每繞一圈顏色走完一次彩虹。

        
flash-lengthui-col光帶長度佔周長的比例，0.05～0.9，預設 0.22。

        
color、sizeui-flash按鈕顏色（色票名稱或色碼，預設 yellow）與字級（純數字視為 px，也接受 rem、em）。

        
設定的優先順序ui-flash 的屬性 > ui-col 的屬性 > UiTableConfig（flashWidth、flashSpeed、flashLoops、flashLength）。

        
UiTable.flash(id, 設定)JavaScript直接播放，回傳是否成功。設定物件可用 flashWidth、flashSpeed、flashLoops、flashLength。播放中再呼叫一次會從頭開始。格子不在畫面內時會先平滑捲動過去。

        
UiTable.stopFlash(id)JavaScript立即停止該格的動畫。

      
    

    
頁面之後才用 JavaScript 加入的 ui-flash 或 ui-table，呼叫一次 UiTable.init() 就會啟動，已經啟動過的不會重複處理。
