<card-badge> 元件說明書

多功能標籤 Web Component，支援文字、圖示、日期、數量徽章、輪播、折疊、複製、過濾與字體控制等行為。

Light DOM 作用域 CSS Custom Elements v1

快速開始

將腳本加入頁面即可使用，不需要任何 CSS 框架。若要使用 Bootstrap Icons 圖示，則額外引入圖示字體。

HTML
<!-- 元件腳本 -->
<script src="./card-badge.js"></script>

<!-- 若需要 Bootstrap Icons（可選） -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

最簡用法，只需 text 屬性：

HTML
<card-badge text="Hello"></card-badge>
<card-badge text="標籤" theme="info"></card-badge>
<card-badge text="完成" theme="safe"></card-badge>

設計概念

元件採用 Light DOM 而非 Shadow DOM，渲染結果完全暴露在頁面 DOM 樹中，方便外部樣式覆蓋與除錯。

為了讓多個 <card-badge> 共存而不產生 CSS 衝突，每個實例在掛載時自動產生一組隨機的 UID（如 cb-a3f9k2m），所有樣式規則都以 [data-badge-id="cb-xxx"] 為選擇器前綴，形成天然的作用域。

渲染後的 DOM 結構
<card-badge text="範例" theme="info" data-badge-id="cb-a3f9k2m">
  <div class="cb-render-root" style="display: contents;">
    <style>
      [data-badge-id="cb-a3f9k2m"] { display: inline-block; ... }
      [data-badge-id="cb-a3f9k2m"] .badge { ... }
    </style>
    <div class="badge">
      <span class="text">範例</span>
    </div>
  </div>
</card-badge>
說明 cb-render-root 使用 display: contents，對佈局完全透明，外部看到的就是 .badge 本身，不會多包一層 div 影響排版。badge-item 子元素（輪播用）隱藏在 render root 之後，不參與渲染。

文字與圖示

用 text 設定文字，icon 設定圖示。圖示支援兩種格式：以 bi- 開頭視為 Bootstrap Icons class，其餘視為直接插入的文字或 Emoji。

範例 1  Emoji 圖示 入門
HTML
<card-badge text="已完成" icon="✅" theme="safe"></card-badge>
<card-badge text="警告"   icon="⚠️" theme="warning"></card-badge>
<card-badge text="新功能" icon="🚀" theme="info"></card-badge>

<!-- 只有圖示、無文字 -->
<card-badge icon="📌" theme="special"></card-badge>
範例 2  Bootstrap Icons（bi- 前綴）
HTML
<!-- icon 值以 "bi-" 開頭，自動渲染為 <i class="bi bi-xxx"> -->
<card-badge text="收藏" icon="bi-heart-fill" theme="warning"></card-badge>
<card-badge text="下載" icon="bi-download"  theme="info"></card-badge>
<card-badge text="設定" icon="bi-gear"       theme="stone"></card-badge>

<!-- 只有圖示 -->
<card-badge icon="bi-star-fill" theme="yellow"></card-badge>

主題與外框

theme 屬性接受品牌色鍵名（如 info、safe）或任意十六進位色碼。在色鍵後加 -outline 切換為外框樣式，或直接用 outline="true" 屬性。

範例 3  品牌色一覽
HTML
<card-badge text="info"    theme="info"></card-badge>
<card-badge text="special" theme="special"></card-badge>
<card-badge text="safe"    theme="safe"></card-badge>
<!-- … 其餘色鍵同樣格式 -->

<!-- 也可直接用 hex 色碼 -->
<card-badge text="自訂色" theme="#A047D0"></card-badge>
範例 4  Outline（外框）樣式
HTML
<!-- 方式 1：theme 加 -outline 後綴 -->
<card-badge text="info-outline"    theme="info-outline"></card-badge>
<card-badge text="special-outline" theme="special-outline"></card-badge>

<!-- 方式 2：theme 不變，加上 outline="true" 屬性 -->
<card-badge text="outline 屬性" theme="sky" outline="true"></card-badge>
提示 Outline 模式下，背景會設為主題色的 12% 透明度，邊框為 1px solid 主題色，文字也使用主題色。亮色背景（如 special、vanilla）在 outline 模式下視覺效果特別清晰。

日期時間格式

設定 type 和 value 後，元件自動格式化並顯示日期或時間字串，不需要手動格式化。

範例 7  三種格式類型 常用
HTML
<!-- type="date"，預設格式 YYYY-MM-DD -->
<card-badge type="date" value="2025-08-15" theme="info" icon="📅"></card-badge>

<!-- format 可選 YYYY-MM-DD / MM/DD / MM-DD -->
<card-badge type="date" value="2025-08-15" format="MM/DD"
            theme="stone" icon="📅"></card-badge>

<!-- type="time"，顯示 HH:mm -->
<card-badge type="time" value="09:30:00" theme="special" icon="🕘"></card-badge>

<!-- type="datetime"，預設格式 MM/DD HH:mm -->
<card-badge type="datetime" value="2025-08-15T14:30:00"
            theme="indigo" icon="🗓️"></card-badge>

截止日期

type="deadline" 自動計算距今天數：逾期時切換為 warning 色並加警告圖示，接近截止（≤ warning-days）時改用 yellow 色，正常時使用設定的 theme 色。

範例 8  截止日期三種狀態 常用
HTML
<!-- 已逾期 → warning 色 + ⚠️ 圖示 -->
<card-badge type="deadline" value="2020-01-01" theme="info"></card-badge>

<!-- 距截止 ≤ warning-days → yellow 色；預設 warning-days="3" -->
<card-badge type="deadline" value="2099-12-30"
            warning-days="30" theme="info"></card-badge>

<!-- 剩餘天數 > warning-days → 使用 theme 色 -->
<card-badge type="deadline" value="2099-12-30"
            warning-days="5" theme="info"></card-badge>
狀態色彩圖示
已逾期（diffDays < 0）warning⚠️（自動加入）
今天到期（diffDays = 0）attention（= yellow）📅
≤ warning-daysattention（= yellow）📅
正常範圍與 theme 屬性同📅

數量徽章

設定 count 屬性進入數量模式。數字超過 max-count 顯示「N+」；dot-mode="true" 則不顯示數字，只顯示圓點。

範例 9  數量與圓點 常用
HTML
<!-- 基本數量 -->
<card-badge count="5" theme="warning"></card-badge>

<!-- 超過 max-count 顯示 99+ -->
<card-badge count="100" theme="info" max-count="99"></card-badge>

<!-- 圓點模式（只顯示色點） -->
<card-badge count="3" theme="safe" dot-mode="true"></card-badge>

<!-- count=0 時預設隱藏，show-zero="true" 強制顯示 -->
<card-badge count="0" theme="special" show-zero="true"></card-badge>

<!-- 搭配圖示 -->
<card-badge count="8" theme="info" icon="bi-bell"></card-badge>

動態更新數量

HTML + JS
<card-badge id="badge" count="0" theme="info"
            show-zero="true" count-animate="true"></card-badge>

<script>
  const badge = document.getElementById('badge');

  // 直接修改 count 屬性，元件自動更新並播放彈跳動畫
  badge.setAttribute('count', parseInt(badge.getAttribute('count')) + 1);
</script>
提示 count-animate="true" 讓數字更新時播放 scale 彈跳動畫，動畫名稱帶入實例 UID 確保多個徽章同時動畫不互相干擾。設為 false 可停用動畫。

可點擊與懸停效果

加上 clickable="true" 後，元件獲得 tabindex、cursor: pointer 及焦點樣式，並可搭配 hover-effect 選擇懸停動畫。

範例 10  五種懸停效果 常用
HTML
<card-badge text="lift（預設）" theme="info"
            clickable="true" hover-effect="lift"></card-badge>

<card-badge text="scale"  theme="special"
            clickable="true" hover-effect="scale"></card-badge>

<card-badge text="glow"   theme="safe"
            clickable="true" hover-effect="glow"></card-badge>

<card-badge text="pulse"  theme="indigo"
            clickable="true" hover-effect="pulse"></card-badge>

<card-badge text="rotate" theme="orange"
            clickable="true" hover-effect="rotate"></card-badge>
hover-effect效果說明
lift上浮 3px，加深陰影（預設）
scale放大至 1.08 倍
glow外發光（使用主題色 55% 透明度）
pulse單次 scale 脈衝動畫（0.6s）
rotate輕微旋轉 2deg + 上浮
none無懸停效果
焦點樣式 可點擊的徽章支援鍵盤焦點（Tab 鍵可聚焦，Enter / Space 可觸發點擊），焦點圈顏色使用 focus-color 屬性設定，預設與 theme 同色。

連結與自我移除

範例 11  連結跳轉
HTML
<card-badge text="前往 GitHub" icon="bi-github"
            theme="info"
            href="https://github.com"
            href-target="_blank"
            clickable="true"></card-badge>
範例 12  點擊後自我移除
HTML
<!-- removeself="true" 讓徽章點擊後以動畫淡出並從 DOM 移除 -->
<card-badge text="× 點我消失"
            theme="warning"
            clickable="true"
            removeself="true"></card-badge>

複製功能

設定 action="copy" 後，點擊徽章會將文字寫入剪貼簿，同時可選擇性地貼到指定目標元素（target）或從來源元素讀取（source）。

範例 13  複製固定文字 常用
← 點擊後顯示提示並複製「https://example.com」到剪貼簿
HTML
<!-- text 屬性也是複製的來源文字 -->
<card-badge text="複製連結" icon="bi-clipboard"
            theme="info" clickable="true"
            action="copy"
            alert-message="連結已複製！" alert-type="success"></card-badge>
範例 14  從 source 元素讀取並複製
HTML
<input id="my-input" type="text" value="這段文字會被複製">

<!-- source 指向來源元素 id -->
<card-badge text="複製輸入框內容" icon="bi-copy"
            theme="special" clickable="true"
            action="copy" source="my-input"
            alert-message="已複製！" alert-type="success"></card-badge>
屬性說明預設
action="copy"啟用複製行為—
source讀取此 ID 元素的文字（input.value 或 textContent）—（用 text 屬性）
target同時將文字寫入此 ID 元素（input.value 或 textContent）—
copy-html設為 true 時讀取 innerHTML 而非 textContentfalse

折疊控制

設定 toggle-target 為目標元素的 ID，點擊徽章時以動畫展開或收起目標元素；圖示會自動旋轉 180° 表示狀態。

範例 15  折疊區塊 常用
詳細說明

這是可以折疊的詳細內容區塊。點擊上方的徽章圖示可以展開或收起。圖示會跟著狀態旋轉，展開時指向上方。

HTML
<div style="display:flex; align-items:center; gap:8px;">
  <strong>詳細說明</strong>

  <!-- toggle-target 指向要折疊的元素 id -->
  <card-badge icon="bi-chevron-down"
              theme="info-outline"
              clickable="true"
              toggle-target="detail-section"
              hover-effect="none"></card-badge>
</div>

<div id="detail-section">
  <p>這是可以折疊的詳細內容。</p>
</div>
提示 圖示元素（.badge i 或 .badge .icon）在折疊時 transform: rotate(0deg)，展開時 rotate(180deg)，搭配 bi-chevron-down 效果最直觀。

過濾功能

設定 action="filter" 與 data-filter，點擊後頁面上具有 data-filter-group 屬性的元素會依標籤篩選顯示或隱藏。

範例 16  標籤過濾清單 常用
Vue.js React Node.js Python Figma Tailwind
HTML
<!-- 過濾器徽章 -->
<card-badge text="全部" theme="info"    clickable="true"
            action="filter" data-filter="all"></card-badge>
<card-badge text="前端" theme="special" clickable="true"
            action="filter" data-filter="frontend"></card-badge>
<card-badge text="後端" theme="safe"    clickable="true"
            action="filter" data-filter="backend"></card-badge>

<!-- 被過濾的內容元素 -->
<span data-filter-group="frontend">Vue.js</span>
<span data-filter-group="backend">Node.js</span>

<!-- 一個元素屬於多個分類，用逗號分隔 -->
<span data-filter-group="frontend,design">Tailwind</span>

輪播模式

輪播使用隱藏的 <badge-item> 子元素儲存候選內容。共有三種動作模式，決定每次點擊輪播的目標。

三種輪播動作

action行為需要
rotate-content每次點擊將 badge-item 的內容寫入 target 元素target
rotate-self每次點擊自身切換下一個 badge-item 的文字／圖示／主題，並展開至 targetbadge-item 子元素
rotate-self-auto按 interval 自動輪播；點擊展開當前項目到 targetbadge-item + interval
範例 17  rotate-content：點擊輸出到目標區
訣竅 1：多用 outline 模式，視覺更輕量。 訣竅 2：用 size="xs" 搭配數量徽章作為通知點。 訣竅 3：hover-effect="glow" 在深色背景最搶眼。
點擊上方徽章顯示訣竅…
HTML
<card-badge text="顯示訣竅" icon="💡"
            theme="info" clickable="true"
            action="rotate-content"
            target="output-area">

  <!-- badge-item 子元素的 innerHTML 會依序寫入 target -->
  <badge-item>訣竅 1：多用 outline 模式，視覺更輕量。</badge-item>
  <badge-item>訣竅 2：用 size="xs" 搭配數量徽章作為通知點。</badge-item>
  <badge-item>訣竅 3：hover-effect="glow" 在深色背景最搶眼。</badge-item>

</card-badge>

<div id="output-area">點擊徽章顯示訣竅…</div>
範例 18  rotate-self：徽章本身切換外觀
HTML
<card-badge text="狀態 A" theme="info"
            clickable="true" action="rotate-self">

  <!-- badge-item 用 text / icon / theme 屬性指定各輪播外觀 -->
  <badge-item text="狀態 A" theme="info"    icon="🔵"></badge-item>
  <badge-item text="狀態 B" theme="special" icon="🟡"></badge-item>
  <badge-item text="狀態 C" theme="safe"    icon="🟢"></badge-item>

</card-badge>

每 2 秒自動切換

            interval="2s">

  <badge-item text="Vue.js"  theme="safe"    icon="💚"></badge-item>

  <badge-item text="Svelte"  theme="orange"  icon="🔥"></badge-item>

</card-badge>

字體控制

設定 font-control 為目標元素 ID，搭配 action 為 font-increase、font-decrease 或 font-reset，點擊後調整目標字體大小。每次步進量由 font-step 設定（預設 2px）。

範例 20  字體放大縮小重設 常用

這段文字的大小會被上方徽章控制。最小 12px，最大 32px。

HTML
<card-badge text="A+" theme="info"
            clickable="true"
            action="font-increase"
            font-control="target-text"
            font-step="2"></card-badge>

<card-badge text="A-" theme="stone"
            clickable="true"
            action="font-decrease"
            font-control="target-text"
            font-step="2"></card-badge>

<card-badge text="重設" theme="region"
            clickable="true"
            action="font-reset"
            font-control="target-text"></card-badge>

<p id="target-text">這段文字的大小由徽章控制。</p>

浮動提示

點擊徽章後，可在頁面固定位置彈出一條品牌色浮動提示，幾秒後自動消失。訊息內容可從屬性直接設定，或從另一個元素動態讀取。

範例 21  四種提示類型 常用
HTML
<card-badge text="成功訊息" theme="safe" clickable="true"
            alert-message="操作成功！"
            alert-type="success"
            alert-position="top"
            alert-duration="3000"></card-badge>

<card-badge text="一般資訊" theme="info" clickable="true"
            alert-message="這是一則資訊提示。"
            alert-type="info"
            alert-position="top-right"></card-badge>

<card-badge text="注意警告" theme="yellow" clickable="true"
            alert-message="請注意這個操作！"
            alert-type="warning"></card-badge>

<card-badge text="錯誤訊息" theme="warning" clickable="true"
            alert-message="發生錯誤，請重試。"
            alert-type="danger"></card-badge>
範例 22  從另一個元素讀取訊息
HTML
<input id="msg-input" type="text" value="輸入要顯示的訊息">

<!-- alert-source 指向來源元素 id，動態讀取其 value 或 textContent -->
<card-badge text="顯示訊息" icon="📢"
            theme="info" clickable="true"
            alert-source="msg-input"
            alert-type="info"></card-badge>
屬性說明預設
alert-message直接設定顯示文字—
alert-source從此 ID 元素讀取文字（優先於 alert-message 以外情境）—
alert-typeinfo / success / warning / dangerinfo
alert-duration顯示時長（ms）4000
alert-positiontop / top-left / top-right / bottom / bottom-left / bottom-righttop

自訂事件

元件在關鍵動作後會 dispatchEvent 自訂事件，讓外部 JavaScript 可以監聽並做進一步處理。所有事件都帶有 bubbles: true，可在父元素上冒泡接收。

範例 23  監聽 badge-click
等待事件…
JavaScript
document.getElementById('my-badge').addEventListener('badge-click', function(e) {
  console.log(e.detail);
  // {
  //   action       : 'copy',       // 目前的 action 屬性值
  //   filter       : null,         // data-filter 值
  //   source       : 'input-id',   // source 屬性值
  //   target       : 'out-id',     // target 屬性值
  //   toggleTarget : null,
  //   fontControl  : null,
  //   isCollapsed  : false,        // toggle 時的折疊狀態
  //   type         : null,         // type 屬性值
  //   value        : null,
  //   text         : '複製內容',
  //   count        : 0,
  //   href         : null,
  //   alertMessage : '已複製！'
  // }
});
事件名稱觸發時機detail 欄位
badge-click任何點擊動作完成後action, filter, source, target, toggleTarget, fontControl, isCollapsed, type, value, text, count, href, alertMessage
badge-rotate輪播切換（rotate-content / rotate-self）mode, currentIndex, totalItems, targetId
badge-expandrotate-self-auto 手動點擊展開currentIndex, totalItems, targetId

停用狀態

設定 disabled="true" 後，元件套用灰化外觀，阻擋所有點擊與鍵盤事件，cursor 改為 not-allowed。

範例 24  正常與停用對比

<card-badge text="停用" theme="info"
            clickable="true" disabled="true"></card-badge>

<!-- 也可在執行時動態切換 -->
<script>
  badge.setAttribute('disabled', 'true');   // 停用
  badge.setAttribute('disabled', 'false');  // 恢復
</script>
