<ui-drag-ans> 拖曳填空

題目中的空格用 {答案} 標記，元件自動產生對應的小卡。把小卡拖到正確的空格，或先點小卡再點空格，空格就換成格式化的答案，用掉的小卡消失；放錯會彈回原位。比對區分大小寫。滑鼠、觸控、觸控筆都能操作。建立日期 11-12-26。

範例一：小卡在下方（預設）

<drag-card> 是干擾卡，不屬於任何空格。全部完成後，剩下的干擾卡會淡出，並出現完成提示與「重做」按鈕。

範例二：小卡在右側，自訂答對後的格式

用 <drop-slot answer="答案"> 時，標籤裡的 HTML 就是答對後顯示的內容。這裡也示範方框空格（slot-shape="box"）與底線樣式的填入文字。

範例三：小卡在左側，淺色主題與各部位覆蓋

theme="shell" 是淺色底。題目框、空格、小卡、填入文字的框線樣式、粗細與顏色都用屬性覆蓋主題。filled-style="highlight" 讓填入的答案帶螢光底。

範例四：和 ui-cards 協作

第一張卡片的內文直接放 ui-drag-ans。第二張卡片點開後，內容區從 <template> 複製題目；第三張則從隱藏的 <div> 複製。被複製的題目都會重新建立成可作答的狀態，作答時的點擊也不會觸發卡片本身的點擊功能。

修訂 v1.1.0：放對時小卡逐漸縮小

放對時，小卡會移到空格中央，逐漸縮小後消失，接著空格才顯示答案。縮小期間空格保持亮起，表示已收下這張卡。拖曳和「點小卡再點空格」都有這個動畫，最後一格的動畫結束後才出現完成提示。shrink-duration 調整縮小時間（毫秒，預設 450），drop-anim="none" 關閉動畫。左邊是慢速 900 毫秒，右邊是關閉動畫，可以對照。

修訂 v1.1.0：程式碼對照

v1.0.0 放對時，小卡只淡出並縮到原大小的六成，空格立刻顯示答案。v1.1.0 改成小卡移到空格中央，逐漸縮小再顯示答案；點選作答時也會先複製一張小卡來播放動畫。

/* v1.0.0 */
_fill(slot, card, ghost) {
  slot.innerHTML = slot._filledHtml || esc(slot.dataset.answer);
  slot.classList.add('uda-filled');
  if (ghost) {
    var r = slot.getBoundingClientRect();
    var a = ghost.animate([
      { transform: ghost.style.transform, opacity: 1 },
      { transform: 'translate(' + r.left + 'px,' + r.top + 'px) scale(.6)', opacity: 0 }
    ], { duration: 220, easing: 'ease-in', fill: 'forwards' });
    a.onfinish = function () { ghost.remove(); };
  }
  card.classList.remove('uda-lifted');
  card.classList.add('uda-gone');
  setTimeout(function () { card.remove(); }, 220);
}
/* v1.1.0 */
_fill(slot, card, ghost, instant) {
  var dur = parseInt(this._val('shrink-duration'), 10);
  if (!(dur >= 0)) dur = 450;
  var anim = String(this._val('drop-anim')).toLowerCase() === 'none' || instant ? 'none' : 'shrink';
  slot.classList.add('uda-filled');   /* 先鎖住空格 */
  slot.classList.add('uda-wait');     /* 縮小期間空格保持亮起 */
  function reveal() {
    slot.innerHTML = slot._filledHtml || esc(slot.dataset.answer);
    slot.classList.remove('uda-wait');
  }
  if (anim === 'shrink' && dur > 0) {
    if (!ghost) ghost = this._makeGhost(card, card.getBoundingClientRect());
    var r = slot.getBoundingClientRect();
    var w = ghost.offsetWidth, h = ghost.offsetHeight;
    var to = 'translate(' + (r.left + r.width / 2 - w / 2) + 'px,' +
             (r.top + r.height / 2 - h / 2) + 'px)';
    var a = ghost.animate([
      { transform: ghost.style.transform, opacity: 1 },
      { transform: to + ' scale(.75)', opacity: 1, offset: 0.35 },
      { transform: to + ' scale(.4)',  opacity: 1, offset: 0.75 },
      { transform: to + ' scale(.05)', opacity: 0 }
    ], { duration: dur, easing: 'ease-in', fill: 'forwards' });
    a.onfinish = function () { ghost.remove(); reveal(); };
  } else {
    if (ghost) ghost.remove();
    reveal();
    dur = 0;
  }
  card.classList.remove('uda-lifted');
  card.classList.add('uda-gone');
  setTimeout(function () { card.remove(); }, 220);
  return dur;   /* 最後一格等動畫結束才觸發完成 */
}

屬性、事件與方法

顏色可寫色票名稱（background、bg-alternative、shell、vanilla、yellow、pink、red、green、blue、indigo、violet、gray、key、calm、quiet、playful、urgent、energetic、dreamy）或任何 CSS 顏色；邊框寫成「粗細 樣式 顏色」，例如 2 solid key，純數字視為 px，none 為無邊框。

屬性預設說明

內容與行為

{答案}寫在題目文字中，產生空格與一張小卡。要顯示一般大括號時寫 \{、\}；code、pre 內的大括號不處理。
<drop-slot answer>空格的另一種寫法，標籤裡的 HTML 是答對後顯示的內容。
<drag-card>干擾卡。內文可含 HTML；比對值為文字內容，也可用 value 指定。
bankbottom小卡位置：bottom、left、right。
shuffle開啟小卡隨機排列；shuffle="false" 依出現順序（先干擾卡，再依空格順序）。
reset-buttondone「重做」按鈕：done 完成後出現、always 一直顯示、none 不顯示。
label-done、label-reset全部完成！、重做完成提示與按鈕文字。
drop-animshrink放對時的動畫：shrink 小卡移到空格中央逐漸縮小，none 不播放。（v1.1.0）
shrink-duration450縮小動畫的時間，單位毫秒。（v1.1.0）

主題與覆蓋

themekeykey、violet、pink（深色底），shell（淺色底）。下列屬性都能覆蓋主題。
accent依主題強調色：選取中的小卡外框、拖曳經過空格的底色、完成提示。
frame-border、frame-radius、frame-bg、frame-color、frame-padding依主題、0、依主題、依主題、24 40題目框。
slot-border、slot-shape、slot-width、slot-hover-color依主題、line、自動、依 accent空格。line 只有底線，box 為方框；寬度預設依最長的答案自動計算，所有空格同寬。
card-border、card-radius、card-bg、card-color、card-padding依主題、0、依主題、依主題、8 20小卡。
bank-border、bank-bg、bank-gap、bank-padding、bank-widthnone、透明、10、0、220小卡區；bank-width 用於左右兩側。
filled-color、filled-style依主題、bold填入的答案。filled-style 可組合 bold、underline、highlight、italic，空白分隔。
font-size、card-font-size1.25、1題目與小卡字級，純數字視為 rem。

事件與方法

drag-ans:correct{ answer, slot }放對時。
drag-ans:wrong{ answer, expected, slot }放錯時。
drag-ans:complete{ wrong, total }全部空格完成時，wrong 為放錯次數。
drag-ans:reset重做時。
reset()、revealAll()、progress重做；直接填入全部答案；目前進度 { filled, total, wrong }。
