ui-table 的 inverse，extra-info 與 alert 屬性

inverse 讓儲存格的文字色與底色對調。extra-info 在儲存格右側加上圖示，點擊後以 popover 顯示指定 div 的內容。alert 讓儲存格定時浮現提示訊息。

基本用法：表頭反色

只有加了 inverse 的儲存格會反色，其餘維持原樣。

各種字色的反色效果

第一列是反色，第二列是原樣，方便對照。

字色的優先順序

底色沿用原本的文字色，優先順序為 ui-col，ui-row，ui-table，最後是 theme。

與其他屬性並用

圖示，展開，輪播，遮罩與自動編號都可以和 inverse 同時使用。展開箭頭與輪播進度條在反色底上會自動改為深色。

extra-info：基本用法

extra-info 的值是 div 的 id。該 div 在元件載入時自動隱藏，內容支援 HTML 標籤。點擊圖示開啟，再點一次圖示，點外面或按 Esc 關閉。

extra-info：與 inverse，expandable 並用，以及文字換行

圖示是排在文字右側的獨立欄位，文字只會在圖示左側換行，不會壓到圖示。反色儲存格的圖示自動改為深色。同一個 div 可以被多個儲存格引用。

extra-info：與遮罩，輪播互斥

有 mask-text 或 carousel-interval 的儲存格，extra-info 會被忽略，不會出現圖示，並在主控台顯示警告。

alert：三種顯示位置

alert-msg 是提示文字，alert-interval 是間隔毫秒數。每個提示在載入後經過一個間隔第一次出現，顯示 5 秒，之後每隔一個間隔重複一次，所以間隔要大於 5000。alert-pos 決定位置：A 蓋在儲存格上，B 在儲存格上方，C 在儲存格右側。以下三個提示會在約 6，7，8 秒後依序出現。

alert：HTML 訊息與預設顏色

alert-msg 的值如果是隱藏的 ui-col 的 id，就會改用那個 ui-col 的內容，支援 HTML 標籤。沒有指定 alert-color 時使用 theme 色。

JSON 資料來源

在欄位物件加上 inverse: true 或 extraInfo 即可，extraInfo 指定的 div 要放在 ui-table 之外。下方是頁面使用的資料。

inverse 行為說明

項目 行為 底色 該儲存格原本的文字色，不透明度 0.97。 文字與圖示 固定為 #0C0D0C。 fixed 與 fixed 並用時，inverse 的底色優先。 hover 反色儲存格不套用 hover-bg-color。 expandable 展開箭頭改為 #0C0D0C。 progress-bar 未指定 progress-bar-color 時，預設改為 #0C0D0C。 mask-invert 只影響遮罩層，可以和 inverse 同時使用。

extra-info 行為說明

項目 行為 來源區塊 以 id 指定的 div，載入時自動隱藏，內容支援 HTML 標籤。要放在 ui-table 與 ui-col 之外。 圖示 儲存格內容右側的圓點格圖示，顏色沿用 theme。反色儲存格改為 #0C0D0C。 popover 深色底加 theme 色邊框與文字。點擊圖示開啟，再點一次圖示，點外面或按 Esc 關閉，全頁同時只開一個。 定位 預設對齊圖示右緣往左下展開，下方空間不足時翻到上方，並限制在視窗內。頁面捲動時跟著圖示移動。 互斥 與 mask-text，carousel-interval 互斥，extra-info 會被忽略並在主控台顯示警告。 並用 可以和 inverse，expandable，show-next 並用。圖示排在內容之後，展開箭頭之前，不會點擊穿透到 show-next。 內容更新 點擊當下才讀取 div 的內容，之後用 JavaScript 修改 div，popover 會顯示最新的。 載入閃現 想避免載入瞬間看到來源區塊，可以在 div 加上 hidden 屬性。

alert 行為說明

項目 行為 alert-msg 提示文字，或隱藏的 ui-col 的 id。使用 id 時內容支援 HTML 標籤。隱藏的 ui-col 要放在 ui-table 底下，ui-row 之外。 alert-interval 間隔毫秒數。載入後經過一個間隔第一次出現，之後每隔一個間隔重複。要大於顯示時間，否則提示會連續出現。 顯示時間 預設 5000 毫秒，由 UiTable.config.alertDuration 決定，要在初始化之前設定。 alert-pos A 蓋在儲存格上，B 顯示在儲存格上方並靠左對齊，C 顯示在儲存格右側，未指定時為 C。B 與 C 掛在 body 上，不受儲存格裁切，也不會擋住點擊。 alert-color 品牌色名稱或色碼，未指定時使用 theme 色。底色不透明度 0.92，文字為 #0C0D0C。 互斥 與 carousel-interval 互斥，carousel-interval 會被忽略並在主控台顯示警告。 被隱藏時 B 與 C 在儲存格被隱藏時（例如 show-next 尚未展開的列）不顯示。
