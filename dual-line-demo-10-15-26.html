extraclass · Bootstrap 整合 NEW

extraclass 屬性的值會整批套用到元素的 classList。 當 extraclass 存在且未同時設定 margin 屬性時， 元件會跳過 inline margin，讓 Bootstrap class 接管間距。

條件 margin 來源
無 extraclass inline style（屬性值或預設值）
有 extraclass，無 margin 屬性 Bootstrap class 接管（不設 inline margin）
有 extraclass，也有 margin 屬性 inline style 優先（明確設定，優先級高）

示範：extraclass="my-5"

Block A
Block B（距上方 Block A 已有 Bootstrap my-5 間距）
<dual-hr color-left="lavender" color-right="ocean" thickness="2px" extraclass="my-5" ></dual-hr> // 不設 margin 屬性 → Bootstrap my-5 完整生效

示範：透明留白 + extraclass="my-5"

最簡潔的 Bootstrap 留白寫法，厚度設為 0（或不設），完全靠 my-5 撐開。

Section 1
Section 2（Bootstrap my-5 留白）
Section 3（Bootstrap my-3 留白）
<!-- my-5 留白 --> <dual-hr line-style="none" thickness="0" extraclass="my-5"></dual-hr> <!-- my-3 留白 --> <dual-hr line-style="none" thickness="0" extraclass="my-3"></dual-hr>

示範：dual-vr + extraclass="mx-3"

Left Center Right
<dual-vr color-top="teal" color-bottom="ocean" height="60px" thickness="2px" extraclass="mx-3" ></dual-vr>
