區域縮時錄影

框選頁面上的任意方形區域，以低頻取樣累積影格，停止後自動快轉輸出成 webm 影片。

操作步驟

  1. 按右下角的 框選區域，拖曳出要錄的方形範圍，按 Esc 可取消。
  2. 設定取樣間隔與輸出 FPS，兩者的比值就是加速倍率。
  3. 按 開始錄製，瀏覽器會跳出畫面分享視窗，務必選擇 這個分頁。
  4. 錄製一開始控制列會自動隱藏，只留一顆迷你停止鈕在離框最遠的角落。錄製期間不會出現任何畫面提示，相關訊息改印在瀏覽器主控台。
  5. 按 Esc 停止並存檔，Shift+Esc 丟棄這次錄製，也可以直接點那顆迷你鈕。
  6. 影片會自動下載為 timelapse-日期時間.webm。

加速倍率的算法：取樣 0.5 秒一格、輸出 24 FPS，等於 1 秒的影片涵蓋 12 秒的實際時間，也就是 12 倍速。

程式介面：

<script src="timelapse-capture.js"></script>
<ui-timelapse data-region="80,120,960,540"></ui-timelapse>

<script>
  var tl = window.Timelapse.el();

  tl.setRegion({ x: 80, y: 120, w: 960, h: 540 });
  tl.useStudioFrame();   // 沿用 teach-studio 的錄影框
  tl.start();            // 等同按下開始錄製
  tl.stop();             // 停止並輸出存檔
  tl.discard();          // 放棄這次錄製
</script>

若頁面同時載入 teach-studio.js，按「沿用錄影框」會直接套用主控列設定的那個範圍，兩者座標一致。

限制與注意事項

  • 分享畫面時必須選 這個分頁。選整個螢幕或其他視窗，座標換算會對不上，錄到的會是錯位的範圍。
  • 錄製期間請不要捲動頁面。框選的座標是視窗座標，捲動後畫面內容會位移。
  • 輸出格式為 webm，YouTube 可直接上傳。要 mp4 請用剪輯軟體轉檔。
  • 影格以 JPEG 暫存在記憶體，上限 6000 格或 600 MB，先到者為準，控制列會即時顯示暫存量。
  • 取樣 0.1 秒與 0.2 秒時單格品質自動降為 0.72，密集取樣才不會吃光記憶體。前一格尚未壓縮完成時會自動跳過該次取樣。
  • 輸出階段是以真實時間快轉重播並錄製，所以 1000 格搭配 24 FPS 需要等約 42 秒。
