ui-fillin 全功能示範

選擇題挖空元件。題幹用 {*正確答案|選項二|選項三} 標記空格，題號與答案表自動對齊。每個區塊左側是實際效果，右側是同一份原始碼，兩邊取自同一段文字，不會不一致。

元件的提示訊息使用 bootstrap alert，所以頁面需要載入 bootstrap 5 的樣式表。

語法與屬性總表

標記語法

寫法說明
{A|B|C}一個空格，直線分隔選項。題號依出現順序自動產生。選項至少兩個才會成為空格。
{*A|B|C}選項開頭的星號表示正確答案。
{*A|*B|C}多個星號即為複選，必須完全相符才算對。
\| \* \{ \}反斜線跳脫，讓選項能出現這些符號。
頭尾空白每個選項的頭尾空白自動去除。

標籤與屬性

元素屬性說明預設
<ui-fillin>results-id批改結果要輸出到哪一個 div 的 id。該 div 內原有的 HTML 與其他元件不會被清除。內含 data-uf-results 的元素就是結果的寫入位置，沒有的話，結果附加在 div 末端。不輸出
<ui-fillin>font-size全域字級，元件內所有文字依此縮放。純數字視為 rem。1rem
<ui-fillin>root-padding元件最外層容器。12px
<ui-fillin>main-padding題幹區塊。12px
<ui-fillin>blank-padding題幹內的空格按鈕。12px
<ui-fillin>menu-padding浮出的選項清單外框。12px
<ui-fillin>option-padding清單內每一個選項。12px
<ui-fillin>ans-padding答案區塊外框。12px
<main-box>source來源 div 的 id，必填。解析後來源 div 會被隱藏並清空。無
<ans-box>無答案表與按鈕列。省略時元件自動補上。無

padding 屬性值只接受 px 或純數字，最多四個值，例如 8、8px 16px。其他寫法會被忽略並改用預設值。

事件、方法與樣式變數

類型名稱說明
事件fillin-change選擇變動。detail 為題號與所選文字陣列。
事件fillin-submit提交批改。detail.results 為每題的題號、對錯、是否作答。
事件fillin-reset重做。
方法submit()提交並批改，提交後鎖定。
方法reset()清除作答、解除鎖定並清空結果區塊。
方法closeMenu()關閉目前開啟的選項清單。
CSS 變數--uf-bg --uf-text --uf-sky --uf-lavender --uf-focus --uf-ok --uf-bad --uf-head --uf-info --uf-line --uf-sans --uf-serif --uf-font-size全部顏色與字體都由變數控制，在 ui-fillin 上覆寫即可換主題。

一、基本單選

點空格按鈕，選項在旁邊浮出。選完後答案表同步更新。可以直接按「提交答案」，沒作答的題目算錯誤，顯示為未作答。提交後空格鎖定，按「重做」可重新作答。

三、跳脫字元與例外

四、results-id 自由排版

  
在 ui-fillin 加上 results-id，提交後元件把精簡的語意結果寫進該 div，沒有任何版面樣式，排版完全由你決定。結果區塊裡可以自由放 HTML 標籤與其他 js 元件，元件只動 data-uf-results 這個位置，其他內容保持原樣，不會被重建，所以其他元件的狀態與計時不會中斷。下面的 demo-tick 是一個每秒計數的小元件，提交與重做時它都繼續運作。每一項結果帶有 data-state（correct 或 incorrect）與 data-answered（true 或 false），只顯示對錯，不含比例。

九、全域 font-size

  
在 ui-fillin 加上 font-size，預設 1rem。題幹、空格按鈕、選項清單、答案表、按鈕列都依它縮放，題幹字級固定為它的 1.1 倍。值只接受純數字或 rem，無效值會被忽略。本頁根字級設為 18px，所以 1rem 等於 18px。
