教材格式

英文句中以方括號標示要挖空的字詞，匯入 .txt 時用 [ZH] 與 [EN] 分段；.json 則是 zh／en 欄位的陣列。

貼上後按下方按鈕可即時替換頁面題組，課前備課不必重新整理。

頁面用法只要三步，元件自動註冊

<script src="cloze-handwrite.js"></script>
<script src="teach-studio.js"></script>

<ui-studio-bar></ui-studio-bar>
<ui-spotlight></ui-spotlight>
<ui-annotate-layer></ui-annotate-layer>
<ui-lower-third></ui-lower-third>
<ui-key-hud></ui-key-hud>
<ui-handwrite-modal></ui-handwrite-modal>

<script>
  var block = document.createElement('ui-bilingual-block');
  block.setAttribute('data-title', 'Part 2　描述一項技能');
  document.getElementById('blocks').appendChild(block);
  block.data = { zh: '中文翻譯', en: 'English with [blanks].' };
  window.TeachStudio.bar().refresh();
</script>
