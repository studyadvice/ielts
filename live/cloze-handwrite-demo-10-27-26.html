cloze-handwrite 元件示範

同一元件的多次修改都會附加在這個檔案，依版本由上而下排列。

v210-27-26　右側垂直工具列（A-／A+／P-／P+）

題組方框右側新增四個垂直排列的小按鈕：A-／A+ 縮放英文字體，P-／P+ 調整中文與英文之間的空白，每按一次增減 16px，範圍 0 至 600px。按鈕尺寸由 34x36 縮小為 28x28。

v310-27-26　虛線色與答案文字色屬性

新增兩個屬性，可設在 ui-cloze-text 或 ui-bilingual-block，值可用色票名稱或任何 CSS 色彩：data-blank-color 控制空格下方虛線，預設 shell；data-answer-color 控制答案文字，預設 sky。答案文字需按下方按鈕（或主控列的 A 鍵）顯示。

v410-27-26　題組標題取代「中文」

摺疊列原本固定顯示「中文」，現在改顯示題組標題。標題來源依序為 data.title、data-title 屬性，兩者都沒有時仍顯示「中文」。JSON 匯入的 title 欄位也會保留。

v510-27-26　純標籤寫法（不需 JS）

題組內容直接寫在 HTML 裡：data-title 屬性放標題，<ui-zh> 放中文，<ui-en> 放英文並用方括號挖空。下方這個題組完全沒有用 JS 塞資料。

我想談談台南的一條老街。那裡的房子多半有上百年歷史，窄巷裡飄著麻油與線香的氣味。 I'd like to describe an old street in Tainan, a place that has [stuck with me] ever since. Most of the houses there are well over a century old, and the narrow lanes are [steeped in] the smell of sesame oil and incense.

v610-27-26　題組間距與邊框色屬性

兩個新屬性設在 ui-bilingual-block 上：data-block-gap 是這個題組與下一個題組之間的距離，單位 px，預設 66；data-border-color 是題組邊框色，可用色票名稱或 CSS 色彩，預設 #26271f。下方三個題組依序是預設、間距 160 加 lavender 邊框、間距 24 加 #EDA109 邊框。

程式碼對照

v6 屬性用法

<ui-bilingual-block data-block-gap="160" data-border-color="lavender">
  ……
</ui-bilingual-block>

// 動態修改
block.setAttribute('data-block-gap', '24');
block.setAttribute('data-border-color', '#EDA109');

v5 純標籤用法

<ui-bilingual-block data-title="Part 2　描述一個讓你印象深刻的地方">
  <ui-zh>我想談談台南的一條老街。……</ui-zh>
  <ui-en>I'd like to describe an old street in Tainan, a place that has [stuck with me] ever since. ……</ui-en>
</ui-bilingual-block>

<!-- 較短的內容也可用屬性 -->
<ui-bilingual-block data-zh="中文" data-en="English with [blanks]."></ui-bilingual-block>

v4 標題用法

block.data = { title: 'Part 1　Do you live in a house or in a flat?', zh: '...', en: '...' };

<ui-bilingual-block data-title="Part 2　自訂標題"></ui-bilingual-block>

// 沒有標題時，摺疊列仍顯示「中文」

v3 屬性用法

<!-- 預設：虛線 shell，答案 sky -->
<ui-bilingual-block></ui-bilingual-block>

<!-- 色票名稱 -->
<ui-bilingual-block data-blank-color="lavender" data-answer-color="special"></ui-bilingual-block>

<!-- 任何 CSS 色彩，且可單獨設在 ui-cloze-text -->
<ui-cloze-text data-blank-color="#E5C3B3" data-answer-color="#FF91D7"></ui-cloze-text>

// 動態修改
block.setAttribute('data-blank-color', 'orange');
