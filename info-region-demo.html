基本鏈式步驟

next / next-interval / color — 每個區塊自動激活下一個

<info-region>
鏈式激活 next="id" next-interval="ms" color="..."

第一個 region active 後等待 next-interval ms，自動設定 next 指定元素的 active="true"，依此串聯。

步驟 1 — color="ocean"，next-interval="600"：600ms 後自動激活下一步。 步驟 2 — color="teal"，next-interval="800"：800ms 後繼續。 步驟 3 — color="special"，使用預設 next-interval（500ms）。 步驟 4（終點） — 無 next 屬性，鏈結到此結束。
所有色票預覽 color="..."

20 個內建色票的 border-left 顏色展示。點擊「全部激活」後可看到各色的左邊框效果。

倒數計時

countdown / countdown-position / countdown-height / countdown-color

倒數進度條 countdown="ms" countdown-position="top|bottom" countdown-height="px" countdown-color="..."

激活後在 position 方向顯示從滿到空的進度條，時間到後自動激活下一步。

步驟 1 — countdown="2000"，底部倒數條（height=4px），2 秒後自動進入下一步。 步驟 2 — countdown-position="top" + height="6"：頂部粗條，1.5 秒。 步驟 3（無倒數） — 無 countdown 屬性，激活後停留。

手動按鈕模式

manual / manual-label / manual-color / manual-align

手動推進步驟 manual manual-label="..." manual-color="..." manual-align="left|center|right"

有 manual 屬性且有 next 的 region，激活後顯示一個按鈕讓使用者手動點擊才進入下一步。

步驟 1 — manual，手動按鈕在右側，顏色 ocean。點擊按鈕才進入下一步。 步驟 2 — manual-align="center"，按鈕置中對齊。 步驟 3 — manual-align="left"，按鈕靠左對齊。 步驟 4（終點） — 最後一步無 next，不顯示手動按鈕。

群組 + 全局進度條

info-region-group 控制按鈕、進度條與百分比顯示

<info-region-group>
基本群組控制 auto-start start-label reset-label start-color reset-color show-controls="false"

群組自動生成開始／重設按鈕。auto-start 讓群組在頁面載入時自動啟動。show-controls="false" 隱藏按鈕。

群組管理的 步驟 1 — 由群組按鈕統一控制開始與重設。 群組 步驟 2 — 群組模式下 next 鏈式仍然有效。 群組 步驟 3（終點）
全局進度條 + 百分比 global-progress show-percent progress-position="top|bottom" progress-height="px" progress-color="..."

global-progress 顯示整組的進度條；show-percent 在末端顯示百分比數字。

全局進度 步驟 1 / 4 — 頂部進度條以 lavender 顯示整組進度（25%）。 全局進度 步驟 2 / 4 — 每個 region 激活後，進度條前進（50%）。 全局進度 步驟 3 / 4 — 75%。 全局進度 步驟 4 / 4（完成） — 進度條達到 100%，百分比顯示。
按鈕尺寸自訂 btn-width btn-height btn-font-size btn-padding start-width reset-padding

統一設定全部按鈕尺寸（btn-*），或對開始/重設各別設定（start-* / reset-*），個別設定優先於統一設定。

按鈕自訂示例：開始按鈕 width=140px；重設按鈕 padding=8px 14px；全部字體 0.8rem。

級聯模式

cascade-interval — 按序列依次延遲激活所有 region

依序延遲激活 cascade-interval="ms"

群組開始後，全部 region 依 cascade-interval 毫秒的間隔依序激活，不需要 next 鏈式。

級聯 步驟 1 — cascade-interval="350"，每 350ms 激活下一個。 級聯 步驟 2 級聯 步驟 3 級聯 步驟 4 級聯 步驟 5 — 最後一個，不需要串聯 next。

水平佈局

layout="horizontal" + cols-per-row / gutter-size / row-gap

水平 + 級聯 + 進度條 layout="horizontal" cols-per-row="3" gutter-size="14px" row-gap="10px"

水平佈局使用 CSS Flexbox，不移動 DOM 結構。每欄寬度由 cols-per-row 和 gutter-size 計算，region 以淡入+左移方式出現。

自訂邊框

border-width / border-style / border-*-width / border-*-style

各邊框寬度與樣式 border-width="px" border-top-width border-right-width border-bottom-width border-left-width border-style="solid|dashed|dotted|double"

預設只有左邊框（4px solid）。各邊可獨立指定寬度與樣式；border-width 同時設定四邊（個別屬性優先）。

預設：border-left=4px solid（只有左邊框） border-width="2"：四邊均 2px solid border-width="1" border-left-width="6"：四邊 1px，左邊框 6px 覆蓋 border-style="dashed" border-width="2"：四邊虛線 border-top=4 border-right=2 border-bottom=4 border-left=0 dotted：各邊獨立設定寬度與樣式 border-style="double" border-width="3"：雙線（需 ≥ 3px）
