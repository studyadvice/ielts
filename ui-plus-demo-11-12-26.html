ui-plus 示範

ui-plus.js 內含兩組元件：展開按鈕 <ui-btn>，以及閱讀輔助標記 <read-pulse>、<chalk-mark>、<col-pair>。本頁合併了先前所有的 ui-plus 示範檔（11-12-26），每個範例左邊是實際元件，右邊是同一段原始碼。

ui-btn：尺寸

size 除了 sm、md、lg，也接受 2rem、1.2em、24px 或純數字（視為 rem）。內距、圓角、圖示間距、展開箭頭都以 md 為基準等比例換算。

預設級距與自訂字級對照

點按鈕會跳出浮動提示，顯示目前的 size。

HTML

圓形圖示按鈕與展開箭頭

沒有文字的圓形圖示按鈕，直徑與右下角的展開小圓點也會等比例縮放；帶 chevron 的按鈕，箭頭跟著字級變化。

HTML

em 單位與格式錯誤

em 以按鈕所在容器的字級為基準，這裡的容器字級為 1.5rem。格式錯誤的值會改用 md，並在主控台警告。

HTML

寫法範例說明
預設級距sm、md、lg與原本相同，預設為 md。
rem2rem按鈕字級。內距、圓角、間距等以 md 為基準等比例換算為 px。
em1.2em以按鈕所在容器的字級為基準。

無效值huge、2vw改用 md，並於主控台警告。

ui-btn：多目標、template 與依序出現

targets 一次展開多個元素或 <template>，id 用空白或逗號分隔，# 可省略。stagger 控制依序出現的間隔，anim-duration 控制每一個淡入的時間。

一次展開散落各處的 div

三個答題提示不必相鄰，也不必放在按鈕旁邊。第三個提示用 bp-hidden class 隱藏，同樣可以展開。

HTML

template 延遲渲染，與 div 混合使用

template 的內容在第一次展開時才複製到它後面的 div，之後的開合都作用在這個 div，所以輸入過的內容會保留。template 內的 ui-btn 會自動初始化。

stagger 依序出現

stagger="400" 讓目標每隔 400 毫秒出現一個；收合時全部同時收起。

HTML

調整間隔與淡入速度

stagger 是「下一個什麼時候開始」，anim-duration 是「每一個淡入要花多久」。stagger 比 anim-duration 短時，畫面會有接力的感覺。

需要同時載入 mini/mini-table.js。mini-table-id 指定表格，target-cell 指定儲存格（座標和 Excel 一樣，表頭算第 1 列），內容寫在 target-cell-content 或用 target-cell-source 從 template 讀。再按一次恢復原本內容。

揭曉儲存格

ui-btn：屬性速查

多目標、儲存格與移除元素相關的屬性。完整屬性見 README。

屬性範例說明
targetstargets="a, b #c"新增。要一起開合的元素 id，逗號或空白分隔，# 可省略。目標可以是任何元素或 <template>。
targettarget="a"原有屬性，寫法不變；現在也接受多個 id。與 targets 同時存在時合併，重複的 id 只算一次。
staggerstagger="400"新增。展開時每個目標間隔的毫秒數，預設 0（同時展開）。收合一律同時進行。
anim-durationanim-duration="1200"原有屬性。每個目標展開或收合動畫的毫秒數，預設 320，fade 與 slide 都適用。修正後可設超過 600。全域預設可用 UiBtnConfig.animDuration。
mini-table-idmini-table-id="mytbl"新增。要操作的 <mini-table> 的 id，需載入 mini/mini-table.js。也接受少一個字母的 min-table-id。設定後按鈕不會再去開合緊接在後面的元素。
target-celltarget-cell="B2"
target-cell="B2 C3"
target-cell="C2:C4"		新增。儲存格座標，和 Excel 相同，表頭算第 1 列。可寫多格（逗號或空白分隔）與範圍，$B$2 的 $ 會略過。不存在的格子會在主控台警告並略過。
target-cell-contenttarget-cell-content="<b>Cafe</b>"新增。要顯示的內容，可寫 HTML。多格時用 | 分隔，一格一段；只寫一段就每格都用同一段。內容本身要放 | 時寫成 \|。
target-cell-sourcetarget-cell-source="ans"新增。改從 <template> 或元素讀取內容，優先於 target-cell-content。適合較長的 HTML，多格時同樣用 | 分隔。

read-pulse：段落進度條

把一段內容包起來，左側色條由上往下跑過，提示「現在讀這段」。以下範例都設了 trigger="click" 與 repeat，點段落可以重播；預設的 trigger="visible" 會在捲動到可見時自動播放。

六種樣式

style 可用 solid、gradient、glow、segmented、double、fuse；gradient 與 double 用到 color2。

HTML

fuse 燃燒引信

條身從燒過的暗色漸變到火花處的亮色，底端有閃爍的火花與飛濺的火星。spark-size 調整火花大小（預設 8，最小 4）。

HTML

chalk-mark：粉筆圈字

點擊後在文字上方畫出粉筆弧線並把文字染色，再點一次擦掉。direction="rtl" 由右往左畫，arrow 在終點加箭頭，arrow-to 讓弧線跨出標記指向另一個字，適合標示後位修飾。

基本用法

點標記畫線，再點擦掉。thickness 調整粗細，duration 調整畫線速度，active 載入時就畫好。

HTML

由右往左與箭頭

direction="rtl" 搭配 arrow：把名詞連同修飾語一起包起來，箭頭落在整段最左端。箭頭尺寸可填 12、10px、0.6rem、0.5em。

HTML

arrow-to 指向被修飾的名詞

只包修飾語，名詞包一個帶 id 的 span。同一行時弧線從上方跨過；名詞在上一行時，弧線走兩行之間，箭頭從名詞下方往上指。縮放視窗看弧線跟著換行重畫。

HTML

arrow-shape 箭頭形狀

arrow-shape 可選 triangle（預設）、square、star，三種都是實心，方向順著弧線，形狀最前端落在弧線終點。arrow 的尺寸照常使用；星星較瘦，會自動放大 1.6 倍。

HTML

col-pair：搭配詞連動

同一個 group 的字詞會連動：滑鼠移到其中一個，同組全部亮起並標上圓點。theme 設定群組顏色，同組只要一個設定即可。

代名詞與搭配詞

把滑鼠移到 government、it、raise、taxes 上看看。

HTML

修改紀錄：chalk-mark 箭頭改為實心形狀（11-12-26）

原本的箭頭是兩條開口的線，方向取弧線最末端的切線。弧線兩端很陡，最末端的切線和肉眼看到的走向不同，加上粗線的圓頭，箭頭看起來是歪的。現在改為實心三角形，方向取「三角形底邊所在的弧線點」指向終點，弧線縮短半個箭頭長，線尾藏進三角形。arrow 的尺寸仍是箭頭長度，寫法不變。上方「由右往左與箭頭」與「arrow-to」兩組範例就是新樣式。

同日再新增 arrow-shape：內建實心三角形、方塊、星星三種形狀，見上方「arrow-shape 箭頭形狀」範例。三種形狀共用同一套方向計算，以弧線方向為 u 軸、法線為 v 軸畫出形狀，再轉成 SVG 座標。

修改前

/* 箭頭方向沿終點的切線（控制點指向終點） */
var ang  = Math.atan2(y2 - cy, x2 - cx);
var wing = Math.PI / 6.5;
var ax1 = x2 - size * Math.cos(ang - wing), ...;
var ax2 = x2 - size * Math.cos(ang + wing), ...;
arrowPath.setAttribute('fill',   'none');
arrowPath.setAttribute('stroke-width', thick);
arrowPath.setAttribute('d', 'M ax1 ay1 L x2 y2 L ax2 ay2');

chalkPath.setAttribute('stroke-dasharray',  len);
chalkPath.setAttribute('stroke-dashoffset', len);

修改後

/* 實心三角形：長度 tl，底邊半寬 hw */
var tl = Math.max(3, arrowSizePx(), thick * 2.6);
var hw = Math.max(tl * 0.55, thick * 1.3);
/* 方向：底邊所在的弧線點指向終點 */
var bp  = chalkPath.getPointAtLength(len - tl);
var ang = Math.atan2(y2 - bp.y, x2 - bp.x);
arrowPath.setAttribute('fill', c);
arrowPath.setAttribute('d', 'M 尖端 L 底邊左 L 底邊右 Z');

/* 弧線縮短半個箭頭長，線尾藏進箭頭形狀 */
var vis = len - tl * 0.5;

/* 新增 arrow-shape：square、star */
<chalk-mark arrow arrow-shape="square">...</chalk-mark>
<chalk-mark arrow arrow-shape="star">...</chalk-mark>
