全功能屬性對照手冊

card-toggle & card-toggle-group

每個屬性均附有可互動的實際效果與對應原始碼。章節依功能分組， 可直接操作左欄的元件，右欄顯示對應的最小化寫法。

基本翻面 色彩系統 外觀樣式 動畫 Toggle 模式 Quiz 輸入 分支翻面 群組 Group 字體排版屬性 完整屬性速查
Chapter 01

基本翻面 — content / source

content="…" — 直接寫翻面內容

點擊卡片後以 content 屬性的 HTML 字串取代正面內容。最簡單的用法。

點擊我 — content 屬性
HTML
<card-toggle
  content="<strong>背面內容</strong>">
  正面文字
</card-toggle>

source="id" — 從 DOM 元素讀取翻面內容

翻面後顯示指定元素的 outerHTML，適合複雜排版。元素本身可設為 display:none。

來自 DOM 元素的內容

這段文字來自 #src-demo-1，可以包含任意 HTML。

點擊我 — source 屬性，讀取 DOM 元素
HTML
<!-- 隱藏模板 -->
<div id="my-back" style="display:none">
  背面複雜內容…
</div>

<card-toggle source="my-back">
  正面文字
</card-toggle>

動畫 — animation / auto-flip

animation="…" — 翻面動畫類型

三種過場：fade（預設）/ slide / none。

animation="fade"（預設） animation="slide" — 左滑進入 animation="none" — 瞬間切換
HTML
<card-toggle animation="fade"  …>…</card-toggle>

<card-toggle animation="none"  …>…</card-toggle>

auto-flip="ms" — 定時翻回正面

翻面後倒數指定毫秒自動翻回，底部出現彩色倒數進度條。flip-bar-color 可自訂進度條色。

auto-flip="2500" — 點擊後 2.5 秒翻回 auto-flip="4000" + flip-bar-color="pink"
HTML
<card-toggle
  auto-flip="2500"
  content="背面…">
  點擊後 2.5 秒翻回
</card-toggle>

<card-toggle
  auto-flip="4000"
  flip-bar-color="pink"
  content="背面…">
  自訂進度條色
</card-toggle>
Chapter 05

Toggle 模式 — toggle

加上 toggle 布林屬性後，翻到背面仍可再次點擊翻回正面，背面右下角顯示「點擊翻回」提示。

toggle 模式 — 點擊翻面，再點翻回 toggle + animation="slide" toggle + auto-flip="3000" — 兩種方式都能翻回
HTML
<card-toggle
  toggle
  color="lavender"
  content="背面，點擊翻回">
  正面
</card-toggle>

<!-- toggle + auto-flip 並存 -->
<card-toggle
  toggle
  auto-flip="3000"
  content="…">
  點擊或等 3 秒翻回
</card-toggle>
Chapter 06

Quiz 輸入模式 — question / answer

基本問答 — question / answer / source

question 觸發輸入框模式，answer 設定正確答案。 答對後翻到 source 或 content 指定的背面，答對後可點卡片翻回重試。

正確！

台灣最高峰是玉山，海拔 3,952 公尺，為東北亞第一高峰。

HTML
<div id="back" style="display:none">答對說明</div>

<card-toggle
  color="sky"
  question="台灣最高峰？"
  answer="玉山"
  placeholder="輸入山名…"
  source="back">
</card-toggle>

max-attempts / success-color / error-message

max-attempts 設定最多嘗試次數，超過後鎖定顯示錯誤背面。 success-color 自訂答對後側邊線色，case-sensitive 啟用大小寫區分。

HTML
<card-toggle
  question="CSS 的全名縮寫？"
  answer="CSS"
  case-sensitive
  max-attempts="3"
  error-message="提示：控制樣式"
  success-message="CSS = Cascading…"
  success-color="safe">
</card-toggle>

hint / hint-text — 提示按鈕

有 hint 屬性時自動顯示提示按鈕。 不設 hint-target 則以 Bootstrap-style alert 顯示在卡片內； 設 hint-target="id" 則顯示在外部指定元素。

HTML
<!-- 內嵌提示（預設） -->
<card-toggle
  hint="和找不到有關"
  hint-text="需要提示？"
  …>…</card-toggle>

<!-- 外部提示 -->
<div id="hint-area"></div>
<card-toggle
  hint="兩個英文字母"
  hint-target="hint-area"
  …>…</card-toggle>

info / info-source / info-color — 額外資訊面板

點擊「額外資訊」按鈕展開/收合說明面板。 info 直接寫 HTML，info-source="id" 讀取 DOM 元素， info-color 自訂面板強調色。

補充說明：這段內容來自 #info-src-1 DOM 元素，可包含任意 HTML。
HTML
<card-toggle
  info="說明 HTML…"
  info-text="補充知識"
  info-color="indigo"
  …>…</card-toggle>

<div id="info-src" style="display:none">…</div>
<card-toggle
  info-source="info-src"
  …>…</card-toggle>

hide-submit / hide-hint / hide-reset / hide-info — 隱藏按鈕

個別隱藏不需要的按鈕，也可搭配自訂按鈕文字屬性。

HTML

Chapter 07

分支翻面 — branch-options / correct-option

基本是非題

同時設定 question、branch-options、correct-option 即觸發分支翻面模式，顯示選項按鈕取代輸入框。 答對/答錯各翻出 branch-correct / branch-wrong 的內容。

HTML
<card-toggle
  question="光速約 30 萬 km/s？"
  branch-options="對,錯"
  correct-option="對"
  branch-correct="正確說明…"
  branch-wrong="錯誤說明…">
</card-toggle>

多選項 + branch-retry + 自訂標籤

branch-options 支援任意數量，逗號分隔。 branch-retry 讓答錯背面出現重試按鈕。 branch-correct-label / branch-wrong-label 自訂背面標題。

HTML
<card-toggle
  branch-options="氦,氫,鋰,碳"
  correct-option="氫 (H)"
  branch-btn-color="lavender"
  branch-correct-label="完全正確！"
  branch-wrong-label="再想想"
  branch-correct="說明…"
  branch-wrong="說明…"
  branch-retry
  branch-retry-text="↺ 再選一次">
</card-toggle>

branch-correct-source / branch-wrong-source + 自訂色

背面內容可從 DOM 元素讀取（優先於內聯屬性）。 branch-correct-color / branch-wrong-color 自訂答對/錯後的卡片色。

答對了！

TCP 建立連線時使用三向交握（SYN → SYN-ACK → ACK），確保雙方都準備好傳輸。

延伸：UDP 是無連線協定，速度快但不保證順序與可靠性。

答錯了。

TCP 是需要連線的協定（connection-oriented）。UDP 才是無連線（connectionless）。

HTML
<div id="br-ok" style="display:none">答對內容…</div>
<div id="br-ng" style="display:none">答錯內容…</div>

<card-toggle
  branch-correct-source="br-ok"
  branch-wrong-source="br-ng"
  branch-correct-color="safe"
  branch-wrong-color="warning"
  branch-retry
  …>…</card-toggle>
Chapter 08

card-toggle-group

mode="stack"（預設）— 垂直堆疊

預設模式，卡片垂直排列，theme 設定主題色。

stack 卡片 A stack 卡片 B stack 卡片 C
HTML
<card-toggle-group theme="sky">
  <card-toggle …>A</card-toggle>
  <card-toggle …>B</card-toggle>
</card-toggle-group>

mode="grid" / mode="grid:16px" / cols="…" — 格線排列

mode="grid" 預設間距 12px，mode="grid:16px" 自訂間距。 cols="2" 強制欄數（否則預設等於卡片數量）。

格線 1 格線 2 格線 3 格線 4
HTML
<card-toggle-group
  mode="grid:14px"
  cols="2"
  theme="lavender">
  <card-toggle …>1</card-toggle>
  <card-toggle …>2</card-toggle>
  <card-toggle …>3</card-toggle>
  <card-toggle …>4</card-toggle>
</card-toggle-group>

mode="slide" — 投影片模式

卡片橫向排列，上方顯示計數器（hide-counter 可隱藏）， 下方有上下頁按鈕（hide-nav-buttons 可隱藏）， show-pages 顯示頁碼點陣。

slide 第 1 張 slide 第 2 張 slide 第 3 張
HTML
<card-toggle-group
  mode="slide"
  show-pages
  theme="teal">
  <card-toggle …>1</card-toggle>
  <card-toggle …>2</card-toggle>
</card-toggle-group>

lock-nav + show-result + show-pages — 完整問答流程

lock-nav 鎖定未答題不能前進；show-result 全部作答後顯示成績畫面； 頁碼按鈕自動顯示答對（綠）/ 答錯（橙）狀態色。

HTML
<card-toggle-group
  mode="slide"
  lock-nav
  show-pages
  show-result
  theme="special">
  <!-- quiz 卡 -->
  <card-toggle
    question="…"
    answer="…">
  </card-toggle>
  <!-- branch 卡 -->
  <card-toggle
    question="…"
    branch-options="對,錯"
    correct-option="對"
    branch-correct="…"
    branch-wrong="…">
  </card-toggle>
</card-toggle-group>

result-source / retry-label — 自訂成績畫面

result-source="id" 在成績畫面加入自訂 HTML 區塊（如鼓勵語或連結）； retry-label 自訂重新作答按鈕文字。

不錯！繼續保持。

HTML
<div id="custom-result" style="display:none">
  鼓勵語…
</div>

<card-toggle-group
  show-result
  result-source="custom-result"
  retry-label="↺ 從頭再來">
  …
</card-toggle-group>

auto-next — 答對後自動跳下一題

卡片上加 auto-next，答對 1.5 秒後自動前往下一張。

HTML
<card-toggle-group mode="slide">
  <card-toggle
    auto-next
    question="1+1=?"
    answer="2">
  </card-toggle>
  …
</card-toggle-group>

字體排版屬性 — fs-* / ff-* / pad-*

所有部位均可透過 fs-{part}（字體大小）、ff-{part}（字型）、 pad-{part}（padding）屬性覆寫，純數字自動加 rem（fs）或 px（pad）。 卡片層級屬性影響單張；設在 card-toggle-group 上則對群組內所有卡片生效。

HTML
<!-- 字體大小（純數字 → rem） -->
<card-toggle
  fs-body="1.3"
  fs-question="1.1"
  fs-submit="0.95"
  fs-feedback="1rem"
  fs-branch-btn="1rem"
  fs-branch-label="1.1rem"
  fs-branch-body="0.95rem"
  …>…</card-toggle>

<!-- padding（純數字 → px） -->
<card-toggle
  pad-submit="8 20"
  pad-aux="6 14"
  …>…</card-toggle>

<!-- group 層級套用（影響所有子卡） -->
<card-toggle-group
  fs-body="1.05"
  fs-nav="0.9"
  fs-counter="0.85"
  fs-result-score="3rem"
  pad-nav="6 18"
  …>…</card-toggle-group>

<card-toggle-group> 屬性

屬性類型 / 預設說明
modestack|slide|grid|grid:gap排列模式（預設 stack）。grid 可附帶間距如 grid:16px
cols數字grid 模式的欄數（預設等於卡片數量）
themepalette key群組主題色，影響計數器、頁碼、active 狀態
hide-counter布林隱藏計數器（slide 模式）
hide-nav-buttons布林隱藏上下頁按鈕（slide 模式）
show-pages布林顯示頁碼點陣按鈕（slide 模式）
lock-nav布林未作答不可前進下一張（slide 模式）
show-result布林全部作答後顯示成績畫面
result-sourceid成績畫面追加自訂 HTML 區塊
retry-labelstring（預設「↺ 重新作答」）成績畫面重新作答按鈕文字
── 排版屬性（group 層級影響所有子卡） ──────────
fs-nav / ff-nav / pad-nav—上下頁按鈕字體 / 字型 / padding
fs-page / ff-page / pad-page—頁碼按鈕字體 / 字型 / padding
fs-counter / ff-counter—計數器字體 / 字型
fs-result-score / ff-result-score—成績百分比大字字體 / 字型
fs-result-text / ff-result-text—成績說明文字字體 / 字型
fs-retry / ff-retry / pad-retry—重新作答按鈕字體 / 字型 / padding
以及所有 card 層級的 fs-* / ff-* / pad-*—設在 group 上則對所有子卡生效
