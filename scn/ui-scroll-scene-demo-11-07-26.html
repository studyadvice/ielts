<ui-scroll-scene> 捲動敘事元件

一欄固定舞台，一欄捲動步驟；捲到哪一步，舞台就切換到對應狀態。

v1.0.0 ・ 11-07-26

1. 寫作第一部分圖表解析（圖層、聚光、放大）

舞台放兩個 <scene-layer>：圖表與範文。步驟用 show 切換圖層，focus 聚光，zoom 放大到指定元素。內嵌 SVG 的線條與圓點也能被聚光。

查看程式碼

2. 閱讀定位訓練（單一內容、平移、步驟在左）

舞台不放圖層時，內容是一整篇文章。pan 只平移不縮放，把答案所在段落帶到舞台中央；focus 標出同義替換的位置。這裡使用 stage-side="right"、step-style="line"。

查看程式碼

3. 驅動其他元件：口說答案升級（set 與 scrub）

舞台裡放一個 <ui-screen>。scrub 讓分隔線隨捲動連續移動，set 在指定步驟改變它的屬性。往回捲時，所有屬性都會還原。

查看程式碼

4. 固定高度區塊內捲動，事件與方法

scroll="self" 讓元件在自己的高度內捲動，適合嵌在卡片或版面格子裡。下方按鈕呼叫 goTo()、prev()、next()，進入步驟時以 Bootstrap alert 顯示 scene:enter 事件。

index ／ steps唯讀目前步驟（尚未進入第一步時為 -1）與所有步驟元素。
