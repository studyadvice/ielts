<ui-screen> 分隔線對照元件

左右或上下拖曳分隔線，對照兩組事先用語意標籤定義好的內容。

v1.0.2 ・ 11-07-26

1. 左右對照（漸層外框、載入示範、標籤自動淡出）

預設 effect="clip"，兩層重疊並以裁切呈現。intro 會在元件進入畫面時自動擺動一次，label-autohide 讓分隔線接近邊緣時標籤淡出。

2. 上下分隔（膠囊把手、分隔線漸層、標籤圖示）

orientation="vertical" 切換成上下分隔。標籤可用 label-icon 加上 Bootstrap Icons，顏色屬性可直接寫色票名稱。

3. 靜態漸層外框預設集

border-gradient 可填預設名稱、逗號分隔的色票（可帶位置，例如 key,yellow 60%,urgent），或完整的 CSS 漸層字串。搭配 border-gradient-type 可改成 radial 或 conic。

4. 擠壓模式（內容重新排版）

effect="squeeze" 時兩塊各自縮放寬度，文字會跟著重新換行，適合對照兩種排版或兩種語言。未設定高度時預設比例為 16/9。

5. 滑鼠跟隨（隱藏把手、離開歸位）

mode="hover" 讓分隔線直接跟著滑鼠，reset-on-leave 在滑鼠離開時回到初始位置，handle-shape="none" 只保留一條細線。

6. 吸附刻度、自訂把手、事件與方法

mode="handle" 只有把手能拖曳，內容裡的按鈕照常可以點。放開時依 snap 吸附最近刻度。把手取得焦點後可用方向鍵移動，按住 Shift 為十倍步距。

8. v1.0.1 修正：透明內容互相透出

v1.0.0 的圖層沒有底色，內容本身若是透明的（只有文字），下層會從上層透出來，文字重疊。v1.0.1 起兩層預設套用 stage-bg 當底色，也可以在圖層上用 bg 分別指定單色、色票名稱或漸層。

9. v1.0.2：height="100%" 填滿父元素

v1.0.1 以前外框不會跟著元件高度撐開，height="100%" 會讓畫面塌成 0。v1.0.2 起外框高度跟著元件，放進固定高度的格子、卡片或 <scene-layer> 都能填滿。

子標籤
<ui-screen-handle>任意 HTML無自訂把手內容，取代 handle-icon。
<ui-screen-label>任意 HTML無放在 before 或 after 內，作為可放複雜內容的標籤；加上 free 屬性則不自動定位。
事件
ui-screen:changedetail：position、orientation位置改變時持續觸發（拖曳中、動畫目標）。
ui-screen:enddetail：position、orientation放開、點擊、鍵盤操作或呼叫 setPosition 後觸發，已含吸附結果。
屬性存取與方法
position讀寫目前位置，寫入時以動畫移動。
orientation讀寫horizontal 或 vertical。
setPosition(n, {animate, silent})animate 預設 true移動到指定位置。
reset(animate)回到 position 屬性設定的初始位置。
toggleOrientation()左右與上下切換。
replay()重播載入示範動畫。
refresh()重新套用所有屬性。
UIScreen.presets ／ UIScreen.palette ／ UIScreen.gradient()靜態取得漸層預設集、色票，或用同一套規則產生漸層字串。

所有顏色屬性都可直接寫色票名稱（例如 key-deep），也接受任何 CSS 顏色值。把手與標籤圖示使用 Bootstrap Icons 類別，元件本身不載入圖示字型。
