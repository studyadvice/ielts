④ annotate API 新增 hintStyle & color 參數

原始碼透過 JavaScript 動態標注：PDO 是 PHP 官方的資料庫抽象層， 而 AOP 則是橫切關注點的程式設計典範。 使用 BpPopnote.annotate 可以在不修改 HTML 的情況下加入彈出說明。

上段文字中「PDO」「AOP」「BpPopnote.annotate」三個詞是由下方 JS 動態標注的。 

BpPopnote.annotate([
  {
    text: 'PDO',
    title: 'PHP Data Objects',
    content: '統一的 PHP 資料庫存取介面，支援多種資料庫驅動，使用 PDO 可避免直接依賴特定資料庫 API。',
    theme: 'ocean',
    hintStyle: 'pill',   // ← 新增
    color: 'ocean',      // ← 新增
  },
  {
    text: 'AOP',
    title: 'Aspect-Oriented Programming',
    content: '面向切面程式設計，將日誌、安全驗證等橫切關注點從業務邏輯中分離，提升模組化程度。',
    theme: 'special',
    hintStyle: 'pill',
    color: 'special',
  },
  {
    text: 'BpPopnote.annotate',
    title: 'annotate API',
    content: '動態標注 API，v2 新增 hintStyle（"dashed"/"solid"/"pill"/"pill-full"）與 color 參數。',
    theme: 'lavender',
    hintStyle: 'solid',
    color: 'lavender',
  },
]);

⑤ 新增屬性速查

屬性 值 說明
data-popover-hint-style dashed（預設）
solid
pill
pill-full		 觸發器樣式。dashed 為原始虛線底線，solid 為實線底線，pill 為圓角膠囊，pill-full 為撐滿容器寬度的膠囊。
data-popover-color 調色盤 token 或 #RRGGBB 覆蓋觸發器的提示色（hint color）。接受 lavender、ocean… 等 token，或任意 hex。此色彩也同步更新 --xpop-hint-color 與 --xpop-hint-rgb CSS 變數，pill / pill-full 背景色由此驅動。
annotate( rule.hintStyle ) 同上 annotate API 對應的 JS 規則屬性。
annotate( rule.color ) 同上 annotate API 對應的 JS 規則屬性，token 或 hex 均可。
