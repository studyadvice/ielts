bp-stepper NEW btn-js 屬性 Demo

在任一 bp-step 加上 btn-js="JS運算式"，即可注入一顆配色繼承自 theme 的自訂呼叫按鈕。

① 基本用法：文字標籤按鈕（lavender theme）

在 bp-step 加上 btn-js="..." 與 btn-js-label="標籤"。
按鈕固定在卡片左下角，配色跟隨 theme 並因步驟狀態（active / done / error）自動變色。

步驟一 資料驗證完畢，點擊左下按鈕觸發業務函數。 步驟二 確認後呼叫儲存邏輯，結果顯示於頁面上方。 步驟三 done 狀態下按鈕半透明，hover 恢復全亮。
<bp-step btn-js="myFunction()" btn-js-label="呼叫函數"> ... </bp-step>

② 圖示按鈕 + progress 模式共存（ocean theme）

同一步驟可同時擁有 progress 推進按鈕（右下）與 btn-js 自訂按鈕（左下）。
使用 btn-js-icon-class 搭配 Bootstrap Icons，不顯示文字時呈現正圓形。

準備資料 左下按鈕預覽，右下按鈕推進到下一步。 處理中 btn-js 與 progress 按鈕同時存在，互不干擾。 完成 最後一步依然支援自訂呼叫。
<bp-step btn-js="exportCSV(step)" btn-js-icon-class="bi bi-download" btn-js-label="匯出"> ... </bp-step>

③ 存取 step、stepper、BPStepper 參數（indigo，垂直）

btn-js 運算式執行時自動注入三個參數：
step（當前 bp-step 元素）、stepper（父 bp-stepper 元素）、BPStepper（全域 API）。
下方範例示範直接讀取步驟的 dataset 並呼叫 BPStepper.setError()。

審核 按鈕可讀取 step.dataset，顯示步驟相關資訊。 簽核 呼叫 BPStepper.setError(stepper, index) 切換此步驟為 error 狀態。 歸檔 呼叫 BPStepper.resetStates(stepper) 重置整個流程。
（步驟資訊將顯示於此）
// btn-js 運算式內可直接使用三個注入參數： btn-js="BPStepper.setError(stepper, 1)" btn-js="BPStepper.resetStates(stepper)" btn-js="myFn(step, stepper)" // step = bp-step 元素

④ 純圖示（正圓形）版本（warning theme）

只設定 btn-js-icon-class，不設定 btn-js-label（或設為空字串），按鈕呈現正圓形，與 progress 按鈕的圓形 icon 模式一致。

建立草稿 垃圾桶圖示按鈕，左下正圓形。 提交審核 active 狀態下圖示顏色跟隨 colorActive。 發佈 分享圖示，純圓形無文字。
// 不設 btn-js-label（或設為空字串）→ 正圓形圖示按鈕 <bp-step btn-js="deleteItem(step)" btn-js-icon-class="bi bi-trash3" btn-js-label="">

⑤ 屬性速查

屬性 預設值 說明
btn-js （必填） 任意 JS 運算式。執行時自動注入 step（bp-step 元素）、stepper（bp-stepper 元素）、BPStepper（全域 API）三個參數。
btn-js-label "執行" 按鈕顯示文字。設為空字串時按鈕縮為正圓形（圖示模式）。
btn-js-icon-class "" Bootstrap Icons 或其他 icon font 的 class 字串，例如 "bi bi-download"。優先於 btn-js-icon。
btn-js-icon "" 圖示 HTML 字串（emoji 或 SVG 等）。btn-js-icon-class 存在時忽略此屬性。
// 配置範例 <bp-step btn-js="submitOrder(step, stepper)" btn-js-label="送出訂單" btn-js-icon-class="bi bi-bag-check"> <bp-step-title>確認</bp-step-title> <bp-step-content>核對無誤後點擊送出。</bp-step-content> </bp-step>
