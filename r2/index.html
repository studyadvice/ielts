ui-reading2 閱讀輔助元件組

包含 <layer-switch>、<ui-spotlight>、<collocation-map>、<cm-group>。遵守 ui 元件共同約定，可直接放進 ui-drill、ui-steps、ui-cards 的內容來源中。完整屬性見 README.md。

版本紀錄

v2.0（11-03-26）　更新品牌色；改為自訂元素，可嵌套在其他 ui 元件中；屬性對齊共同約定（color、tooltip、detail、active、title、placeholder、disabled）；沒有 target 時自動建立內建內容區；移除過渡動畫；低透明度底色改用實色。舊屬性名稱與 <spotlight> 仍可用。

範例一：分層標記，內建內容區

沒有 target 時，自動在文字下方建立內容區。按鈕切換文法層；標記帶 detail，滑鼠移上去時內容區顯示補充說明，移開後還原。active 讓第一層一開始就顯示說明。


  

  
  
範例二：多層同時啟動，外部目標

  
multi 允許多層同時亮起；mark-style="box" 用外框標記；toggle-style="dot" 改成圓點按鈕並放在下方。說明顯示在你自己設計的 target 區塊；標記用 detail-trigger="click" 點擊鎖定。

  

  

  

  
  
範例三：聚光

  
點擊段落，其餘內容變暗；再點一次、點遮罩或按 Esc 關閉。第二段用滑過觸發，第三段用虛線外框。

  

  

  

  
  
範例四：搭配詞圖與共用內容區

  
<cm-group> 裡的搭配詞圖都沒有 target 時，群組自動建立一個共用內容區。第一張滑過顯示例句；第二張錨點在右，改用點擊鎖定，並用 active-detail 預先鎖定一項。

  

  

  

  
  
組合一：OneNote 式頁籤＋閱讀元件

  
ui-drill 的每個頁籤內容來源裡放閱讀元件，切換頁籤時自動建立。

  

  

  

  
  
組合二：Outlook 式文章清單＋分層標記

  
左側選單元，上方是文章清單，點文章後下方出現可切換文法層的課文。

  

  

  

  
  
組合三：課程步驟＋單字卡

  
ui-steps 呈現上課流程，第二步的內容是 ui-cards 單字卡；點卡片，卡片下方的內容區出現搭配詞圖。
