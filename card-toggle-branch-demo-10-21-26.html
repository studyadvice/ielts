card-toggle 分支翻面

Branch Flip 擴充 — 答對/答錯各翻出不同內容，與 card-toggle-group 完全相容

Example 01

是非題 — 最簡設定

只需設定 question、branch-options、correct-option， 再給 branch-correct 和 branch-wrong 直接填入 HTML 說明文字即可。

branch-options="對,錯" correct-option="對" branch-correct="…" branch-wrong="…"
Example 02

四選一 + 答錯可重試

branch-options 支援多個選項（逗號分隔）。加上 branch-retry 屬性後， 答錯背面會出現重試按鈕，翻回正面重新選擇。

branch-options="A,B,C,D" branch-retry branch-retry-text="再選一次" branch-btn-color="lavender"
Example 03

背面內容來自 DOM 元素

branch-correct-source 與 branch-wrong-source 讀取任意元素的 innerHTML， 適合放置圖表、程式碼或複雜排版。

branch-correct-source="tpl-correct-3" branch-wrong-source="tpl-wrong-3" branch-btn-color="teal"

Example 04

搭配 card-toggle-group — 完整問答流程

分支翻面與 card-toggle-group 完全相容：答對計為 correct、答錯計為 wrong， 頁碼按鈕顯示答題狀態色，全部作答後出現成績畫面。

mode="slide" lock-nav show-pages show-result branch-options + correct-option
Example 05

自訂標籤文字 + hex 顏色按鈕

branch-correct-label、branch-wrong-label 可自訂背面標題。 branch-btn-color 直接接受 hex 色碼（不限 palette key）。

branch-correct-label="太棒了，完全正確！" branch-wrong-label="這次沒選對，來看說明" branch-btn-color="#EDA109"
Reference

新增屬性速查

屬性 預設值 說明
branch-options NEW "是,否" 選項文字，逗號分隔，支援任意數量。搭配 question 屬性使用時自動切換為分支翻面模式。
correct-option NEW — 正確答案選項文字，與 branch-options 中的某個值完全比對（預設不區分大小寫，加 case-sensitive 屬性則區分）。
branch-correct NEW — 答對後翻面顯示的 HTML 內容（內聯）。
branch-correct-source NEW — 答對後翻面內容來源的元素 id（讀取其 innerHTML），優先於 branch-correct。
branch-wrong NEW — 答錯後翻面顯示的 HTML 內容（內聯）。
branch-wrong-source NEW — 答錯後翻面內容來源的元素 id，優先於 branch-wrong。
branch-correct-label NEW "答對了！" 答對後翻面的標題文字。
branch-wrong-label NEW "答錯了（你選了「…」）" 答錯後翻面的標題文字，預設帶入所選選項。
branch-correct-color NEW "safe" 答對後卡片側邊線顏色（palette key 或 hex）。
branch-wrong-color NEW "warning" 答錯後卡片側邊線顏色（palette key 或 hex）。
branch-btn-color NEW （繼承 special） 選項按鈕的邊框與文字顏色（palette key 或任意 hex）。
branch-retry NEW false（布林屬性） 答錯後背面顯示重試按鈕，點擊翻回正面重新作答。
branch-retry-text NEW "↺ 再試一次" 重試按鈕文字。
case-sensitive false（布林屬性） 原有屬性，分支模式同樣適用：啟用後比對 correct-option 時區分大小寫。
animation "fade" 原有屬性：fade / slide / none，分支翻面完全沿用。
auto-next false（布林屬性） 原有屬性：答對後 1.5s 自動切換到 group 下一題。
