示範文章結構

下方各節共用同一篇文章，分成三個 <section>，id 分別為 #sec-ai-1、#sec-ai-2、#sec-ai-3。 「模型」、「訓練」、「損失函數」等詞彙在多個段落重複出現，用來驗證各種定位策略。 文章 HTML 本身完全不含任何 data-popover-* 屬性，所有標注均由 BpPopnote.annotate() 在 DOMContentLoaded 後注入。

within — 限定搜尋範圍

最常用的定位策略，把搜尋鎖在一個 CSS selector 所圈出的 DOM 區塊內

規則設計 within

「模型」在第一節出現一次，在第二節出現兩次。加上 within 後每條規則各自只在指定 section 內搜尋，互不干擾。

規則 A
「模型」 限定在 #sec-ai-1 — 解釋「機器學習模型」基礎定義（lavender 主題）
規則 B
「訓練集」 限定在 #sec-ai-1 — 解釋訓練集概念（teal 主題）

第一節：基礎概念

機器學習的核心是讓電腦從資料中自動學習規律，而不需要人工手動設計規則。為了達到這個目標，我們需要建構一個模型，它本質上是一個數學函數，負責將輸入資料映射到預測的輸出結果。

模型的品質取決於訓練集的品質與規模。訓練集是用來讓模型調整內部參數的標記資料集合。若訓練集過小或帶有偏差，模型的泛化能力將大打折扣。

context — 前後文字確認

when 同一個詞在同一 section 出現多次，加上 before / after 確認周圍文字

規則設計 within + context

第二節裡「模型」出現兩次：一次是「預訓練模型」，一次是「基礎模型」。用 context.before 分別定位，各給不同解釋。

規則 C
「模型」 within #sec-ai-2， context.before: "預訓練" — 命中「預訓練模型」（sky 主題）
規則 D
「模型」 within #sec-ai-2， context.before: "基礎" — 命中「基礎模型」（special 主題）
規則 E
「損失函數」 within #sec-ai-2， context.after: "最小化" — 確認是「最小化損失函數」語境（orange 主題）

第二節：訓練流程

現代深度學習廣泛採用預訓練模型策略：先在超大規模語料上學習通用表示，再針對特定任務進行微調，大幅降低了從零訓練的成本。

另一種常見做法是以輕量化的基礎模型為起點，再透過蒸餾技術壓縮為更小的可部署版本。在訓練流程中，最小化損失函數是核心目標，優化器（如 Adam）透過反向傳播不斷調整模型權重，直到損失函數收斂為止。

occurrence — 指定第 N 個

within 範圍內找到多個符合、且 context 無法區分時，直接指定要第幾個

規則設計 within + occurrence

第三節「訓練」出現兩次。第一個是「訓練資料」，第二個是「模型訓練」。兩者語境類似，context 難以區分，改用 occurrence 直接指定。

規則 F
「訓練」 within #sec-ai-3， occurrence: 1 → 第一個「訓練資料」（note 主題）
規則 G
「訓練」 within #sec-ai-3， occurrence: 2 → 第二個「模型訓練」（indigo 主題）

第三節：常見挑戰

在實務上，訓練資料的品質往往比資料量更重要。標注錯誤、類別不平衡或資料洩漏，都可能導致模型在評估集上表現良好，卻在實際部署後失效。

另一項挑戰是計算成本。現代大型語言模型訓練動輒耗費數千個 GPU 小時，如何在有限預算內達到足夠精度，是業界持續研究的課題。

混合使用

手動 data-popover-* 與 annotate() 在同一篇文章中共存

場景說明

文章作者在寫稿時就預知「過擬合」需要解釋，直接在 HTML 加了 data-popover-content。 事後編輯者再用 annotate() 追加「正則化」的解釋，兩種方式互不影響。

附加說明：泛化能力

當模型在訓練集上表現極佳但在測試集上大幅衰退時，稱為 過擬合 （Overfitting）。此時需要使用正則化技術來約束模型的複雜度。

panel 模式

annotate() 支援 panel 屬性，點擊後內容渲染到頁面固定區域而非浮動 popover

規則設計 panel

「反向傳播」點擊後內容出現在右側固定面板 #annot-panel 而非浮動框，適合需要顯示較長說明的情境。點第二次同一詞可切換關閉。

梯度下降與反向傳播

反向傳播演算法是深度學習的基礎，它利用鏈式法則計算每個參數對損失的梯度，再由梯度下降更新權重。理解反向傳播是掌握神經網路訓練的關鍵。

點擊文章中「反向傳播」查看面板輸出

clearAnnotations()

移除所有或指定範圍的 mark.bpn-annotated，恢復原始 DOM

clearAnnotations() clearAnnotations(scope)

不帶參數清除全頁；帶 CSS selector 只清除該範圍。清除後 DOM 恢復為無標注狀態，再次呼叫 annotate() 可重新注入。
