ui-tabs

未選中的頁籤是空心輪廓，選中的變成實心，站在底線上。三種外形、可以疊在一起的負間距、每個頁籤各自的顏色，內容切換時依左右順序滑入。

1. 選中頁籤的圓弧與頁籤太多時的箭頭

browser 外形選中的頁籤，底部左右兩側會往外張開一段圓弧，接到底線上。大小用 flare 調整（預設 8px），寫 none 關閉。頁籤多到放不下時，不會出現捲軸，而是在頁籤列兩端出現左右箭頭；點選頁籤會自動把它捲到中間，也可以用滑鼠滾輪橫向捲動。所有外形都有這個行為。

4. 負間距：頁籤疊在一起

gap 可以是負值（CSS 本身的 gap 不行，這裡是元件自己處理）。預設右邊的頁籤疊在左邊上面；stack="left" 則相反。選中的頁籤永遠在最上層。被蓋住的那一側會自動多留空間，文字不會被壓到。

梯形的兩條斜邊相鄰時是「V」字，不會互相貼合；負間距會讓右邊頁籤蓋住左邊頁籤的斜邊，看起來像疊在一起的卡片。

5. 顏色、圖示、停用

theme-color 是整組的顏色，頁籤自己的 accent 優先。選中時頁籤填滿該顏色，文字顏色依亮度自動選深或淺。滑過未選中的頁籤，輪廓與文字會變成該頁籤的顏色。line-color 是輪廓與底線的顏色。

每個頁籤各有一個顏色。 寫作用紫色。 停用的頁籤不能點。 閱讀用綠色。 align="center"，字級 1.15rem，線色 shell。 第二個頁籤。

7. 內容來源與其他元件

內容可以直接寫在 <tab-item> 裡，也可以用 source 指向頁面上別處的元素（<template> 會複製內容；其他元素則把裡面的東西「搬」進面板，所以裡面的按鈕、輸入內容、已經初始化的元件都不會遺失）。面板裡放表格、卡片也能正常顯示，切換到時會通知它們重新排版。

8. 屬性速覽

寫在 <ui-tabs> 上

屬性預設說明
shapetrapezoidtrapezoid 梯形、chamfer-right 右上切角、chamfer-left 左上切角、browser 瀏覽器分頁。
skew14僅 browser：斜邊的傾斜角度，0 到 30。
flare8px僅 browser：選中頁籤底部往外張開的圓弧大小，寫 none 關閉。
bar-colorbg-alternative僅 browser：頁籤列的背景色，可寫 transparent。
plus無加上這個屬性，在最右邊顯示裝飾用的「+」，不能點擊；寫 plus="false" 等於不顯示。
cut8px斜邊或切角的大小，單位 px、rem 或 em。
gap6px頁籤間距，可以是負值讓頁籤疊在一起，例如 -10px。
stackright疊放順序：right 右蓋左、left 左蓋右。選中的永遠在最上面。
theme-colorkey整組的選中顏色，色票名稱、色碼或 CSS 顏色。
line-colorgray未選中頁籤的輪廓與底線顏色。
tab-size1rem頁籤文字大小，數字視為 rem。
alignstart頁籤列對齊：start、center、end。
animationslide內容切換動畫：slide、fade、none。
panel-padding16px頁籤列與內容之間的距離，可寫完整的 CSS 簡寫，例如 24px 0 0 0。
