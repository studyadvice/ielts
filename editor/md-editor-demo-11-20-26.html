<md-editor> Markdown 輸入框

GitHub 留言框的樣式：Write 與 Preview 分頁，工具列有標題、粗體、斜體、引用、程式碼、連結、三種清單、提及、參照、斜線與復原。送出的內容可以用 <link-when do="feed"> 直接送進 ui-post、ui-stream，或代入 template 填進 ui-play，不需要寫 JavaScript。

預覽由元件自己轉換，使用者輸入的 HTML 標籤一律跳脫，不會被執行。支援標題、粗斜體、刪除線、行內程式碼與程式碼區塊、引用、巢狀清單、核取清單、連結與圖片（只接受 http、https、mailto、相對路徑）、分隔線，以及 @名稱、#編號 的標色。不支援表格。

事件與方法

名稱說明
md-submit送出時觸發（會冒泡）。detail = { markdown, value, html, text, name }，value 與 markdown 相同；html 是轉好的 HTML；text 是去掉格式的純文字。link-when 的 event="done" 就是這個事件。
md-change內容改變時觸發，detail = { markdown, value }。
md-tab切換分頁時觸發，detail = { tab }。
el.value、el.html、el.text讀取目前內容（value 可寫入）。
el.submit()、el.clear()、el.focus()送出、清空、聚焦。
el.setTab('preview')、el.tab切換或讀取分頁。
el.insert(text)、el.undo()、el.redo()在游標處插入文字、復原、重做。
MdEditor.render(markdown)全域函式，把 Markdown 轉成安全的 HTML。

快捷鍵：Ctrl / Cmd + B 粗體、I 斜體、K 連結、Z 復原、Y（或 Shift + Z）重做、Enter 送出。在清單項目按 Enter 會接續下一項，空項目再按一次就結束清單。

link-when 的 do="feed"

屬性預設說明
do="feed"把事件 detail 的輸入內容送進 B。once 預設改為 false，每次送出都處理；連續送出不會互相擋住。
B 是 ui-post、ui-stream呼叫 add()。ui-post 需要 mode="live"，作者用 detail.name（沒有就是「我」）；ui-stream 預設角色 student。
item不設JSON，補充或覆蓋 add() 的欄位，例如 {"likes":12}、{"from":"teacher"}。
feed-ashtmlhtml 用轉好的 HTML、text 用純文字、markdown 用原始 Markdown 文字。
template不設改為把輸入代入該 <template>，填進 B 容器。代入記號：{html}（轉好的 HTML）、{text}、{markdown}（同 {value}）、{name}，除 {html} 外一律跳脫，可以放在屬性裡。用來填 ui-play，因為它只在建立時讀劇本。
feed-modereplacereplace 先清空 B 再填入；append 接在後面。

不只 md-editor：detail 只要有 value（例如 ui-blank 的 blank-submit、ui-otp 的 otp-complete），也能用 feed 送進這些元件，內容會當作純文字跳脫。
