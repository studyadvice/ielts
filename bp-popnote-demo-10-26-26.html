bp-popnote 示範

本頁對照說明新增的 data-popover-url 屬性：只要給網址，說明方框底部就自動出現一顆 pill 樣式的連結按鈕。

1. 最小寫法：只給網址

範例

雅思口說第二部分常被稱為 Long Turn， 也有人直接叫它 cue card。

未指定按鈕文字時，外部連結自動取網域名當標籤，並附上外開圖示、target="_blank" 與 rel="noopener noreferrer"。

程式碼
<mark
  data-popover-title="Long Turn"
  data-popover-content="考生抽題卡後有 1 分鐘準備…"
  data-popover-theme="lavender"
  data-popover-url="https://www.ielts.org/for-test-takers/test-format">Long Turn</mark>

4. JS 標註 API

範例

許多考生以為 collocation 只是背單字，其實它決定了詞彙資源這一項的上限。

上句中的「collocation」由 BpPopnote.annotate() 在載入後動態包成觸發器。

程式碼
BpPopnote.annotate({
  text    : 'collocation',
  within  : '#js-demo-target',
  title   : 'Collocation',
  content : '自然搭配詞，例如 heavy rain 而非 strong rain。',
  theme   : 'yellow',
  color   : 'yellow',
  url     : 'https://example.com/collocation',
  urlText : '搭配詞練習題',
});

5. 屬性總表

屬性預設值說明
data-popover-url （無） 設定後，說明方框底部自動產生 pill 連結按鈕。可為完整網址或站內路徑。
data-popover-url-text 網域名／「前往」 按鈕文字。外部連結省略時取網域名（自動去除 www.），站內連結省略時顯示「前往」。
data-popover-url-align end 按鈕對齊：start、center、end、full（滿寬）。
data-popover-show-btn
data-popover-btn-href		 （無） 舊版寫法，方角按鈕，維持相容。與 data-popover-url 並存時以後者為準。

6. 本次改動

  • 新增 data-popover-url、data-popover-url-text、data-popover-url-align 三個屬性。
  • buildShowBtnEl() 改寫，優先讀 data-popover-url，否則走舊的 show-btn 流程。
  • 外部連結自動判斷：改用 bi-box-arrow-up-right 圖示、開新分頁、加 rel="noopener noreferrer"，並把完整網址放進 title。
  • 新增 .xpop-url-pill 樣式（圓角 999px、長標籤自動省略），以及 [data-align] 的對齊規則。
  • BpPopnote.annotate() 支援 url、urlText、urlAlign 三個欄位。
  • 按鈕文字改以 textContent 寫入，避免標籤字串被當成 HTML 解析。
