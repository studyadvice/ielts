ui-tracker — AOP 行為追蹤元件

自動攔截 <ui-*> 語意標籤的點擊事件，以及頁面離開事件，批次送往後端 API。

展示模式：API 端點 /api/behavior-log 為虛構位址，送出時會觸發 fetch 錯誤並自動重新排隊。 實際使用時替換 api 屬性即可。所有事件已同步顯示在下方日誌面板。

手動呼叫 track()

非 <ui-*> 範圍內，或需要自訂 payload 時，可直接呼叫：
window.uiTracker.track(action, payload)

記錄自訂事件 立即 Flush

即時事件日誌（僅前端預覽，實際資料送往 API）

  • 尚無事件，請點擊上方元件。

快速整合方式

<!-- 1. 引入元件（放在 </body> 前）-->
<script src="ui-tracker.js"></script>

<!-- 2. 在頁面任意位置放置元件標籤 -->
<ui-tracker
  api="/api/behavior-log"
  flush-interval="5000"
  batch-size="20">
</ui-tracker>

<!-- 3. 你的 <ui-*> 元件照常撰寫，無需任何修改 -->
<ui-button id="confirm-btn" label="確認付款">確認付款</ui-button>

// 4. 手動記錄自訂事件
window.uiTracker.track("form_submit", {
  form_id: "checkout",
  items: 3,
});
