v1.4 新增屬性

── <step-flow> ───────────────────────────────────────────────
show-step-label   「步驟 N」序號標籤是否顯示
                  預設 false（隱藏）→ true | false

default-padding   卡片內距
                  舊預設 32px 36px 26px → 新預設 14px 16px

── <flow-item> ───────────────────────────────────────────────
extra-tab-width   右側垂直色帶寬度
                  預設 16px（例如 24px、2rem）
                  無 extra-info 時此屬性無效

v1.4 完整屬性速查

── <step-flow> ──────────────────────────────────────────────────────────────
  theme              色彩主題 token
  default-width      步驟寬度，預設 min(700px,100%)
  default-border     卡片邊框，省略顏色補主題色
  default-padding    卡片內距，預設 14px 16px
  default-radius     卡片圓角，預設 0
  show-step-label    步驟序號顯示，預設 false → true | false
  show-finish        完成按鈕顯示，預設 true  → true | false
  show-reset         重設按鈕顯示，預設 false → true | false
  reset-label        重設按鈕文字，預設「重新開始」
  btn-a-color        第一按鈕色彩（token 或 #hex）
  btn-b-color        第二按鈕色彩（token 或 #hex）
  font-label         步驟標籤大小，預設 0.72rem
  font-body          內文大小，預設 1.125rem
  font-btn           分支按鈕大小，預設 1rem
  font-pill          pill / 重設按鈕大小，預設 1rem

── <flow-step> ──────────────────────────────────────────────────────────────
  id             步驟識別碼（非首個必填）
  btn-a          第一分支按鈕文字
  btn-b          第二分支按鈕文字
  single-btn     單按鈕，搭配 target-a
  target-a       btn-a / single-btn 目標
  target-b       btn-b 目標
  finish-btn     終點完成按鈕文字
  finish-target  完成按鈕跳至的 div#id

── <flow-item> ──────────────────────────────────────────────────────────────
  width              覆蓋此步驟卡片寬度
  border             覆蓋此步驟卡片邊框
  extra-info         右側色帶 hover 時的 popover 內容（支援 HTML）
  extra-info-title   popover 標題（純文字）
  extra-tab-width    右側色帶寬度，預設 16px
