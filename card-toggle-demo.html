card-toggle.js

輕量化原生 Web Component，零外部框架相依、無 Shadow DOM，一行 <script> 引入即可使用。支援翻轉展示、問答驗證、自動翻回、Grid 網格、群組滑動，以及全新的結果畫面系統。

Web Component Zero Dependency Quiz Mode Grid / Slide Group Result Screen

引入方式

將 card-toggle.js 放到專案目錄，並引入 Bootstrap Icons（圖示來源）。兩個自訂元素 <card-toggle> 與 <card-toggle-group> 自動註冊，無需手動初始化。元件內建重複初始化防護（connectedCallback 只執行一次）。

HTML
<!-- 1. Bootstrap Icons -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">

<!-- 2. card-toggle 元件（置於 </body> 前） -->
<script src="card-toggle.js"></script>
元件樣式在首次使用時自動注入 <head>（ID：card-toggle-styles），每頁只注入一次。

基本翻轉

點擊卡片，正面內容被替換為背面。背面來源有兩種：content（直接 HTML 字串）與 source（clone 頁面隱藏元素）。

屬性型別說明
contentstring可選背面 HTML 字串，適合簡短內容。
sourcestring可選頁面隱藏元素的 id，元件 clone 其內容。適合複雜 HTML 結構。

<card-toggle content="<strong>背面！</strong> 可放任意 HTML 字串。">
  點擊查看背面 ▸
</card-toggle>

自動翻回

翻到背面後底部出現倒數進度條，倒數結束自動翻回正面。flip-bar-color 自訂進度條顏色，優先順序：flip-bar-color > color-after > color > sky。

屬性型別預設說明
auto-flipnumber (ms)—可選翻面後自動翻回的毫秒數（例如 3000）。
flip-bar-colorstringsky可選倒數進度條顏色名稱或 hex 值。
HTML
<!-- 3 秒後自動翻回，sky 進度條（預設） -->
<card-toggle auto-flip="3000" color="sky"
             content="3 秒後自動翻回，留意底部進度條。">
  auto-flip="3000" — 點擊後 3 秒翻回
</card-toggle>

<!-- 5 秒後翻回，pink 進度條 -->
<card-toggle auto-flip="5000" color="shell" flip-bar-color="pink"
             content="5 秒後翻回，Pink 進度條。">
  flip-bar-color="pink" — 自訂進度條顏色（5 秒）
</card-toggle>
即時預覽
auto-flip="3000"（3 秒倒數） flip-bar-color="pink"（5 秒）

問答模式 — 基本

設定 question 與 answer 後，點擊卡片展開問答介面，預設不區分大小寫。

屬性型別預設說明
questionstring—必填題目文字，設定此屬性即啟用問答模式。
answerstring—必填正確答案字串。
placeholderstring請輸入答案可選輸入框提示文字。
case-sensitiveboolean—布林啟用後，答案比對區分大小寫。
success-messagestring答對了！可選答對後顯示的訊息。
error-messagestring答錯了，請再試一次可選答錯時訊息。
success-colorstringsafe可選答對後卡片切換的顏色主題。
success-sourcestring—可選答對後 clone 並展示的元素 ID（用於詳細解說）。
HTML
<card-toggle
  color="sky"
  question="台灣的首都是哪個城市？"
  answer="台北"
  placeholder="請輸入城市名稱"
  success-message="正確！台北是台灣的首都城市。"
  error-message="不對喔，再想想看…">
  點擊作答 — 台灣的首都？
</card-toggle>

群組模式 — Slide 滑動

設定 mode="slide" 後，卡片橫向滑動展示，一次只顯示一張。此版本新增頂部計數器、lock-nav 強制依序作答、頁碼按鈕答題狀態顏色。

屬性（group）型別說明
mode="slide"string群組啟用橫向滑動模式。
show-pagesboolean布林顯示頁碼按鈕，可直接跳頁。答題後頁碼會變色（✓ 綠 / ✗ 橙）。
hide-nav-buttonsboolean布林隱藏上一張／下一張按鈕。

lock-nav boolean 布林 NEW鎖定導覽：必須先答題（或翻牌），才能前往下一張。頁碼按鈕也受限制。
auto-next（子卡片）boolean布林問答答對後 1.5 秒自動進入下一張。

群組模式 — 結果畫面 NEW

在 card-toggle-group 加上 show-result，全部題目作答完畢後（600ms 延遲），自動取代群組內容，顯示分數、答題明細及重新作答按鈕。

屬性（group）型別預設說明
show-result boolean — 布林 NEW全部答題後顯示結果畫面，包含百分比、答對／答錯／略過題數。
result-source string — 可選 NEW結果畫面中附加顯示的自訂元素 ID（如鼓勵語句、後續資源連結）。
retry-label string ↺ 重新作答 可選 NEW重新作答按鈕的文字。
答題狀態由 _markAnswered(card, 'correct'|'wrong') 收集。答對計 correct，達到嘗試上限計 wrong，翻牌但未作答計 skipped。_retryAll() 方法可完整重置群組。
HTML
<!-- 自訂結果區塊（隱藏） -->
<div id="result-msg" style="display:none">
  <p style="margin-top:16px; font-size:0.9rem; opacity:0.7">
    繼續練習，熟能生巧！複習後可點擊上方按鈕重新作答。
  </p>
</div>

<card-toggle-group

  retry-label="↺ 重新挑戰">

JavaScript API

card-toggle 提供 reset() 方法；card-toggle-group 提供 _retryAll() 方法，可程式化重置整組。

元素方法說明
card-toggle reset() 重置單張卡片：清除翻面狀態、錯誤訊息、嘗試次數、計時器、提示顯示區，恢復原始 color。
card-toggle-group _retryAll() NEW 重置整組：清空答題狀態、計數器、頁碼按鈕，重新初始化 slide 模式，用於從結果畫面重新作答。
JavaScript
// 重置單張卡片
document.querySelector('card-toggle').reset();

// 重置頁面所有卡片
document.querySelectorAll('card-toggle').forEach(c => c.reset());

// 程式化重新作答整組（等同結果畫面的「重新挑戰」按鈕）
document.querySelector('card-toggle-group')._retryAll();
