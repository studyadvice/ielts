dot-go 跳轉圓點

按 1 開觸控筆，再用筆點下方任何圓點，一樣會跳轉，不會被繪圖層吃掉。按 0 回到一般點選。

大小 size

自訂色碼

Part 3　屬性與介面

屬性說明預設
href「#id」為同頁平滑捲動並閃一下目標外框，其餘當網址跳轉無（未設則停用）
theme配色表名稱，或 #RGB／#RRGGBBsky
dot-stylecircle、circle-fill、star、star-fill、square、square-fill、iconcircle-fill
icondot-style="icon" 時的 Bootstrap Icons 名稱，例如 bi-translate無
size圖示大小 px，範圍 10 至 4818
target設為 _blank 時另開分頁同分頁
offset同頁跳轉時保留的上方距離 px，給固定頁首用16
clear-ink有此屬性時，跳轉前先清除繪圖層筆跡不清除
標籤內文字顯示在圖示右側當標籤，留空只顯示圖示空

事件與 JavaScript

// 跳轉前觸發，可 preventDefault() 取消
document.addEventListener('dot-go', function (e) {
  console.log(e.detail.href, e.detail.internal, e.detail.target);
});

InkPen.dots();                 // 頁面上所有 <dot-go>
InkPen.dots()[0].go();         // 用程式觸發跳轉
InkPen.dotStyles;              // 支援的樣式清單

注意：若 <dot-go> 的祖先元素設了 transform、filter、opacity 小於 1， 或 position 搭配 z-index，會建立新的堆疊環境，圓點可能被繪圖層蓋住。

Part 4　清筆跡後跳轉

先按 1 在畫面上隨意畫幾筆，再點這顆 回頂端並清除， 筆跡會先清空再跳轉。少了 clear-ink 的圓點則保留筆跡：回頂端（保留筆跡）

本示範的繪圖層設為 data-anchor="document"，筆跡會跟著內容捲動。

修改 2　dot-style="icon"（Bootstrap Icons）

新增第七種樣式 icon，搭配 icon 屬性指定 Bootstrap Icons 名稱。 頁面若還沒引入 Bootstrap Icons，元件會自動從 jsDelivr 載入一次；已引入則不重複載入。

範例

翻譯練習 口說錄音 提示 回頂端 IELTS 官網

只有圖示，搭配不同 size

容錯

缺 icon 屬性，退回 circle-fill

icon 寫成「bi-translate」、「translate」或「bi bi-translate」都可以。 名稱拼錯時畫面會是空白，請到 icons.getbootstrap.com 核對名稱。
