dot-go.js：跳轉圓點與轉場拆成獨立元件

原本內建在 ink-pen.js 的 <dot-go> 與 View Transitions 轉場，現在是同資料夾的 dot-go.js。只用畫筆的頁面少載約 30 KB；只要跳轉圓點的頁面也不必載入整套畫筆。

1. 檔案拆分前後

原本

<!-- 一支檔案包含畫筆、手寫、NG、dot-go、轉場（約 97 KB） -->
<script src="ink-pen.js"></script>

11-11-26

<!-- 只要畫筆（約 69 KB） -->
<script src="ink-pen.js"></script>

<!-- 只要跳轉圓點與轉場（約 32 KB） -->
<script src="dot-go.js"></script>

<!-- 兩者都要：順序不拘；用到跨頁轉場時 dot-go.js 放在 <head> -->
<script src="dot-go.js"></script>
<script src="ink-pen.js"></script>

3. 對外介面

原本

InkPen.dots();
InkPen.dotStyles;
InkPen.transitions;
InkPen.transitionSupport;
InkPen.transition('zoom-in', () => { /* 換畫面 */ }, { ms: 800 });

11-11-26

// 新的介面
DotGo.dots();
DotGo.dotStyles;
DotGo.transitions;
DotGo.transitionSupport;
DotGo.transition('zoom-in', () => { /* 換畫面 */ }, { ms: 800 });

// 兩支都載入時，舊寫法 InkPen.dots()、InkPen.transition() 照常可用

// 全頁預設轉場：沒有工具列的頁面可以寫在 <body> 上
<body data-transition="push" data-transition-edge="key">

4. 其他調整

原本

dot-go:hover { background: rgba(32,33,25,0.92); }
樣式 id：ink-pen-dotgo-styles、ink-pen-vt-styles
轉場屬性：html[data-ip-vt]

11-11-26

dot-go:hover { background: #202119; }   /* 改成實色 */
樣式 id：dot-go-styles、dot-go-vt-styles
轉場屬性：html[data-dg-vt]
