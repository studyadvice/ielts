ink-pen 極簡畫筆層

螢幕錄影時的最小標註工具。只保留觸控筆、雷射筆、筆跡色彩、清除與收合，工具列預設是右下角一顆 40px 的小圓鈕，不會壓到錄影主體區。零依賴，單獨一支 js 丟進任何頁面就能用。

快捷鍵

按鍵功能
1觸控筆，筆跡會保留在畫面上
3雷射筆，拖曳時出現紅色光跡並自動淡出
0關閉繪圖，回到一般點選與捲動
C清除全部筆跡
H收合或展開工具列

游標停在輸入框或下拉選單裡時，快捷鍵不會觸發，可以放心打字。

錄影時的小圓鈕狀態

  • 圓鈕中心的小點會顯示目前筆色，一眼就知道待會畫出來是什麼顏色。
  • 筆或雷射作用中時，圓鈕外圈會亮起海洋藍光暈，提醒你此時頁面無法點選。
  • 工具列收合後，1、3、0、C 仍然有效，所以整段錄影其實可以不展開工具列。

筆跡色彩

下拉選單提供八個顏色，都取自既有配色表。雷射筆固定使用警示紅，不受這裡影響。

霧白 focus 海洋藍 ocean 黃 yellow 嫩綠 special 粉紅 pink 橙 orange 薰衣草 lavender 天空藍 sky

粗細輸入框範圍 3 至 12 px，預設 3。觸控筆若回報壓力值，線寬會依壓力在設定值的 0.35 至 1.85 倍之間浮動；用滑鼠畫則維持固定寬度。

頁面用法

<script src="ink-pen.js"></script>

<!-- 全頁各放一個即可，位置任意 -->
<ui-ink-layer></ui-ink-layer>
<ui-ink-bar data-pos="br"></ui-ink-bar>

工具列屬性

data-pos="br"      右下角（預設）
data-pos="bl"      左下角
data-pos="tr"      右上角
data-pos="tl"      左上角

data-open="true"   載入時直接展開工具列

程式介面 window.InkPen

InkPen.layer()            // 取得 <ui-ink-layer>
InkPen.bar()              // 取得 <ui-ink-bar>
InkPen.palette            // 配色表物件
InkPen.penColorOptions    // 筆色選項
InkPen.widthRange         // { min:3, max:12, def:3 }
InkPen.showAlert(msg, 'info')

// 直接操作繪圖層
InkPen.layer().setMode('pen');   // pen / laser / off
InkPen.layer().setColor('yellow');
InkPen.layer().setWidth(6);
InkPen.layer().clear();

// 操作工具列（會連動按鈕外觀）
InkPen.bar().setMode('laser');
InkPen.bar().toggleBar(true);
