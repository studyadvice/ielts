ink-pen NG 標記

2026-11-10 新增：錄影中按下快捷鍵，整頁出現紅色遮罩並記下時間點，方便事後剪輯。

即時操作

00:00.0 未計時 NG 0 筆

快捷鍵：Ctrl+Shift+3 開始或結束計時，Ctrl+Shift+4 標記 NG。工具列的「錄」「NG」「清單」按鈕效果相同。

遮罩預設 2 秒，只用色票的 urgent，不擋任何操作，所以按下後仍可繼續講課與畫筆。

模擬錄課內容

Describe a place you often go to relax. You should say where it is, how often you go there, and explain why it helps you unwind.

Well, there's a quiet park ________ my office, and I tend to drop by after a long day.

錄影時講到這裡說錯了？按 Ctrl+Shift+4，整頁會變紅 2 秒。

範例與程式碼對照

項目範例程式碼
基本用法 放了 <ui-ink-bar> 就有「錄」「NG」「清單」三顆按鈕和兩個快捷鍵，不必另外設定。 
<ui-ink-layer></ui-ink-layer>
<ui-ink-bar></ui-ink-bar>
調整遮罩與前推秒數 遮罩改 3 秒，標記前推 5 秒，開始時間前推 2 秒。數值單位：遮罩為毫秒，其餘為秒。 
<ui-ink-bar
  data-ng-mask-ms="3000"
  data-ng-offset="5"
  data-ng-start-offset="2">
</ui-ink-bar>
用程式操作 上方四顆按鈕就是呼叫這些方法。mark() 在未計時的情況下只顯示遮罩，不記時間點。 
InkPen.ng.start();          // 開始計時
InkPen.ng.mark();           // 標記 NG
InkPen.ng.stop();           // 結束計時
InkPen.ng.text();           // 取得純文字清單
InkPen.ng.isRecording();    // 是否計時中
InkPen.ng.openPanel();      // 開啟清單視窗
InkPen.ng.clear();          // 清空紀錄
清單格式 按下「錄」那一刻為 00:00.0。每筆標記都前推 3 秒，不足 0 以 00:00.0 計，剪輯時請以影片中的紅幀為準。
