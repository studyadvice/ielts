ink-pen 極簡畫筆層

螢幕錄影時的最小標註工具。只保留觸控筆、雷射筆、筆跡色彩、清除與收合，工具列預設是右下角一顆 40px 的小圓鈕，不會壓到錄影主體區。零依賴，單獨一支 js 丟進任何頁面就能用。

錄影時的小圓鈕狀態

  • 圓鈕中心的小點會顯示目前筆色，一眼就知道待會畫出來是什麼顏色。
  • 筆或雷射作用中時，圓鈕外圈會亮起海洋藍光暈，提醒你此時頁面無法點選。
  • 工具列收合後，1、3、0、C 仍然有效，所以整段錄影其實可以不展開工具列。

v2　10-28-26

新增 data-anchor 座標模式，筆跡可選擇固定在視窗或跟著內容捲動；新增 extra-color 自訂筆色。

座標模式　data-anchor

viewport　貼著視窗（預設）

筆跡以螢幕座標記錄，捲動頁面時筆跡留在原本的螢幕位置。適合畫面固定不動的錄影，或在單一畫面上做框線、箭頭這類不屬於某段文字的標記。

觸控時會完全鎖住捲動（touch-action:none），下筆最穩。

document　貼著內容

筆跡以文件座標記錄，捲動頁面時筆跡跟著段落一起移動，可以邊捲邊畫，整頁講解完回頭捲上去，前面劃的線還在原來的句子上。

觸控時放行垂直捲動（touch-action:pan-y），用觸控筆橫向劃線、用手指上下捲；滑鼠滾輪在兩種模式下都能捲。

實際比較

按 1 開筆，在下面三個色塊上各畫一條線，然後捲動頁面看看筆跡的行為；再切換模式重畫一次。切換當下畫面上的筆跡位置不會跳動，元件會依當時的捲動量換算座標。

自訂筆色　extra-color

用法

在工具列加上 extra-color，色彩選單尾端就會多一個選項，並在載入時自動選用它。extra-label 可指定顯示名稱，省略時直接顯示色碼。

接受 #RGB 與 #RRGGBB 兩種寫法，格式不符會跳出警示並沿用內建色彩，不會中斷其他功能。

目前自訂色：#FFFFFF

v2 標籤寫法

<ui-ink-layer data-anchor="document"></ui-ink-layer>

<ui-ink-bar
    data-pos="br"
    extra-color="#FFFFFF"
    extra-label="純白 white"></ui-ink-bar>

v2 新增介面

// 座標模式，兩邊都可以叫
InkPen.layer().setAnchor('document');
InkPen.layer().getAnchor();      // 'viewport' | 'document'
InkPen.bar().setAnchor('viewport');   // 另外跳提示訊息

// 自訂筆色，等同改屬性，選單即時重建
InkPen.bar().setExtraColor('#FF5C00', '螢光橘');
InkPen.bar().setExtraColor(null);     // 移除自訂色

設計取捨

為什麼預設仍是視窗座標

錄影時畫面多半固定不動，視窗座標的運算最少，觸控也能完全鎖住捲動，下筆不會誤觸發頁面滑動。需要長篇講解再切 document。

為什麼沒有復原

錄影當下按錯鍵的成本比畫錯一筆高。清除是一個明確動作，復原則需要盯著畫面確認結果，反而打斷講解節奏，因此只保留 C。

為什麼工具列在角落

橫跨頂端的主控列會吃掉畫面高度，錄影時主體內容被往下推。改成右下角膠囊後，收合狀態只佔 40 px，展開也只是一條懸浮列，不影響版面。
