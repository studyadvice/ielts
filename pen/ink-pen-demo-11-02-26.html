新增屬性與方法

項目值說明
<ui-ink-layer data-lock-scroll>true 或空值觸控筆、雷射筆模式都鎖定捲動，只有「關」可以捲動。viewport 與 document 兩種模式都適用。
pen只在觸控筆模式鎖定，雷射筆仍可捲動。
不寫屬性不鎖定，維持原本行為。
layer.setScrollLock(v)true／"pen"／false程式端切換，會同步改寫屬性。bar.setScrollLock(v) 與 InkPen.lockScroll(v) 效果相同。
layer.isScrollLocked()布林此刻是否鎖定中。
ink-scroll-lock 事件{ locked, rule, mode }鎖定狀態改變時觸發，會冒泡到 document。
InkPen.shortcuts陣列模式快捷鍵對照，可用來產生自己的說明畫面。

本次修改對照（2026-11-02）

一、模式快捷鍵

修改前 
if (e.ctrlKey || e.metaKey || e.altKey) return;
switch (e.key) {
  case '1': this.setMode('pen'); break;
  case '3': this.setMode('laser'); break;
  case '0': this.setMode('off'); break;
  ...
}
修改後 
var MODE_KEYS = [
  { code: 'Digit1',    mode: 'pen',   label: 'Ctrl+Shift+1' },
  { code: 'Digit2',    mode: 'laser', label: 'Ctrl+Shift+2' },
  { code: 'Backquote', mode: 'off',   label: 'Ctrl+Shift+`' }
];
/* 依實體按鍵 e.code 判斷，按住 Shift 時 e.key
 * 會變成 ! @ ~，中文輸入法下也可能不準 */
var mode = this._matchModeKey(e);
if (mode) { e.preventDefault(); this.setMode(mode); return; }

二、捲動鎖定（HTML 用法）

修改前 
<ui-ink-layer data-anchor="document"></ui-ink-layer>
<!-- 開筆時滾輪照樣捲動；
     document 模式下手指拖曳會捲動頁面 -->
修改後 
<ui-ink-layer data-anchor="document"
              data-lock-scroll="true"></ui-ink-layer>
<!-- 筆或雷射開著時完全不能捲動，按「關」才恢復
     只想鎖觸控筆：data-lock-scroll="pen" -->

三、document 模式的手指拖曳

修改前 
if (touch && this._anchor === 'document') {
  /* 手指拖曳 → 捲動頁面 */
}
修改後 
if (touch && this._anchor === 'document' && !this._locked) {
  /* 鎖定中不捲動，手指比照 viewport 模式交給作畫，
   * 防手掌誤觸照常運作 */
}

四、鎖定的三道防線

/* 1. 源頭攔截：wheel、touchmove（passive:false）與捲動鍵 preventDefault
 *    Ctrl+滾輪是縮放，放行；空白鍵在按鈕上是按下按鈕，放行；輸入框內的方向鍵放行
 * 2. 拉回原位：拖曳捲軸等擋不掉的捲動，在 scroll 事件裡以 behavior:'instant' 拉回
 * 3. 放行通道：<dot-go> 同頁跳轉前呼叫 layer.allowScroll()，平滑捲動結束後
 *    落點成為新的鎖定位置 */
