info-region

內容區塊的逐步展開元件——倒數、手動、鏈結、群組、進度條

安裝

無外部相依，在 <body> 末尾引入即可。

<script src="info-region.js"></script>

基本展開

<info-region> 初始隱藏，設定 active="true" 或呼叫 InfoRegion.activate('id') 來展開。color 接受所有品牌色名稱。

直接設定 active="true" 
<info-region active="true" color="lavender">
  這段內容預設就是展開狀態。
</info-region>

<!-- 或用 JS 觸發 -->
<info-region id="r1" color="sky">
  由按鈕觸發展開的內容。
</info-region>

<button onclick="InfoRegion.activate('r1')">
  展開
</button>

Countdown 倒數自動跳下一個

加上 countdown="毫秒"，展開後底部出現倒數進度條，時間到自動觸發 next 指定的下一個區塊。countdown-color 可覆寫進度條顏色。

countdown + next 鏈結 
<info-region id="cd1"
  color="ocean"
  countdown="2500"
  next="cd2">
  第一段：2.5 秒後自動展開下一段
</info-region>

<info-region id="cd2"
  color="teal"
  countdown="2500"
  next="cd3">
  第二段：再 2.5 秒後展開第三段
</info-region>

<info-region id="cd3"
  color="safe">
  第三段：終點，無倒數
</info-region>

<button onclick="InfoRegion.activate('cd1')">開始</button>

鏈結 next（無倒數）

不加 countdown 時，展開後等待 next-interval（預設 500ms） 再觸發下一個，適合純粹的順序展示。

next 純鏈結 
<info-region id="n1"
  color="indigo"
  next="n2"
  next-interval="400">
  Step 1
</info-region>

<info-region id="n2"
  color="lavender"
  next="n3"
  next-interval="400">
  Step 2
</info-region>

<info-region id="n3"
  color="pink">
  Step 3：完成
</info-region>

手動按鈕

加上 manual 屬性，展開後顯示「下一步」按鈕，由使用者決定何時繼續。 manual-label 自訂按鈕文字，manual-align 控制對齊（left / center / right）。

manual 手動推進 
<info-region id="m1"
  color="focus"
  manual
  manual-label="我準備好了 →"
  manual-align="right"
  next="m2">
  閱讀這段內容，準備好再繼續。
</info-region>

<info-region id="m2"
  color="yellow"
  manual
  manual-label="繼續 →"
  next="m3">
  第二段內容。
</info-region>

<info-region id="m3"
  color="safe">
  ✅ 完成！
</info-region>

<button onclick="InfoRegion.activate('m1')">開始</button>

Group 群組

用 <info-region-group> 包裹，自動產生「開始」和「重設」按鈕， 管理群組內所有區塊的展示流程。

info-region-group 基本用法 
<info-region-group
  start-label="▶ 開始閱讀"
  start-color="ocean"
  reset-color="warning">

  <info-region
    color="ocean"
    next="g2">
    第一段：展開後自動觸發下一段
  </info-region>

  <info-region id="g2"
    color="teal"
    manual
    next="g3">
    第二段：手動按鈕
  </info-region>

  <info-region id="g3"
    color="safe">
    第三段：終點
  </info-region>

</info-region-group>

Cascade 依序展開

在 <info-region-group> 設定 cascade-interval="毫秒"， 按下開始後所有區塊依序以固定間隔自動展開，不需要 next 屬性。

cascade-interval="600" 
<info-region-group
  cascade-interval="600">

  <info-region color="lavender">0.0s 展開</info-region>
  <info-region color="sky">    0.6s 展開</info-region>
  <info-region color="ocean">  1.2s 展開</info-region>
  <info-region color="teal">   1.8s 展開</info-region>
  <info-region color="safe">   2.4s 展開</info-region>

</info-region-group>

水平佈局

在 <info-region-group> 設定 layout="horizontal"， 區塊由下往右展開。cols-per-row 控制每列幾欄（預設 4）， row-gap 控制間距。

layout="horizontal" cols-per-row="3" 
<info-region-group
  layout="horizontal"
  cols-per-row="3"
  cascade-interval="300">

  <info-region color="lavender">
    Task Achievement
任務完成度
  </info-region>

  <info-region color="sky">
    Coherence & Cohesion
連貫性
  </info-region>

  <info-region color="ocean">
    Lexical Resource
詞彙豐富度
  </info-region>

  <info-region color="teal">
    Grammatical Range
語法多樣性
  </info-region>

</info-region-group>

全體進度條

在 <info-region-group> 加上 global-progress， 出現整體完成進度條。show-percent 加上百分比數字。 設定 global-progress 時，個別 countdown 不觸發 next， 由群組的 cascade 或 next 鏈結統一控制。

global-progress + show-percent 
<info-region-group
  cascade-interval="500"
  global-progress
  show-percent
  progress-color="ocean">

  <info-region color="indigo">評分維度 1</info-region>
  <info-region color="lavender">評分維度 2</info-region>
  <info-region color="sky">評分維度 3</info-region>
  <info-region color="ocean">評分維度 4</info-region>

</info-region-group>

框線細設定

預設只有左側框線。用 border-width 設定四邊同寬， 或用 border-top-width 等個別控制。border-style 支援所有 CSS border-style 值。

各種框線組合 
<!-- 預設：只有左側框線 -->
<info-region active="true" color="lavender">
  預設左側 4px solid
</info-region>

<!-- 四邊框線 -->
<info-region active="true"
  color="ocean"
  border-width="1">
  四邊 1px solid
</info-region>

<!-- 上框線 dashed + 左框線加粗 -->
<info-region active="true"
  color="focus"
  border-top-width="2"
  border-top-style="dashed"
  border-left-width="6">
  上框虛線 + 左框加粗
</info-region>

JS API

方法說明
InfoRegion.activate('id')展開指定 id 的 info-region
InfoRegion.resetAll()重設頁面所有 info-region 回初始狀態
InfoRegion.colors取得所有可用色名陣列
InfoRegion.config取得當前全域設定的副本
el.activate()元素方法：展開（等同設定 active="true"）
el.reset()元素方法：收起並清除倒數/手動按鈕
groupEl.start()群組方法：開始
groupEl.reset()群組方法：重設所有子區塊

全域設定（引入前宣告）

<script>
  window.InfoRegionConfig = {
    defaultColor:      'lavender',   // 預設色
    animDuration:      400,          // 垂直展開動畫 ms
    horizontalAnimDur: 300,          // 水平淡入動畫 ms
    defaultInterval:   400,          // 無 countdown 的鏈結延遲 ms
    borderWidth:       4,            // 預設左框線粗細
    borderRadius:      '0 6px 6px 0',
    bgColor:           '#2a2b2a',    // 展開區塊背景色
    fontSize:          '1rem',
    padding:           '14px 18px 20px 20px',
    manualLabel:       '繼續 →',
    cascadeInterval:   0,
    colsPerRow:        3,
  };
</script>
