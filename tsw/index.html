ui-theme-switcher

點擊左下角的「外觀」，可即時切換淺色、深色、跟隨系統，以及六組色彩主題。下方的產生器會依目前主題的角色變數，產生可直接貼進 .html 或 .php 的 div 區塊。

使用方式

1. 載入元件

<head>
  <script src="ui-theme-switcher.js"></script>
</head>
<body>
  <ui-theme-switcher placement="top" storage-key="ui-theme"></ui-theme-switcher>
</body>

2. 屬性

屬性預設值說明
storage-keyui-theme儲存鍵名前綴，前後台想用不同主題時請設不同值。
placementtop選單展開方向，可設 top 或 bottom。
alignstart選單對齊，可設 start 或 end。
label外觀觸發按鈕上的文字。

3. 事件與 API

document.addEventListener('ui-theme-change', function (e) {
  console.log(e.detail); // { mode, color, colorName, resolved }
});

UIThemeSwitcher.set({ mode: 'light', color: 'gruvbox' });
UIThemeSwitcher.get();
UIThemeSwitcher.register({
  id: 'mine',
  name: 'Mine',
  dark: [/* 14 個色碼，順序同角色對照表 */],
  light: [/* 14 個色碼 */]
});

4. 在頁面中使用角色

body    { background: var(--bg-base); color: var(--text-main); }
.card   { background: var(--bg-panel); border: 1px solid var(--border); }
a       { color: var(--accent); }
.danger { background: var(--warning); color: var(--on-color); }

5. 使用品牌色

.tag-lavender { background: var(--brand-lavender); color: var(--brand-bg); }
.tag-indigo   { background: var(--brand-indigo);   color: var(--brand-focus); }

/* 新增或覆蓋品牌色，只接受 #rgb 或 #rrggbb */
UIThemeSwitcher.addBrand('coral', '#FF7F50', '珊瑚橘');

修改紀錄對照

同一個元件的每次修改，都把修改前後的範例與程式碼附加在這裡。

v1.2.0　新增 16 個品牌色變數

原因：品牌色固定不變，不應該跟著主題改。新增的變數名稱都以 --brand- 開頭，不影響原有的 14 個角色。

1. 在 CSS 使用品牌色

舊v1.1.0
/* 寫死色碼，或借用會隨主題變的角色 */
.tag { background: #C3A5E5; }
.tag { background: var(--accent-2); }
新v1.2.0
/* 固定的品牌色，切換主題也不變 */
.tag { background: var(--brand-lavender);
       color: var(--brand-bg); }

2. JavaScript API

舊v1.1.0
UIThemeSwitcher.get();
UIThemeSwitcher.set({ mode, color });
UIThemeSwitcher.register(def);
UIThemeSwitcher.roles;
UIThemeSwitcher.themes;
新v1.2.0
/* 原有 API 不變，另外新增 */
UIThemeSwitcher.brand;
UIThemeSwitcher.addBrand('coral', '#FF7F50', '珊瑚橘');

3. 產生器的選項

舊v1.1.0
背景、文字、邊框、色條的下拉選單
只有主題角色，例如 --accent、--warning
新v1.2.0
下拉選單分成兩組：
  主題角色（隨主題改變）
  品牌色（固定色碼）
實色底的文字色會依深淺自動挑選

品牌色不分亮暗，淺色模式下色碼也相同，所以只用深色背景時不需要另外調整。

v1.1.0　屬性 data-theme 改名為 data-jstheme

原因：data-theme 容易與其他函式庫或自己的樣式衝突。data-color 與 Bootstrap 的 data-bs-theme 維持不變。

1. 容器固定亮或暗

舊v1.0.0
<aside data-theme="dark">
  永遠是暗色側邊欄
</aside>
新v1.1.0
<aside data-jstheme="dark">
  永遠是暗色側邊欄
</aside>

2. 自己的 CSS 選擇器

舊v1.0.0
[data-theme="light"] .card {
  box-shadow: 4px 4px 0 var(--border);
}
新v1.1.0
[data-jstheme="light"] .card {
  box-shadow: 4px 4px 0 var(--border);
}

3. html 根元素上的屬性

舊v1.0.0
<html data-theme="dark" data-color="shell" data-bs-theme="dark">
新v1.1.0
<html data-jstheme="dark" data-color="shell" data-bs-theme="dark">

4. 舊頁面的遷移方式

全域搜尋並取代：
  data-theme=   改為   data-jstheme=
  [data-theme   改為   [data-jstheme

不要動：data-color、data-bs-theme
