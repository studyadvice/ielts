ui-btn 多目標展開

ui-plus.js 的 <ui-btn> 新增 targets 屬性：一次點擊，同時展開多個隱藏的 <div> 或 <template>，由 id 決定。建立日期 11-10-26。
第二次修改：anim-duration 可設超過 600 毫秒，修正淡入被截斷，見範例四。
第三次修改：新增 mini-table-id、target-cell、target-cell-content、target-cell-source，揭曉 mini-table 的指定儲存格，見範例五。

範例一：一次展開散落各處的 div

三個答題提示不必相鄰，也不必放在按鈕旁邊。targets 用空白或逗號分隔 id，開頭的 # 可寫可不寫。第三個提示用 bp-hidden class 隱藏，同樣可以展開。

範例二：template 延遲渲染，與 div 混合使用

<template> 的內容在第一次展開時才複製到它後面的 <div>，之後的開合都作用在這個 div，所以輸入過的內容會保留。template 內的 ui-btn 會自動初始化。template 的 class 與 style 會帶到輸出的 div。

範例三：stagger 依序出現

stagger="400" 讓目標依 targets 的順序，每隔 400 毫秒出現一個；收合時全部同時收起。搭配 animation="fade"，適合上課時一步一步揭曉答案。

HTML

範例四：調整間隔與淡入速度

兩個屬性分工：stagger 是「下一個什麼時候開始」，anim-duration 是「每一個淡入要花多久」，單位都是毫秒。anim-duration 預設 320，現在可以設超過 600，淡入不會被提前截斷。stagger 比 anim-duration 短時，前一個還沒完全出現，下一個就開始，畫面會有接力的感覺。

HTML

範例五：揭曉 mini-table 的儲存格

需要同時載入 mini/mini-table.js。mini-table-id 指定表格，target-cell 指定儲存格，座標和 Excel 一樣：欄用字母、列用數字，表頭算第 1 列。內容寫在 target-cell-content，或用 target-cell-source 從 template 讀。再按一次會恢復原本的內容。揭曉時格子內框會短暫亮起按鈕的顏色。

HTML

新增與調整的屬性

屬性範例說明
targetstargets="a, b #c"新增。要一起開合的元素 id，逗號或空白分隔，# 可省略。目標可以是任何元素或 <template>。
targettarget="a"原有屬性，寫法不變；現在也接受多個 id。與 targets 同時存在時合併，重複的 id 只算一次。
staggerstagger="400"新增。展開時每個目標間隔的毫秒數，預設 0（同時展開）。收合一律同時進行。
anim-durationanim-duration="1200"原有屬性。每個目標展開或收合動畫的毫秒數，預設 320，fade 與 slide 都適用。修正後可設超過 600。全域預設可用 UiBtnConfig.animDuration。
mini-table-idmini-table-id="mytbl"新增。要操作的 <mini-table> 的 id，需載入 mini/mini-table.js。也接受少一個字母的 min-table-id。設定後按鈕不會再去開合緊接在後面的元素。
target-celltarget-cell="B2"
target-cell="B2 C3"
target-cell="C2:C4"		新增。儲存格座標，和 Excel 相同，表頭算第 1 列。可寫多格（逗號或空白分隔）與範圍，$B$2 的 $ 會略過。不存在的格子會在主控台警告並略過。
target-cell-contenttarget-cell-content="<b>Cafe</b>"新增。要顯示的內容，可寫 HTML。多格時用 | 分隔，一格一段；只寫一段就每格都用同一段。內容本身要放 | 時寫成 \|。
target-cell-sourcetarget-cell-source="ans"新增。改從 <template> 或元素讀取內容，優先於 target-cell-content。適合較長的 HTML，多格時同樣用 | 分隔。
<template> 目標<template id="t">第一次展開時渲染到緊接其後的 <div class="ubtn-tpl-out" data-ubtn-from="t">。多顆按鈕指向同一個 template 時共用同一份輸出。渲染後觸發會冒泡的 ubtn-template-rendered 事件，e.detail 含 template、output、button。

開合狀態：只有全部目標都已顯示時，按鈕才會以展開狀態開始；部分顯示時，按下會補開其餘目標，已顯示的不重播動畫。open、scroll-gate、group、unlock-chunk、href 都能和多個目標一起使用。

順帶修正：目標用 class（例如 bp-hidden）隱藏時，展開後改以 display:block 顯示；收合動畫進行中快速再按一次，內容不會在動畫結束時又被藏起來。
