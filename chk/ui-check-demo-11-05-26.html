ui-check：品牌色與按鈕樣式

修改日期 11-05-26。品牌色改用新色票，舊色名自動對應；新增 variant、color2、angle、shape 四個屬性；內部 class 改為 uck- 前綴並限定在 ui-check 內，不再與 ui-cards 的 .uic-btn 互相影響。修改 2：outline 滑過時改為 solid 效果。

屬性一覽

屬性值預設說明
variantoutline、solid、soft、ghost、link、gradient、gradient-outlineoutline按鈕的視覺樣式。寫錯時退回 outline。
color品牌色名blue主色。舊色名仍可用，見下方對照表。
color2品牌色名violet漸層的第二色，只在 gradient、gradient-outline 使用。
angle90deg、to right 等135deg漸層方向。
shaperounded、pill、squarerounded按鈕外形。
sizexs、sm、md、lgxs沿用原本的尺寸。
icon、key、state不變行為與原本相同。

品牌色與舊色名對照

實心底上的文字色依亮度自動選擇；這組品牌色都偏亮，因此一律使用深色字，對比度介於 5.36 到 15.87。舊色名對應到最接近的新色，若想改對應，只要修改檔案開頭的 ALIASES。

修改 2：outline 滑過時變成 solid

    
原本 outline 滑過時只換成深灰底；現在滑過時以按鈕本身的品牌色填滿，文字與圖示改用深色字，效果和 solid 相同。只影響 outline，其他樣式不變。把滑鼠移到下方按鈕上試試看。

/* 修改後 */
ui-check .uck-outline:hover:not([disabled]) { background: var(--uck-c); color: var(--uck-on); }
